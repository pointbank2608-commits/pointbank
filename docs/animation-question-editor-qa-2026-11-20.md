# 애니메이션 영상 중간 질문 편집 수정 — 2026-11-20

## 시간·저장 계약

- 기존 `VideoQuestion.at`와 `replayStart`는 원본 영상의 절대 초다. 이 저장 형식과 수업 재생 기준을 유지한다. 마이그레이션이나 질문 시각의 일괄 이동은 없다.
- 편집창을 열 때만 `at - slide.startSec`, 저장할 때만 `입력 시각 + slide.startSec`으로 변환한다. 새 편집본은 해당 영상의 `learningRange`를 사용하며, 기존 편집본은 저장된 구간과 절대 질문 시각을 유지한다.
- 재생바의 입력 값도 학습 구간 기준으로 바꾸고, 기존 플레이어에 전달할 때 원본 초로 변환한다. 재생바에서 위치를 고르면 열린 질문 시점을 즉시 갱신한다. 오른쪽 ±1초도 같은 기준이며, 0초는 유효하다.
- 대본 선택과 저장 목록·번호의 시간은 같은 시작점을 뺀다. 24.50초 시작 구간에서 원본 25.00초 대사는 `00:00.50`, 질문 `00:27`은 저장 시 51.50초다.
- 새 질문과 수정 저장에는 다시 보기 시작점을 넣지 않는다. 이전의 선택적 값은 편집 검증을 막지 않으며, 기존 수업 재생에서는 유효한 값만 다시 보기에 사용한다.

## 편집·미리보기

- 저장 성공 후에만 저장 목록과 재생바 번호를 갱신한다. 시간순으로 번호를 매기고, 번호 클릭으로 편집한다. 가까운 번호는 다른 높이에 놓아 클릭 영역이 겹치지 않게 한다.
- 저장 중 표시와 중복 저장 방지 유지. 저장 오류는 작성창 버튼 바로 위에 남기며, 내용을 보존한다. 구간 밖 시각은 질문 시점 바로 아래에서 안내한다. 문항 입력 검증도 미리보기·저장 버튼 가까이에 표시한다.
- 미리보기는 기존 `VideoQuestionCard`를 즉시 표시하고 영상을 자동으로 재생하지 않는다. 편집창 상태는 유지한다. 미리보기에는 학습 관측 콜백을 전달하지 않는다.

## 검증

사용자 컴퓨터의 마우스·창을 조작하지 않고 GPT 내장 브라우저에서 확인했다. 운영 `자료 → 애니메이션 영어 → Mum's Washing Game → 영상 중간 질문 편집` 진입 및 원본 연결 영상의 실제 재생을 먼저 확인했다. 이후 같은 YouTube ID와 24.50~89.50초 구간을 사용하는 로컬 합성 계정으로 질문을 저장했다. 운영 개인 수업 자료는 테스트 목적으로 변경하지 않았다. 합성 대본은 시간 변환을 확인하기 위한 테스트 문장이다.

| 항목 | 확인 결과 |
| --- | --- |
| 재생바·질문 시각 | 재생바 27초 선택 → 질문 시점 `00:27.00`. +1초 조정 시 재생바와 입력 모두 7초 |
| 대본 변환 | 원본 25초/30초 → `00:00.50`/`00:05.50` |

| 네 유형 미리보기 | 저장 전 질문/보기/빈칸/섞인 단어 카드가 영상 재생 없이 즉시 표시. 돌아온 뒤 입력과 시점 유지 |

| 위치·순서 수정 | 6초 질문을 번호로 열어 1초에 저장 → 0·1·2·4초 순서로 번호 재배치, 이후 6초로 복원 |

| 답변 동작 | 말하기 예시 답, 보기 선택·정답 보기, 빈칸 정답 표시, 문장 배열 오답→카드 제거·재배열→정답 확인. 영상은 질문 시점에 멈춘 상태 유지 |
| 최종 확인 | 마지막 코드에서 0초 → 계속 보기 → 2초 질문 정지를 다시 확인. 화면 캡처에 멈춘 원본 영상 장면과 학생 질문·재생바 0:02가 함께 표시 |

이번 실행에서는 `PLAYBACK_TIMEOUT`이 발생하지 않았다. 질문 저장·재열기 테스트의 저장소는 합성 API이며 운영 DB 쓰기 왕복을 별도로 수행한 것은 아니다. 기존 사용자 질문은 절대 시각 보존·변환 왕복과 선택적 이전 필드 호환을 회귀 검사했으며 사용자의 실제 과거 질문을 수정하지 않았다.
