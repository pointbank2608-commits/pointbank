# 휴대폰 참여 보카 대회: 전체 자료 출제와 단계별 설정

- 경로: `/games/quizshow` (교사용, 기존 URL 유지)
- 새 대회는 학습 자료(단어장/문장모음) → 게임 선택·상세 설정 → 확인·저장 순서다. 자료·선택·설정은 이전 단계로 이동하거나 설정 창을 닫아도 현재 화면에서 유지된다. 새로고침 복구는 보장하지 않는다.
- 저장 성공 후 설정 창을 닫고 기존 대회 시작 화면을 제공한다. QR 세션은 선생님이 시작을 누를 때만 생성한다. 저장 실패 시 입력을 유지하며 중복 대회를 만들지 않고 재시도할 수 있다.
- 기본 라운드 수량은 5에서 `count: -1`(가능한 전체 항목)로 변경했다. 명시적인 기존 양수 수량/저장 문제는 자동 변경하지 않는다. 기존 대회는 문제 다시 만들기에서 전체 항목을 선택할 수 있다.
- 문제 수를 줄인 라운드와 전체 라운드가 함께 있어도 같은 라운드 안에서 큐 순환 때문에 항목이 반복되지 않는다.
- 그림·빈칸·글자 섞기는 실제 그림/예문/단일 영어 단어 조건에 맞는 항목만 사용한다. 뜻이 없는 항목, 선택지를 만들 수 없는 문제는 생성하지 않는다. 설정에 전체/출제 가능 수와 최대 문제 수를 구분해 표시한다.
- 단어장/문장모음 전체 카드와 원본 ID·종류를 기존 `classroomSource`에 저장한다. 원본 자료를 수정하지 않는다.
- 게임별 순서·문제 수·제한 시간·기본 점수를 저장한다. 부저는 기존처럼 제한 시간을 사용하지 않는다.
- 변경 파일: `ContestSetup.tsx`, `QuizShowPage.tsx`, `GameWorkspace.tsx`, `liveQuiz.ts`, `types.ts`, KO/EN 번역. 기존 공통 게임 안내는 보카 대회에서만 별도 설정으로 연결한다.

## 검증

`node app/scripts/games/check-contest-setup.mjs`

- 실제 앱 셸과 페이지를 사용하는 합성 API 브라우저 검증 (운영 DB 쓰기 없음).
- 37개 단어, 한 게임만 20문제로 제한하고 나머지는 전체 사용: 총 131문제. 전체 철자/부저 라운드는 서로 다른 37개 정답 모두 포함.
- 12개 문장 → 4게임 48문제. 문장모음 저장 종류 유지, 글자 섞기 비활성.
- 81개 단어 → 기본 4게임 324문제. 기존 숫자 5 호출은 20문제로 유지. 그림 있는 13개 항목만 그림 문제 생성.
- 이전 단계 설정 보존, 실패 후 재저장, PC/390px 모바일 가로 넘침 없음, 콘솔 오류 없음.
- 화면: `output/contest-setup-desktop.png`, `output/contest-setup-mobile.png`.
- 타입 검사·프로덕션 빌드 통과. 기존 빌드의 큰 청크 경고는 남아 있다.
- 실제 학생 휴대폰 접속/운영 QR 세션 생성은 이번 합성 검증에 포함하지 않았다.

사용자의 커밋·푸시·배포 요청에 따라 이번 대회 변경만 선별하여 릴리스한다. 다른 진행 중인 작업과 운영 DB 변경은 포함하지 않는다.

공통 회귀 검증: GUIDE_SKIP_SAMPLES=1 node app/scripts/games/check-guide-flow.mjs 통과. 직접 입력·숫자·자료 저장/불러오기·활동지/수업 연결·문장 게임·모바일 흐름을 확인했다. 대회의 기존 일반 안내 시나리오는 새로운 자료 우선 설정 검증으로 교체했다. 접기 영역과 버튼 문구가 바뀐 공통 검증 선택자도 현재 UI에 맞췄다.
