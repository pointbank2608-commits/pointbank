# 장보기 소리 점검 (2026-10-26)

옷가게도 공통 Shopping 컴포넌트와 GAME_SFX.shopping을 사용한다. 효과음 4041·6001·4015·4025·5037은 기존 파일이 존재한다.

재현: `classbank.gameSound=off`인 상태에서 물건을 선택하고 화면 스피커 버튼을 직접 눌러도 음성 호출이 0회였다. 자동 선택음의 음소거는 정상이나 명시적인 문장 듣기까지 조용히 무시하고, 게임 진행 중 음소거 상태를 바로 알기 어려웠다. 실제 사용자 기기의 소리 설정을 읽은 결과가 아니라 합성 브라우저에서 재현한 코드 경로다.

수정:
- 장보기 화면 왼쪽 아래에 기존 공통 소리 켜기/끄기 버튼을 항상 표시한다. 소리를 켤 때 짧은 확인음을 재생한다.
- 문장 스피커/결과의 문장을 직접 누르면 브라우저 영어 읽기를 요청한다. 효과음 음소거 저장 설정 자체를 바꾸지는 않는다.
- 자동 문장 읽기와 효과음은 기존 음소거 설정을 따른다. 끄기·새 판·페이지 종료 시 진행 중 음성을 취소한다.
- 새 음성 파일·외부 서비스·DB 변경은 없다.

확인: 음소거에서 직접 문장 듣기, 소리 켜기 이후 선택 효과음과 문장 읽기, 다시 음소거 후 자동 재생 차단, 효과음 5개 HTTP200/본문 존재, PC/390px 배치·가로 넘침 없음·런타임 오류 없음. 검증은 Audio.play 및 speechSynthesis.speak 호출을 계측했다. 실제 스피커 출력이나 사용자 기기의 음성 설치 상태까지 확인한 것은 아니다.

임시 검증: `tmp/check-shopping-audio.mjs`. 화면: `output/shopping-audio/after.png`, `mobile.png`. 사용자 요청에 따라 관련 수정만 선별하여 커밋·푸시·운영 배포한다.
