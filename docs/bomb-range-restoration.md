# 시한폭탄 폭발 시간 설정 복원 (2026-10-27)

원인: 폭발 시간은 `config.bombRange`와 TimeBomb 타이머에 남아 있었으나, 입력란이 게임판 안의 `editable && !itemsHidden` 영역에만 있었다. 공통 준비/플레이 분리 후 이 영역이 숨겨지고 BombPage의 별도 설정 창에는 시간 입력이 옮겨지지 않았다. 기존 데이터나 무작위 타이머가 삭제된 것은 아니다. 이전 전수 점검은 저장 흐름·버튼 표시 중심으로, 각 게임의 모든 설정 항목 존재 여부를 확인한 것은 아니었다.

수정:
- 준비 창 ‘시한폭탄 설정’의 진행 소리 위에 최소·최대 시간 입력 복원.
- 새 BombRangePicker를 준비 창과 예전 게임판 편집기 양쪽에서 재사용.
- 기본 15~60초, 기존 저장값, bombRange 필드 유지. 같은 값은 고정 시간, 서로 다른 값은 범위 내 무작위 시간.
- 빈값은 이전 값으로 복구, 최소 1초·정수, 최대값은 최소값 이상으로 보정.
- 실행 중인 판의 타이머를 다시 걸지 않고 다음 시작부터 반영.

검증: `node app/scripts/games/check-bomb-range.mjs` 통과. 기본값 15/60, 범위 12/18 저장·재열기, 같은 게임 ID에 12/12 저장, 실제 gameClock에 12000ms 예약 전달, 잘못된 값 보정, 진행 소리 선택 유지, PC/390px 가로 넘침 없음, 런타임 오류 없음. 타입 검사·Vite 빌드 확인. 합성 API 검증이며 운영 자료를 변경하지 않았다.

화면: `output/bomb-range-desktop.png`, `output/bomb-range-mobile.png`.
현재 로컬 변경이며 커밋·배포하지 않았다.
