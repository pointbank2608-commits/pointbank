# 게임 조작 되돌리기 · 다시 실행 (2026-11-22)

모든 선생님 게임의 상단 도구줄에 뒤로가기(Undo)와 앞으로가기(Redo)를 추가했다. 사용자 참고 이미지의 돌아오는 곡선 화살표만 SVG로 재현하고, 버튼은 기존 사이트의 흰색 배경·남색 선·옅은 테두리·둥근 모서리를 따른다. 청록색 타일은 쓰지 않는다.

## 동작과 범위

- 한 게임 안에서 최근 50회 조작을 보관한다. 보드·선택·입력·점수·차례·문제 진행과 무작위 추첨 결과를 복원한다. 새 조작을 하면 이후 다시 실행 기록은 버린다.
- 기본 게임 76개 경로와 파닉스 48개 경로가 같은 버튼을 쓴다. 일반 화면·전체화면·수업 발표에서 동일한 세션을 사용한다.
- Ctrl/Cmd+Z는 취소, Ctrl/Cmd+Shift+Z와 Ctrl+Y는 다시 실행이다. 입력란에서는 브라우저의 글 편집 단축키를 우선한다. 게임 소유 팝업은 단축키로 취소할 수 있다.
- 다시하기, 자료·게임 설정 변경은 이전 게임 기록을 초기화한다. 반·팀 순서 설정을 닫을 때도 기존 순서의 기록을 버린다. 원본 단어장·수업 저장 버전을 되돌리는 기능은 아니다.
- 버튼은 기록이 없거나 준비·설정·공유 읽기 화면이면 비활성화된다.

## 구현

`GameHistory`는 명시적으로 등록한 상태를 복사해 보관한다. React 내부 자료구조, 전역 브라우저 타이머 패치, DOM 전체 재실행을 쓰지 않는다.

`GameHistoryContext`의 상태·논리 ref 바인딩은 문제 컴포넌트가 교체된 후에도 저장된 타이머가 복원된 컴포넌트를 가리키게 한다. `gameClock`은 세션별 남은 타이머·가상 시간을 복원하고 effect별 타이머 정리도 유지한다. DOM·오디오·물리 엔진 자체를 일반 상태처럼 복사하지 않는다. 수박 게임은 과일 물체의 별도 위치·속도 어댑터를 사용한다.

기록 이벤트는 기존 캔버스에 연결한다. 레이아웃용 DOM 래퍼를 추가하지 않으므로 게임별 직접 자식 CSS 규칙을 보존한다. 리모컨의 명령도 같은 조작 경계를 사용한다.

휴대폰 퀴즈쇼 미리보기는 로컬 상태를 복원한다. 실제 대회는 기존 호스트 API로 단계와 교사 판정을 변경하며 학생이 제출한 답·참가자를 과거 스냅샷으로 덮어쓰지 않는다. 대회 생성·종료·참가자 내보내기는 새 기록 경계다. 추가 DB 마이그레이션은 없다.

## 검증

`app` 폴더에서 실행한다. 모두 합성 교사 세션이며 학습 센서는 끈다. 테스트용 히스토리 조회는 fixture 플러그인만 주입하고 운영 번들에는 넣지 않는다.

```powershell
node scripts/games/check-game-history.mjs
node scripts/games/check-game-history-matrix.mjs
$env:HISTORY_PHONICS='1'
node scripts/games/check-game-history-matrix.mjs
npm run build
```

- 기본 경로마다 실제 조작 뒤 상태를 비교해 취소·복원을 검사한다.
- 파닉스 모든 경로에서 힌트 상태를 비교하며, 소리 풍선은 정답·별·다음 문제 컴포넌트 교체까지 검사한다.
- 상세 검사는 알 애니메이션 도중 취소와 타이머 재개, 새 기록 분기, 4 in a row 보드·차례, 같은 돌림판 당첨 결과·최근 결과 중복 방지, 모험 게임 여러 문제 이동, 실제 브라우저 전체화면 유지, 수박 물리 물체 복원을 검사한다.
- 화면 비율 검사는 단어 뽑기·두 주사위·퀴즈쇼·텔레파시·소리 풍선의 일반/전체화면/발표에서 수행했다. 실제 다중 휴대폰 대회 동시 접속은 이번 UI 검증에 포함하지 않는다.
