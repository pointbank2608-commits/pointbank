# 랜덤 공 뽑기 디자인 개선 (2026-10-21)

- 실행 화면의 바로 추가 입력과 공 투입 애니메이션을 제거했다. 기존 게임 준비·설정의 항목 편집은 유지한다. 한국어/영어 이용 안내도 새 경로로 갱신했다.
- 기존 나무 이미지 대신 `LotteryCabinet.tsx`의 SVG 유리 볼·민트 받침·크림 배출구를 사용한다. 공은 파스텔 색과 대비가 있는 밝은 이름표, 결과 받침은 크림색으로 통일했다. 공은 유리의 앞/뒤 레이어 사이에서 움직이며 추첨 규칙은 유지한다.
- 확대된 화면에서도 공 배출 애니메이션 좌표가 맞도록 화면 배율을 반영한다. 명시적 저장·DB 모델 변경은 없다.
- `check-order-design.mjs`: 실제 페이지와 합성 계정/API로 바로 추가 제거, 섞기·6개 중복 없는 추첨·새 라운드, 무저장, 기존 설정 편집, 전체화면·모바일·런타임 오류를 확인한다. 운영 계정 확인을 대신하지 않는다.
- 확인: `npm --prefix app run dev` → 로그인 → `/games/order` → 샘플로 먼저 해보기 → 게임 시작.
- 검증: 빌드(타입 검사 포함), 린트(기존 경고만), 브라우저 검사 및 데스크톱·모바일 캡처 확인. 커밋·배포 전 로컬 수정이다.

후속 디테일 개선: 공이 놓이는 유리 내부는 유지하고 민트 받침에 미세 점토 질감, 입체 테두리, 뚜껑·배지·나사·다이얼의 음영, 배출 트레이와 바닥의 접지 그림자를 추가했다. 새로운 장식은 받침과 유리 가장자리에 배치했다. 동일 브라우저 회귀 검사와 린트를 다시 통과했으며 캡처에서 공 가시성을 확인했다.


## 입체 점토 추첨기 이미지로 교체

미세한 SVG 장식 변경만으로는 배경의 점토 질감과 차이가 컸다는 사용자 피드백에 따라, 내장 image_gen으로 새 입체 점토 프레임을 생성했다. `app/public/skins/lottery-cabinet-clay-v2.png`(1196×1315, RGBA, 약 895 KB)를 사용한다. 중앙과 외부의 알파 0을 검사했으며 공은 기존 HTML 애니메이션을 그대로 유지한다. 배경·항목·추첨 로직은 유지한다. 프레임은 이미지, 유리 뒷면은 SVG로 분리한다.

생성 프롬프트: `docs/order-clay-image-prompt.txt`. 내장 이미지 생성 도구 사용, CLI/API 대체 경로 사용 안 함. 이 에셋은 새 파일이며 원본 생성 파일도 보존했다.


## 공의 점토 질감 통일

`lottery-ball-clay-v1.png`를 내장 image_gen으로 생성했다(1254×1254 RGBA, 약 1.59 MB). 원본 생성 파일은 보존하고 프로젝트 public/skins에 복사했다. `LotteryBall.tsx`는 이 한 장의 실제 점토 질감·광원을 마스크와 multiply 합성으로 파스텔 6색에 적용한다. 통 안·배출 애니메이션·결과 공에 동일 컴포넌트를 사용하며 이름표는 별도 텍스트로 유지한다. 추첨 결과·항목 데이터·규칙 변경은 없다. 생성 프롬프트는 `docs/order-clay-ball-prompt.txt`에 기록했다.

브라우저 검사는 통 안과 결과 공에 질감 이미지가 모두 로드되는지도 확인한다. 실제 사용자 계정이나 운영 배포 검증은 아니다.
공의 둥근 점토 표면이 드러나도록 이름표를 작은 타원형으로 다듬고 명도를 조정했다. 통 안/결과 이미지 로드, 6개 중복 없는 추첨·재시작, 설정 편집, 전체화면·모바일 검사를 통과했다. 빌드·타입 검사·린트도 통과했으며 실제 화면 캡처를 확인했다. 커밋·배포 전이다.
