# 문법 30분 단체수업 (2026-11-03)

문법 자동 수업이 4장(약 10분)뿐이라 짧다는 피드백으로, 문법 하나를 30분 흐름으로 만든다.

| 분 | 슬라이드 | 재료 |
|---|---|---|
| 0~3 | 출석 · 제목 칠판(패턴·워밍업) | 문법 항목 |
| 3~10 | 문법 칠판 · 규칙 발견 질문 | `grammarPoints.json`, 워크북 `discover` |
| 10~16 | 개념 확인 문제(고르기 10, 점수판) | 워크북 `choose` |
| 16~19 | 게임① **문법에 어울리는 문법별 게임**(없으면 문장 배열하기) | `recommendGrammarGames` 의 첫 번째 |
| 19~26 | 틀린 곳 고치기(8) · 조건 영작(6) | 워크북 `correct`, `review` (A·B 세트) |
| 26~28 | 게임② 팀 대항 퀴즈 | B 세트 고르기(없으면 A 뒷부분) |
| 28~30 | 정리 칠판 · 마무리 문제 3 | `tip`, `review` |

- 문제 풀이는 새 슬라이드 종류 없이 기존 Q&A 슬라이드를 쓰고, 슬라이드마다 타이머 보조 블록을 단다.
- 코드: `lib/grammarLesson.ts`, 연결: `lessonRecipes.ts`(`makeGrammarGames`), `quickLesson.ts`, `QuickLessonWizard`, `LessonRecipePicker`, `CurriculumPage`. 문구 `i18n/grammarLessonLocales.ts`.
- 워크북 자료가 부족한 문법은 예전 짧은 수업(출석·칠판·문장 배열)으로 돌아간다.
- 게임 내용은 수업을 만들 때 게임 센터에도 템플릿으로 생긴다(문장 배열하기 1개 + 팀 대항 퀴즈 1개).
- 확인: `node app/scripts/grammar/check-grammar-lesson.mjs`.
- 한계: 개별수업은 아직 그대로. 워크북 문항은 교사 전수 검수 전 초안.

## 문장 공장 (2026-11-03)
`lib/sentenceFactory.ts` — 예문 하나를 규칙(AI 없음)으로 과거/현재/미래·부정·의문·주어 바꾸기(They/He) 문제로 늘린다.
- 알려진 동사 목록(불규칙 포함 약 110개)과 간단한 주어(대명사·관사+명사·이름)만 다룬다. 시간 표현(yesterday·every…), 소유격·재귀대명사(주어 바꾸기·1·2인칭 의문문), 쉼표·의문문·부정문 원문은 건너뛴다. 틀린 문장(She play)은 거른다.
- 30분 수업의 심화 뒤에 "문장 공장 미션" Q&A 슬라이드(3분)로 붙는다 — 변형 문제가 6개 이상 나오는 문법(169개 중 122개)만.
- 확인: `node app/scripts/grammar/check-sentence-factory.mjs`.
- 아직: 문장 공장을 독립 게임/연속 미션 화면으로, 문법 종류별 맞춤 게임 틀 7~8개(타임라인·저울·문장 합치기 등)와 자동 추천, 단어장 슬롯을 게임까지 확장.

## 게임① 자동 연결 (2026-11-04)
수업을 만들 때 문법 종류에 어울리는 문법별 게임(61~69번) 하나를 게임 템플릿으로 만들어(`config.grammarId`만 저장) 게임① 자리에 넣는다. 게임②는 사용자 결정대로 팀 대항 퀴즈 그대로.
- 규칙표: `lib/grammarGamesB.ts` `AFFINITY` — 비교급·최상급 → 비교급 챔피언, 접속사 → 이유·결과 연결 다리, 빈도부사 → 습관 캘린더, 품사(`pos-*`) → 문장 속 품사 탐험, 5형식(`forms-*`) → 문장 뼈대 조립소, be동사·3인칭 -s → 주어·동사 짝꿍, 시제·부정·의문 → 문장 변신 연구소. 규칙이 없는 문법은 문법 id로 고정된 순환(같은 문법은 늘 같은 게임)으로 문장 변신 연구소·뼈대 조립소·품사 탐험·짝꿍에 나눈다.
- 추천은 실제로 문제가 만들어지는 게임만(`MIN_ROUNDS`). 하나도 없는 문법(169개 중 1개)은 예전처럼 문장 배열하기.
- 분포(169개): 변신 66·품사 54·뼈대 23·짝꿍 11·비교급 6·연결 6·습관 2·없음 1.
- 선생님이 바꾸려면 수업 편집에서 그 게임 슬라이드의 "종류 바꾸기"를 쓰면 된다.
- 확인: `node app/scripts/grammar/check-grammar-lesson.mjs`(저장소는 가짜로 대체해 템플릿 생성까지 검사).

## 개별수업 문법 수업 늘리기 (2026-11-04)
단체수업과 같은 문제 자료를 개별수업(학생 혼자 하는 수업)의 기존 채점 단계로 옮겨 "교과과정 3단계"와 "표준 50분 흐름"의 문법 수업을 길게 만들었다. 새 단계 종류·SQL 변경 없음.
- `lib/soloGrammarBank.ts` `soloGrammarBank(grammarId)`: 워크북 A·B 빈칸 고르기 → **맞는 문장 고르기**(`pickCorrect`, 문장 능력으로 집계 — 어휘 빈칸 `fillBlank` 로 만들면 어휘 점수가 되므로 일부러 피함), 워크북 오류 문장 → **오류 고치기**(`fixError`), 워크북 추가 예문 → **단어 배열 영작**, **문장 공장** 미션(과거·부정·의문·주어 바꾸기) → 배열 영작, 조건 영작 → `condWrite`(워크북 조건은 안내 문구, 자동 검사는 단어 수만), 문법별 게임(짝꿍·비교급·연결·수동태·조건문·장보기) 문제 → 맞는 문장 고르기.
- 3단계 틀: 1) 기본 개념 = 카드 → 해석·맞는 문장 + 워크북 4 + 게임 문제 2 → 게임, 2) 심화 = 오류 고치기 3~4 · 배열 영작 · 문장 공장 2 · 게임 문제 2 · 조건 영작 2 → 게임, 3) 총정리 = 최종 테스트 8문항 + 워크북 B 4 + 게임. 문법 110개 중 109개가 **예상 35~43분(평균 40분, 기본 수업은 14분)**.
- 표준 50분 흐름: 문법 수업이 실제로는 약 23분이었다 → 같은 은행으로 34~47분(평균 42분).
- 각 그룹 안내의 "N분"은 이제 그 그룹의 실제 문제 수로 계산한다(`soloBoard.relabelGroupMinutes`, 문제 종류별 예상 시간 `SECONDS` 합).
- "기본(약 15분)" 수업은 짧은 선택지로 그대로 둔다. 은행 자료가 없는 문법(1개)은 예전 구성.
- 같이 고친 오래된 버그: 해석 보기에 같은 문장이 두 번 들어가던 것(`options()` 중복 제거), 표준 수업 빈칸 보기에 "Are"/"are"가 같이 들어가던 것.
- 확인: `node app/scripts/grammar/check-solo-grammar-long.mjs`(110개 전부 생성 + 개별수업 저장 전 검사 `lessonProblems`).
