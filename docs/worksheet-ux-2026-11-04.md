## 보존한 기존 기능

- 같은 워크시트 catalog/generator, 샘플 모달, 전체 81종, 수정용 JSON/기기 저장/이름 붙인 사본/되돌리기 유지.
- 기존 문서 schema는 classbank-worksheet-v1 그대로. source/selectedWordIds는 선택 필드이며 기존 파일도 읽음.
- 기존 전체 단어 점선 쓰기, A4 생성기, 교사 설명/답안, 원본 단어장·문장 모음 보호, 업로드·사전 편집 재사용.
- 게임 정답 판정·수업 저장 형식·기존 묶음의 네 활동 구성은 변경하지 않음. 새로운 게임 모드나 자동 저장을 추가하지 않음.
- 워크북 파일 변경 없음. 테스트는 mock API의 UX점검 자료로만 진행. 기존 운영 자료 읽기/쓰기 검증은 하지 않음.

## 검증한 경로와 결과

- `node --experimental-websocket scripts/workbooks/check-worksheet-ux-logic.mjs`: 81종의 적합한 예시 + 일반 25개 단어 데이터 검사 통과. 원본 불변, 유효/0쪽 처리, 실제 사용 수, 소문자 섞기, 낱말 찾기 격자 실제 배치, road의 r|oa|d 3칸, 한 음소 차이, 영어 그림 보기, 색칠 답안 일치, 기존 JSON 호환, 같은 이름/다른 ID 구분 검사.
- `check-worksheet-ux-browser.mjs`: 실제 React 화면 + 테스트 API. 활동지 메뉴→공통 허브, 단어장→인쇄물 만들기→허브, 양식 왕복, 샘플 열기/닫기, 자료 변경 취소/교체, 같은 이름의 두 ID, 새로고침, URL에 source가 없는 기존 편집본 복원, 불러오기 실패/재시도, 문항 없는 문장 양식의 인쇄 차단→문장 모음 선택 통과. 390px 모바일 가로 넘침 없음. 원본 목록 불변/게임 저장 쓰기 0 확인.
- `check-worksheet-ux-print.mjs`: 아래 27종의 일반 25개 단어/적합한 예시를 구분하여 생성. 출력 가능한 일반 자료를 우선 사용하고 불가능한 양식은 적합한 예시로 출력. 학생용·교사용 PDF 54개, 226쪽 생성. 학생용 미리보기/print media의 문항 텍스트 동일, 모든 학생용 예상 쪽수와 PDF 쪽수 일치. 가로 넘침 검사 통과.
- PDF 전쪽 텍스트에서 빈 쪽/undefined/앱 사이드바 유입 없음. 학생용 첫 쪽, 학생·교사용 마지막 쪽 contact sheet를 눈으로 확인하고 점선 쓰기 첫 쪽을 크게 확인. 긴 waterfall, 빈칸·섞인 글자·미니북 배치와 마지막 쪽 레이아웃 확인.
- 27종: basic-list, basic-card, basic-tracing, basic-quiz, basic-coloring, basic-fillBlank, basic-cutPaste, basic-miniBook, basic-trueFalse, alphabet, soundBoxes, targetLetters, soundSort, rhyme, wordChain, minimalPairs, syllables, pictureMatch, meaningPairs, wordSearch, scramble, wordSort, frayer, morphology, collocations, sentenceOrder, grammarChoice.
- `check-worksheet-ux-wheel.mjs`: 실제 SVG 2·5·25칸의 숫자 폭+외곽선이 칸의 현 길이 안에 들어옴. 2칸은 50px 이상, 24/25 두 자리 번호 유지. 옆 번호 목록과 모바일 넘침 검사. 활동 목록 112개를 registry와 비교하여 누락 없음. 문법 탐정 설명 표시. 테스트 수업에서 준비→돌림판 추가/선택→기존 네 활동 묶음 추가→저장→새로고침→재열기 후 5개 활동과 돌림판 1개 유지.
- 앱 TypeScript `tsc --noEmit -p tsconfig.app.json` 통과. 변경 파일 oxlint(경고 오류 처리) 및 `npm run build` 통과. 최종 재검사 결과는 output/worksheet-ux에 기록.

## 아직 확인하지 못한 항목과 범위

- 실물 프린터 출력/종이 접기 및 운영 서버 배포는 하지 않음. 미니북의 접는 순서는 코드와 PDF의 패널 배치를 확인했으며 실물 접기 검수는 아님.
- 운영 계정의 권한/RLS·실제 저장 API·운영 자료별 외부 이미지/업로드 링크 접근성은 검증하지 않음. 실패/재시도와 저장은 격리된 테스트 API로 검증.
- 테스트 브라우저는 운영 API 접근을 차단했으며 외부 웹 폰트도 대체 글꼴로 검사함. 실제 네트워크에서 내려받은 웹 폰트의 인쇄 차이는 별도 확인이 필요함.
- PDF 중간 쪽 전체를 하나씩 육안 검수하지는 않음. 전쪽 텍스트/빈 쪽/쪽수 검사와 대표 첫·마지막 쪽 시각 검사를 구분함.
- 일반 25개 단어 테스트의 그림은 구조 검증을 위해 같은 테스트 이미지를 재사용. 실제 수업 자료의 모든 단어-그림 의미 대응을 사람이 전수 판정한 결과는 아님.
- 파닉스 규칙·발음·강세·영어 표현 짝이 등록되지 않은 단어에 대해 값을 추정하지 않음. 해당 양식은 명시적인 자료 보완이 필요.
