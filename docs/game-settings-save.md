# 게임 설정 저장 완료 표시 (2026-10-27)

## 사용자에게 보이는 동작

- 공통 게임 준비/설정 창의 내용만 스크롤하고 하단 저장 영역을 고정한다.
- ‘게임 저장하고 닫기’: 임시 활동은 새 game_templates로 생성, 기존 저장 게임은 같은 ID의 items/config를 저장한다. 저장 응답이 성공한 뒤 닫고 완료 안내를 표시한다.
- ‘설정 적용하고 닫기’: 기존의 현재 활동 적용/닫기를 유지한다. 임시 활동을 서버 게임으로 생성하지 않는다. 기존 게임의 자동 반영 동작을 취소하는 기능은 아니다.
- 저장 중에는 중복 제출·헤더 닫기·내용 변경을 막는다. 실패하면 창을 유지하고 오류와 재시도를 제공한다.
- 임시 활동/저장된 게임 안내를 구별한다. 기존 단어장 저장 옵션과 이름을 지정하는 활동 저장 기능은 유지한다.
- 보카 대회는 전용 단계별 저장 기능을 그대로 사용한다.

## 구현

- GameWorkspace: 본문 스크롤/하단 고정, 명시적 저장·성공 안내·모바일 세로 버튼.
- GameWorkspaceBridge/useGameTemplates: saveSettings로 현재 설정을 저장한다. blur 저장 필드의 최신 반영을 기다린다. 성공 시 로컬 설정도 저장한 스냅샷으로 맞춘다.
- gameTemplateWrites/api: 같은 게임의 자동 저장·명시 저장 요청 순서를 직렬화한다. 항목 갱신도 동일 경로로 처리한다. 서버 갱신 시 실제 ID 한 행의 응답을 확인하므로 권한 등으로 0행 갱신된 경우 성공으로 처리하지 않는다.
- 공통 데이터 구조·DB 스키마를 바꾸지 않는다.

## 검증

- `node app/scripts/games/check-settings-save.mjs`: PC/390px 하단 버튼 가시성, 임시 게임 생성·설정 보존, 같은 게임 업데이트, 실패 시 창 유지·재시도, 저장 성공 안내, 중복 생성 없음, 요청 직렬화·실패 후 복구 통과.
- `GUIDE_SKIP_SAMPLES=1 node app/scripts/games/check-guide-flow.mjs`: 공통 준비·자료 저장/불러오기·활동지·수업 연결·문장·모바일 회귀 통과.
- `node app/scripts/games/check-contest-setup.mjs`: 보카 대회 전용 설정/저장 흐름 통과.
- 타입 검사 및 Vite 빌드 통과(기존 청크 크기 경고 유지).
- 합성 사용자/API 검증이며 운영 DB 변경은 하지 않았다.
- 화면: `output/settings-save-desktop.png`, `output/settings-save-mobile.png`.

사용자 요청에 따라 설정 저장·아이스크림 배치·장보기 소리 수정도 함께 선별 커밋·푸시·운영 배포한다.
