# 게임 안에서 수업 준비·진행하기 (2026-10-19)

## 범위
게임센터와 내수업 실행에 공통 게임 작업 화면을 적용한다. 자료·반/학생·팀/순서·시작·설정·저장을 게임에서 접근하고 기존 게임 구현과 자료 원본을 보존한다. 커밋·운영 배포·운영 DB 변경은 실행하지 않는다.

## 시작 상태
추적 파일 변경 없음. 기존 scripts/vocab/out 생성 자료 및 제안서 PDF가 미추적 상태이며 이번 작업에서 수정하지 않는다. CLAUDE.md의 기존 시스템 보존·커밋 금지 지침을 확인했다.

## 조사
- 게임 페이지가 useGameTemplates와 GameThemeFrame을 공유한다.
- 실제 설정/저장 UI는 게임 프레임 밖 페이지 아래에 있다.
- 수업 실행은 같은 게임 라우트를 사용한다. 수업 편집 안의 GameEmbedContext는 유지한다.
- 팀/순서는 기존 TeamOrderPanel 및 명단별 기기 저장을 재사용한다.
- buildGameContent는 게임별 단어장 변환 필드를 이미 구분한다. 이를 재사용해 게임 변경 때 잘못된 config 복사를 피한다.

## 완료한 동작

- 선생님용 게임 47개 라우트에 공통 작업 화면을 적용했다. 게임센터와 내수업 실행 모두 자료·반, 팀·순서, 시작·이어하기, 설정·저장에 게임 화면에서 접근한다. 학생용 라우트와 수업 편집기의 게임 삽입 화면은 기존 구조를 유지한다.
- 기존 페이지 설정 폼은 게임 위 준비 창으로 옮기고, 게임판은 같은 인스턴스를 유지하도록 별도 stage에 portal로 표시한다. 준비 창 열기/닫기로 게임판을 재생성하지 않는다. 기존 게임마다 저장 버튼·입력 자동 반영 방식은 유지한다.
- 단어장·문장 모음을 선택하면 해당 게임에 맞는 게임 구성을 만든다. `classroomSource`에 자료 출처와 카드 스냅샷을 보관하며 원본 단어장·문장은 수정하지 않는다. 같은 반·같은 자료 버전의 기존 구성이 있으면 재사용한다.
- 같은 내용으로 다른 게임을 열 때 목표 게임의 변환기를 다시 실행한다. 퀴즈의 정답 번호 등 이전 게임 전용 config를 그대로 복사하지 않는다. 이미지·분류 등 필요한 조건이 부족한 게임과 내장 역할극은 자료 선택에서 호환되지 않음을 표시한다.
- 반 명단과 기존 팀·순서 저장을 재사용한다. 이번 진행에서 제외할 학생, 자유 참여, 다음 차례를 지원한다. 명단이 같은 게임 간 팀·순서는 기기 저장을 통해 유지된다. 제외 학생 목록은 현재 게임 화면 세션에만 적용된다.
- 일부 게임의 고정 2팀과 기존 가변 팀 수 설정을 연결했다. 진행 중 팀 수 변경으로 새 판이 필요하면 안내한다.
- 수업 실행 중 게임을 바꾸면 현재 게임 활동만 교체하고 다음 활동·현재 순서를 유지한다. 추후 학생 따라보기를 시작할 때 쓸 snapshot도 갱신한다. 학생 따라보기가 이미 켜져 있으면 자료·게임 설정 변경은 끈 뒤 진행하도록 안내한다.
- 로컬 게임용 `gameClock`으로 타이머·연출 시간을 정지/재개한다. 브라우저 전역 타이머와 숙제 타이머는 교체하지 않는다. 준비·일시정지 중 게임 클릭과 게임 단축키도 차단한다.
- 화면 크기 관찰 과정에서 발생하던 ResizeObserver 반복을 프레임 단위 배치 및 동일 크기 갱신 생략으로 정리했다.

## 주요 파일

- `app/src/components/GameWorkspace.tsx`, `app/src/context/GameWorkspaceContext.tsx`: 공통 게임 화면·준비 창·자료/게임 선택·팀 연결.
- `app/src/components/GameThemeFrame.tsx`, `EditOnly.tsx`, `TeamOrderPanel.tsx`, `GameFitText.tsx`: 게임판 유지, 전체화면/발표 중 내부 제어, 팀 패널, 크기 계산.
- `app/src/lib/useGameTemplates.ts`: 기존 템플릿과 작업 화면 연결, 자료 선택·게임 전환·반 전환 비동기 응답 보호. 기존 게임별 템플릿 동작을 재사용한다.
- `app/src/lib/gameWorkspace.ts`, `types.ts`: 자료 호환 판정·변환과 선택적 `classroomSource` 필드.
- `app/src/lib/gameClock.ts` 및 게임 컴포넌트 34개: 게임 전용 일시정지 가능한 시간 처리.
- `app/src/context/LessonRunnerContext.tsx`: 현재 게임 활동 교체와 자료 전달.
- `app/src/App.tsx`, `WordListGameLauncher.tsx`, `WordListsPage.tsx`, `tailwind.css`: 진입 경로·자료에서 게임 시작·레이아웃.
- `app/scripts/games/`: 합성 데이터 로직 및 브라우저 검증 fixture.

## 동작의 범위와 남은 실기기 확인

- 준비 창은 같은 화면에 보인다. 프로젝터에 연결된 화면에서 선생님에게만 보이는 비공개 설정창을 구현한 것은 아니다.
- 온라인 Quizshow 참가자·서버 시계는 계속 진행한다. 화면에 이를 명시하며, 로컬 화면 가리기를 대회 전체 일시정지라고 표시하지 않는다.
- 전체 47개 게임은 설정창 열기/닫기를 확인했다. 모든 게임의 모든 라운드·특수 규칙을 끝까지 플레이한 것은 아니다. 실제 교실 전자칠판/터치, 실기기 전체화면, Safari, 온라인 다인 대회는 추가 확인 대상이다.
- 기존 저장 폼의 저장 동작을 유지한다. 모든 게임 필드의 통합 자동 저장이나 새로고침 후 진행 상황 복원까지 보장하지 않는다. 게임을 바꾸면 새 판으로 시작하며 게임 간 점수를 합산하지 않는다.
- 자료 호환성이 있는 게임에만 자료를 바로 넣는다. 내장 역할극 등 전용 콘텐츠 게임에도 공통 설정 화면은 적용하지만, 임의 단어장 사용을 지원한다고 표시하지 않는다.

## 배포·되돌리기

커밋·푸시·배포·운영 DB 변경은 하지 않았다. 스키마 마이그레이션은 없다. `game_templates.config`의 선택적 JSON 필드만 추가 사용한다. 기존 미추적 생성 자료와 PDF는 수정하지 않았다.

되돌릴 때 위 주요 파일과 게임 타이머 교체를 이번 변경 단위로 복원한다. 기존 숙제 편집기 등 이전 작업은 포함하지 않는다. 실제 사용 후 생기는 게임용 구성은 일반 게임 템플릿이며 원본 단어장과 별개다. 이번 합성 검증으로 운영 템플릿이 만들어지지는 않았다.
