# 문장 은행 — 말하기 목적·문장 패턴 (2026-10-28)

선생님이 문장을 매번 입력하지 않고, **미리 만든 예문을 골라 수업·게임·문장 목록에 쓰도록** 문장 은행을 두 갈래 더 열었다(사용자 아이디어: 단어장이 가족·동물·동사로 나뉘듯 문장도 사용 목적별로).

## 보는 기준 4가지 (`SentenceBankPicker`, 레벨 칩 유치·초등·중등·고등은 공통)
| 기준 | 내용 | 자료 |
|---|---|---|
| 상황·주제 | 자기소개·음식 주문·길 묻기 … 12상황 | `data/sentenceBank.ts` (기존) |
| **말하기 목적** | 소개하기·질문하기·부탁하기·좋아하는 것·감정·길 안내·감사/사과·제안·묘사·계획·의견 11가지 × 레벨 4 × 8문장 = 352문장 | `data/sentencePurposes.ts` (새, id 는 `p:` 로 시작) |
| **질문·대답 짝** | 상황 12개 × 레벨 4 × 6쌍 = 288쌍. 질문 하나에 그 질문에 맞는 대답 하나. 고르면 질문 줄 다음에 대답 줄이 이어서 담긴다(짝 활동·말하기용) | `data/sentenceQA.ts` (`scripts/sentences/gen-qa.mjs`가 만듦) |
| **문장 패턴** | 처음 두 낱말(I like / Can you / What is …)이 같은 문장을 **모든 상황·목적에서 모아** 같은 구조를 반복 연습 | 위 두 자료에서 계산(`commonPatterns`, 3문장 이상인 패턴) |

## 쓰는 곳
- 게임 설정의 "문장 은행에서 담기"(번개 피하기·문장 잡기·문장 배열하기·마지막 박스 등 기존 자리 전부).
- **내 단어장 > 문장 목록 편집**(`SentenceListEditor`): 문장 은행에서 골라 바로 그 목록에 더한다(`hideSaveAsList` — 새 목록으로 저장하는 칸은 숨김). 이미 있는 문장은 `newSentenceItems`가 걸러 준다.
- 문장·해석은 ✎로 고쳐서 담을 수 있고, 고친 값은 은행 원본을 바꾸지 않는다.

## 자료를 만든 방법과 한계
- `app/scripts/sentences/gen-purposes.mjs`: 목적마다 Gemini 로 레벨별 8문장 생성 → 형식·낱말 수(유치 2~7·초등 4~10·중등 6~15·고등 8~22)·중복·상황 은행과의 겹침 검사 → 독립 검수(영어 자연스러움·번역·목적 적합성)에서 나온 지적을 고쳐 `sentencePurposes.ts` 를 쓴다. 다시 돌리면 덮어쓴다.
- **전부 AI 초안(자동 검수만 거침, 선생님 검수 전)** — 화면에 "초안" 안내가 뜬다. 사람이 읽고 다듬은 것이 아니다.
- 패턴은 첫 두 낱말만 보는 단순 규칙이라 "It is"처럼 뜻이 넓은 패턴도 한 묶음이다(문법 분류가 아님).
- 질문·대답 짝은 문장 두 줄로 담길 뿐 "짝" 정보를 따로 저장하지 않는다(문장 목록에서는 이어진 두 줄). 짝은 ✎로 고칠 수 없다.
- 단어장 낱말을 틀에 넣어 문장 만들기(예: 동물 단어장 → I like dogs.)는 아직 없다(다음 후보).

## 확인
`node app/scripts/sentences/check-picker.mjs` — 로그인 없이 선택기를 띄워 목적별 8문장·패턴 칩·패턴별 필터·질문·대답 짝 담기 순서(질문→대답)와 결과 형식을 본다(스크린샷은 `scripts/sentences/picker*.png`, 커밋하지 않는다).
