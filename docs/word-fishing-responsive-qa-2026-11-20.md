# 단어 낚시 그림·물고기 확대 — 2026-11-20

- 문제 그림과 물고기를 고정 픽셀 상한 대신 게임 영역의 너비·높이에 맞춰 배치한다. 수업에 삽입된 게임도 같은 컴포넌트와 화면 비율을 사용한다.
- 가로 화면에서는 큰 문제 그림과 물고기 영역을 나란히, 세로 화면에서는 그림을 위에 배치한다. 짧은 화면에서는 제목·안내 영역을 줄여 선택지 공간을 확보한다.
- 물고기의 글자도 물고기 크기에 비례한다. 기존 `GameFitText`를 재사용해 긴 단어·표현을 한 줄로 축소한다.
- 그림·물고기 원본 아트와 낚시·정답 판정 로직은 유지한다.

GPT 내장 브라우저의 합성 단어장으로 확인했다. 사용자 컴퓨터의 창이나 마우스는 조작하지 않았다.

## 단어·뜻 문제 배치 추가

- 그림 없는 문제에서는 뜻을 상단 중앙에 크게, 안내는 그 아래 작게 표시한다. 물고기는 아래 전체 폭을 사용한다. 듣기 버튼과 기존 듣기 모드도 유지한다.
- 높이가 짧은 가로 화면에서는 물고기를 한 줄에 배치해 크기를 확보한다. 그림 문제는 가로 화면의 좌우 배치와 세로 화면의 위아래 배치를 유지한다.
- 위 표의 7개 화면 크기에서 단어 문제의 중앙 정렬, 전체 폭 사용, 물고기 간 겹침 없음, 게임 영역 내 배치, 가로 넘침 없음을 GPT 내장 브라우저로 확인했다. 긴 뜻은 390×844에서도 카드 안에서 줄바꿈된다. 자료를 다시 선택하면 원본 뜻으로 복원되는 것도 확인했다.
- 그림 문제는 1440×810에서 그림 왼쪽·물고기 오른쪽 2×2, 390×844에서 그림 위·물고기 아래 배치를 확인했다.
- 대상 TSX oxlint와 프로덕션 빌드를 통과했다. 이 추가 작업에서 음성 출력이나 실제 교실 시인성은 별도로 확인하지 않았다.
