# 애니메이션 에피소드의 단체수업 연결

`/videos`의 기본 목록은 개별수업과 같은 원본 29개·이야기 181개·의미 챕터 760개다. `이야기별 에피소드`에서 대표 이미지와 제목으로 고르고, 에피소드 안에서 챕터 재생바·챕터 선택·단어 선택을 사용한다. 이전 단체수업의 준비된 질문·활동 구성은 `기존 발췌 수업`에 보존했다. `내 수업 → 단체수업`에서도 에피소드 목록으로 들어갈 수 있다.

선택한 챕터·단어는 기존 단체수업 편집 화면의 새 초안으로 전달한다. 제목, 선택한 단어 소개, 영상, 상황·의도 이야기하기, 확보한 시간 지정 대사의 따라 읽기, 마지막 총정리 칠판을 만든다. 선생님이 기존 편집기로 바꾸고 저장한다. 목록 탐색·미리보기만으로 수업·학생 배정을 저장하지 않는다. 단체수업 시간 선택은 기존 30·40분을 유지하고, 개별수업의 10·20·40분 선택과 구별한다.

연속된 챕터는 하나의 영상 슬라이드에 챕터 바와 함께 저장한다. 떨어진 챕터를 골랐으면 별도 영상 슬라이드로 나누어 선택하지 않은 가운데 구간이 섞이지 않게 한다. 원본 절대 시작·끝, 선택한 챕터 제목·범위, 에피소드 ID·검수 버전·범위, 그 안의 확보된 대사를 슬라이드 JSON에 담는다. 실제 발표/학생 따라보기는 기존 `LessonSlideContent`와 `TimedVideoLesson`을 사용한다. URL을 다른 영상으로 바꾸면 이전 챕터·대사·출처는 제거한다. 100분 이후 원본 대사를 위한 세 자리 분 타임스탬프도 읽는다.

공통 목록은 `AnimationEpisodeLibrary`, 단체수업 연결은 `AnimationGroupLibrary`, 초안 생성은 `animationEpisodeGroup.ts`다. 미리보기는 실제 단체수업 렌더러를 사용하되 저장된 실행/관찰 문맥을 전달하지 않는다. 실제 저장된 수업은 기존 그룹 센서·수업 버전 경로를 유지한다. 단어/장면 추천을 원음 인용으로 바꾸지 않으며, 확보되지 않은 자막·시간·정답을 만들어 넣지 않는다. 상황 이야기하기/총정리 칠판은 교사가 이끄는 활동이며 개별수업의 자동 채점 단계와 같다고 표시하지 않는다.

검사: `node --experimental-websocket scripts/solo/check-animation-group-library.mjs ../output/animation-solo/library-full.json` (`app`에서 실행). 181개 에피소드의 전체 범위·챕터 스냅샷, 비연속 선택 시 제외 구간 미포함, 실제 단체수업 렌더러, 이전 개별수업 탭 선호보다 명시적 단체수업 경로 우선, 초안 열기, 메모리 DB의 명시적 저장과 영상/출처 보존, 미리보기 수집·자동 배정 없음. 실제 외부 영상 재생 확인과 격리 기능 검사를 구별한다.
