### 서버 API와 저장소

- `admin_learning_research(p_days int, p_academy uuid)`: 7/30/90일에 **생성된 계획**의 배정 집단을 추적한다. 그 이후의 결과도 포함하므로 기존 수집 현황의 최근 N일 이벤트 수와 직접 비교하지 않는다.
- `admin_learning_research_decide(...)`: 검토 영역과 방향(원인 점검 / 비교 검증 준비 / 변경 보류), 선택적 메모와 당시 집계 근거를 보존한다. 학생 배정·수업·간격을 수정하지 않는다.
- `admin_learning_research_decisions(...)`: 정확히 같은 기간/학원 범위의 최근 25건. 저장 후 학생이 더 학습해도 과거 근거는 변경되지 않는다.
- `learning_research_decisions`: RLS 및 직접 접근 권한 차단. authenticated RPC 안에서 `is_platform_admin()`를 매번 검사한다. 일반 교사·학생은 접근할 수 없다.
- 저장 시 클라이언트의 임의 수치를 받지 않는다. 서버가 집계를 다시 계산해 검토한 `evidence_hash`와 비교한다. 달라졌으면 `research_changed_refresh`. 같은 요청 ID의 재시도는 기존 기록을 반환하고 다른 내용의 재사용은 거부한다.
- 저장 응답이 유실되면 화면이 입력과 범위를 고정하고 **같은 요청으로 저장 확인**을 제공한다. 이력 갱신만 실패한 경우 저장 실패로 오인해 새 요청을 만들지 않는다.
- 재시도 요청은 메모리에만 있다. 페이지를 닫았다면 저장 이력을 확인한 뒤 다시 결정한다. 학생 열쇠나 응답 원문은 보고서/브라우저 추가 저장소에 넣지 않는다.

## 지표 해석

- 분석 단위는 배정 내 단어 목표다. 한 학생의 여러 단어와 반복 배정은 독립된 학생들이 아니다. 전체/집단별 서로 다른 학생 수를 별도로 표시한다.
- 진단 정답/오답/미상 집단을 분리한다. 미시작과 진단 누락은 오답으로 넣지 않는다.
- 독립 확인 첫 답과 제한된 재학습 후 최종 초기 확인을 분리한다. `learning_path_checks(round=0)`는 재학습을 포함할 수 있어 첫 답을 대체하지 않는다.
- 지연 확인 정답률 = 정답 / 실제 응답. 참여율 = 응답 / 기한 도래. 미응답, 기한 전, 아직 예약 전을 구분한다. 첫 지연 확인을 늦게 마쳤다면 두 번째 확인이 최소 다음 날로 예약되는 현재 규칙을 반영한다.
- 실제 경과 일수는 해당 단어의 초기 확인과 지연 확인 시간 차이로 계산한다. 1일/7일은 검증된 최적값이 아니다.
- 첫 답·연습 응답은 올바른 배정/학생/학원/위치와 고정 스냅샷에 연결된 서버 채점만 사용한다. 미연결/불일치는 품질 지표로 드러낸다.
- **재접속은 새 delivery run을 만든다.** 최신 `state.run_id`만으로 과거 기록을 찾지 않는다. 같은 배정의 `learning_solo_versions.snapshot_id`에 연결된 모든 실행을 합친다. 활동 센서가 있는 배정 수는 run 수를 학생 수처럼 중복 계산하지 않는다.
- 화면 노출은 집중·순수 학습 시간이 아니며 탭 간 중복이 가능하다. 센서가 없으면 시간/도움이 0이라는 뜻이 아니다. 외부 도움·실제 교사 개입은 미상이다.
- 교사 추천 처리/방식 변경은 교사 선택 기록이며 학습 효과와 구분한다.
- 버전 표는 고정된 제공 내용 지문 + 진단 집단별 결과다. 사례 수 순 최대 30행이며 정답률 순위가 아니다. 학생·단어·난도·교사 차이를 보정하거나 무작위 배정한 비교가 아니다.
- 새 단어/새 상황으로의 전이는 미측정이다. 현재 지연 확인은 같은 단어를 다시 묻는다.

## 성능과 범위

응답을 목표별로 반복 전체 스캔하지 않고 첫 응답/연습 수를 먼저 집계한다. 계획 생성 시각, 배정의 실행/스냅샷, 센서 run 연결 인덱스를 추가했다. 그래도 대규모 실데이터의 지연·메모리 부하는 아직 벤치마크하지 않았다. 수십만 학생 운영 전에는 학원/기간별 부하 검사와 배치 집계·캐시 도입을 검토한다. 학원 선택 목록은 최대 200개이며 규모 확장 시 서버 검색/페이지화를 추가한다.

교사 개인의 역량 점수, 학생의 성격·집중력 점수, 통계적 유의성/처치 효과 추정, 실제 비교 실험 배정·실행은 이번 범위에 포함하지 않는다. 자동 점검 제안은 현재 누락·분모·첫/최종 확인을 읽고 검토 과제를 제안한다.
