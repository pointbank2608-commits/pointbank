# Sentence Splash 문장 불러오기·수업 저장 수정

2026-10-25. 로컬 수정·검증 완료. 아직 커밋·배포하지 않았다. 앞서 진행한 파닉스 목록·워크북 UI 변경은 그대로 유지한다.

## 재현한 원인

- C반의 내 수업에 템플릿 없는 Sentence Splash 블록을 연다.
- 문장 목록에서 두 문장을 가져와도 게임 템플릿을 만들거나 연결하지 않고, 편집기 내부 상태에만 추가했다.
- 기본 샘플 7개도 남아 편집기에는 9개가 표시됐다. 이때 수업 저장을 누르면 블록의 `templateId`가 비어 있었다. 다시 게임을 열면 샘플로 시작했다.
- 별도의 새 게임 저장도 편집기 최신 입력 대신 마지막 적용 템플릿을 복사했다. 직접 수정하거나 가져오기 직후 저장 시 다른 내용이 저장될 수 있었다.
- 내 수업 상단의 문장 목록 선택기는 문장 배열하기에만 연결되어 있었다.

## 수정한 동작

- 목록·문장 은행·붙여넣기 가져오기는 기존 저장 API로 즉시 적용한다. 새 수업 내 게임이면 해당 반의 템플릿을 만든 다음 기존 `GameEmbedContext`를 통해 수업 블록에 연결한다.
- 수정하지 않은 기본 7문장만 있는 경우에는 저장된 게임인지와 관계없이 새 문장으로 교체한다. 이미 맞춤 문장을 가진 게임은 해당 문장을 유지하고 중복 문장을 제외해 추가한다.
- 새 게임 저장은 편집창의 최신 문장·순서·제한 시간을 사용한다. 원본 템플릿을 덮어쓰지 않는다.
- 게임 항목과 `classroomSource.cards`, 제한 시간을 같은 함수로 구성해 실행과 다른 게임 재사용에 전달되는 내용이 일치하도록 했다.
- 저장 중 조작을 막고, 실패하면 입력을 유지해 재시도할 수 있게 했다. 비어 있거나 두 단어 미만인 문장은 새 게임 저장을 막는다.
- 내 수업의 문장 목록 선택을 Sentence Splash에도 제공하고, 기존 변환 함수를 사용해 게임을 생성한다. 문장 배열하기의 경로도 같은 방식으로 검증했다.

## 검증

- `app/scripts/games/check-splash-lesson-save.mjs --reproduce`: 수정 전 실제 앱에서 C반 모의 수업 오류 재현. 편집기 9문장, 저장 템플릿 0개, 수업 게임 참조 누락을 기록했다.
- 같은 스크립트의 수정 후 검증: 문장 불러오기 즉시 저장, C반 귀속, 수업 저장·재열기, 최신 입력·60초 설정으로 새 사본 저장, 원본 보존, 저장 실패·입력 유지·재시도, 수업 문장 목록 선택, 발표 실행, 새로고침 재실행, 기존 저장 샘플 재불러오기, A반 자료 불변, 문장 배열하기 회귀 검증 통과.
- 실제 게임 벽돌이 샘플이 아닌 가져온 첫 문장의 단어로 구성되는지 확인했다.
- 기존 `check-splash.mjs` 통과: 축약형·문장부호·중복 단어·판정·4개 시간 옵션·효과음·일시정지·실패·재도전·7라운드 완주·1440/768/390px·편집/정렬/삭제/사본 저장/새로고침·게임 목록·학생 화면.
- 기존 테스트의 편집기 진입은 현재 UI에 맞게 독립 편집 화면 fixture를 사용하도록 갱신했다. 중복 제거 검증과 충돌하지 않도록 붙여넣기에는 서로 다른 문장 두 개를 사용했다.
- TypeScript·Vite 프로덕션 빌드·수정 게임 파일 lint 통과. 브라우저 예외 없음. 빌드의 기존 큰 번들 경고는 남아 있다.
- API는 상태를 유지하는 로컬 모의 응답으로 검증했다. 운영 C반 자료를 직접 수정하거나 SQL을 실행하지 않았다.

결과: `output/splash-lesson-save/reproduction.json`, `checks.json`, `saved-lesson-playing.png`.

## 주요 파일

- `app/src/pages/SentenceSplashPage.tsx`: 불러오기 즉시 적용, 새 템플릿 저장·연결, 최신 편집값 저장, 실패 시 입력 유지.
- `app/src/lib/sentenceSplash.ts`: 기본 샘플 판별, 현재 문장·제한 시간·공통 자료 정보 구성.
- `app/src/components/LessonSlideSorter.tsx`: Sentence Splash 문장 목록 제공, 기존 문장 변환 재사용.
- `app/src/i18n/locales/ko.ts`, `en.ts`: 가져오기·저장 안내.
- `app/scripts/games/check-splash-lesson-save.mjs`, `check-splash.mjs`, `splash.tsx`: 재현 및 회귀 검증.

## 기존 수업에서 사용할 때

배포 후, 샘플로 잘못 저장됐던 수업은 문장 목록을 한 번 다시 불러와 적용 완료를 확인한 뒤 수업을 저장한다. 기존의 적용되지 않은 입력은 서버에 없으므로 자동으로 복원하지 않는다. 이미 정상 저장된 맞춤 문장이나 다른 반 자료를 일괄 변경하지 않는다.
