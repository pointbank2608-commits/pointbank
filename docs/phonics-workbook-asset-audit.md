# 완성 워크북 자산 현황

완성 워크북은 컬러 그림과 별도 선화를 모두 갖춘 경우에만 기존 6가지 활동으로 제공한다. 읽기·쓰기 대체 템플릿은 사용하지 않는다.

| 단어 | 부족한 자료 | 영향받는 유닛 |
|---|---|---|
| them | color, lineart | th-voiced-b |
| then | lineart | th-voiced-b |
| term | lineart | r-er-a |

them: 대명사의 목적격을 정확히 드러내는 컬러 장면 검토 필요. then: 현재 단일 장면으로 시간 순서가 드러나지 않음. term: 학교 건물 그림만으로 학기 의미가 불명확함. 이 세 항목은 임의 선화를 제작해 완료 처리하지 않았다.
