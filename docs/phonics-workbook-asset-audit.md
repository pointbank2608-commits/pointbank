# 4·5단계 워크북 자산 조사 및 보완 목록

공통 단어 ID·표기·대소문자·실제 파일 경로를 대조했다. 정확한 단어명으로 존재하지만 연결되지 않은 컬러·선화 파일은 0개다. brush는 기존 솔/빗 그림에 맞춰 공통 뜻을 ‘솔, 빗’으로 바로잡았다. 기본 단어·순서·ID는 유지했다. blank/blink는 사전 컬러 그림에 연결되어 있으며 선화만 없다. clam/glob/glum에는 대응 그림이 없다. shell/globe처럼 철자나 의미가 다른 자산은 대신 사용하지 않는다.

파일이 없다는 이유로 단어를 변경하지 않는다. 자산 부족은 활동 대체로 처리하며, 아래 자료는 원래 그림 활동을 복원할 때 제작할 목록이다.
