# 클래스뱅크 문법 게임 조사·추천 · 2026-11-03

이번 작업은 온라인 조사와 코드 비교다. 새 게임을 구현하거나 사이트에 등록하지 않았다. 해외 서비스의 공식 설명·수업 활동 안내를 확인했으며 모든 게임을 직접 끝까지 플레이한 검수는 아니다. 아래 게임 이름·교실 흐름·개발 단계는 클래스뱅크를 위한 제안이다.

## 현재 코드에서 확인한 출발점

- `app/src/data/grammarPoints.json`: 문법 항목 169개, 예문 848개. 초등 55·중등 55·고등 31·품사 9·시제 13·문장 형식 6개 항목. 단계 사이 개념 중복을 제거한 서로 다른 규칙의 수라는 의미는 아니다.
- 166개 항목에 pitfalls(오문·정문·이유), 64개 항목에 안전한 단어 치환용 slots가 있다. 필드 존재가 곧 게임용 문제 검수 완료를 뜻하지 않는다.
- `app/src/lib/adventureGames.ts`의 문법 탐정은 오류 구간 선택/직접 수정·복수 정답·해설을 지원한다. 같은 기능을 새 이름으로 다시 만드는 것보다 기존 문법 데이터 연결을 우선한다.
- 단어 기차·문장 로켓·문장 배열·Sentence Splash·문장 다리·문장 탑, 기존 퀴즈·분류·매치업·장보기·무지개 문법도 활용 가능하다. 문법 데이터를 고르는 연결과 문법별 문제 구성이 핵심이다.

## 우선 추천

먼저 기존 문법 탐정에 문법 기준표를 연결하고, 문장 변신 연구소·질문 제작소·전치사 방 꾸미기를 대표 신규 샘플로 만드는 편이 좋다. 각각 오류 수정, 문장 구조 변화, 질문의 목적, 공간적 의미라는 서로 다른 학습을 보여 준다. 팀 복습은 문법 경매로 보완한다.

게임의 공통 진입은 ‘문법 선택→게임 선택→문제 미리보기→시작’으로 설계한다. 처음에는 ‘고르기→바꾸기→직접 만들기’ 중 가능한 모드만 보여 준다. 문법 설명 카드와 한 줄 해설, 재도전, 수업 삽입은 기존 기능과 연결한다. 모든 게임을 모든 문법에 억지로 적용하지 않는다.

## 자동 제작 전 필요한 데이터

1. 공통 grammarId를 유지한다. 화면별 문법 목록을 복제하지 않는다.
2. 기존 예문·뜻·pitfalls·slots를 먼저 활용하고 게임용 정보만 별도로 보충한다.
3. 변형 문제에는 원문/변형 종류/정답/허용 답/변경 구간, 질문에는 질문 대상 정보, 품사에는 문맥별 역할, 장면에는 사물과 위치 관계가 필요하다.
4. 예문만으로 시제·수동태·부정·의문을 일괄 자동 변환하지 않는다. 불규칙·부정어·다중 문법·의미 변화는 검수한다.
5. 문법은 맞아도 의미가 다른 답, 같은 뜻의 복수 표현, 축약형, 구두점 처리를 게임마다 정의한다. 말하기 활동을 자동 문법 채점한다고 약속하지 않는다.
6. 사용자가 단어장을 바꾸어도 품사·가산성·동사 활용·문형 조건을 지킨 범위만 대체한다. 현재 slots 64개가 이 안전한 출발점이고, 다른 항목은 추가 검수가 필요하다.

외부 사이트의 작동 원리와 수업 방식을 참고해 자체 문제·문구·그림·화면으로 제작한다. 위 서비스의 이미지·캐릭터·문제은행을 그대로 가져오거나 외부 페이지를 임베드한 것만으로 자체 게임 제작 완료라고 하지 않는다.
