# 초등 800단어 워크북 → 단어장·게임·수업

## 사용

활동지 → 초등 800단어 → 품사별 교재에서 레벨을 선택한다. 선택 바로 아래에서:

- **단어장으로 저장**: 레벨별 저장이 기본. 여러 레벨을 선택하면 합치기도 가능하다. 새 자료는 학원 공용 단어장으로 만든다.
- **이 단어로 게임하기**: 계정·학원으로 범위를 제한한 기존 `quickSource`로 게임 목록에 전달한다. 호환성과 최소 개수는 기존 게임 목록에서 안내한다. 단어장·게임·반·수업을 자동 저장하지 않는다. 게임 목록의 카드가 계정 검사를 통과한 자료를 기존 `guideLaunch`에도 전달해 준비 창의 내용 확인 단계에서 이어진다.
- **수업에 추가**: 기존 `AddActivityToLesson`을 재사용한다. 기존 수업을 고르거나 새 수업을 명시적으로 확인한 후 돌림판 활동의 스냅샷을 추가한다. 단체수업 기능이 꺼진 학원에는 표시하지 않는다.

원본 동사편에서는 Level 1–4 라디오 선택을 사용한다. 후속 PDF Level 5–7 카드에는 해당 레벨의 재사용 화면으로 가는 링크가 있다.

## 데이터

`Elementary800Actions.tsx`와 `elementary800Sources.ts`가 선택한 워크북 항목을 변환한다. 단어 순서·뜻·그림·품사·분류·예문을 보존한다. 저장 항목의 ID는 새로 부여한다. 기존 `word_lists.items` JSON에 선택적 `example`을 보관하므로 SQL 변경은 없다. `wordListToCards`와 카드 학습은 저장 예문을 먼저 사용하고, 이전 자료는 기존처럼 사전 예문을 보완한다.

중복 검사는 같은 학원의 단어장만 대상으로, 순서와 모든 저장 내용이 같은지 비교한다. 단순히 이름이 같다고 수정하지 않는다. 동일 이름의 수정된 자료가 있으면 번호를 붙인 새 자료를 만든다. 여러 레벨 저장 중 실패하면 성공한 자료는 남기고 재시도 시 다시 조회하여 재사용한다. 중복 클릭은 ref로 차단한다. 계정·학원·선택 레벨이 바뀌면 모달과 결과를 폐기하고 후속 저장 루프를 중단한다.

## 확인한 제약

- 원본 PDF Level 1–4는 단어 순서를 보존하지만, 디지털 뜻·그림·예문은 현재 사전에서 가져온다. PDF 원본의 모든 표현·그림을 추출한 자료가 아니며 화면에도 안내한다. 원본 선택의 단어가 하나라도 없으면 불완전한 단어장 생성을 막고 재시도를 제공한다.
- 중복 방지는 현재 조회 결과를 이용한다. 서로 다른 탭에서 정확히 동시에 저장하는 경우까지 원자적으로 보장하는 DB 고유 키는 추가하지 않았다.
- 수업 추가는 기존 동작인 돌림판 활동 추가다. 별도 게임을 고르려면 먼저 ‘이 단어로 게임하기’를 사용한다.
- 검증은 합성 API로 수행했으며 운영 계정의 실제 저장 자료는 변경하지 않았다. 사용자 요청으로 해당 기능을 선별 커밋·푸시하고 main 자동 운영 배포를 진행한다.

## 검증

`node app/scripts/materials/check-elementary800.mjs` — 실제 React 구성과 로컬 합성 API로 확인:

- 품사·레벨 정렬, 원본 100개 순서, 사전 원본 비변경
- 학원·문장 자료 제외, 수정된 자료 중복 판별 제외
- 레벨별·합본 저장, 순서/뜻/그림/예문 일치, 기존 단어장 화면 재진입
- 중복 저장과 부분 실패 후 재시도
- 저장 없이 50개 단어를 기존 돌림판 준비 창으로 전달 → 내용·참가자 확인 → 실제 플레이 진입, 자동 서버 저장 없음
- 기존·새 수업은 확인 후에만 추가, 활동에 25개 원본 단어 보존
- 원본 Level 2의 25개 순서로 저장
- PDF 인쇄 회귀, 모바일 가로 넘침, 영어 전환, 자료 로딩 오류

`npm --prefix app run build`(타입 검사 포함), `npm --prefix app run lint`도 실행했다. 기존 린트 경고는 남아 있다. 캡처: `output/elementary800-reuse-desktop.png`, `output/elementary800-reuse-mobile.png`.
