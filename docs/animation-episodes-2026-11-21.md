# 원본 → 에피소드 → 의미 챕터

## 최신: 원본 음성·프레임으로 경계 재검수 — 2026-11-21

**29개 원본 전체 13시간 53분 17초 → 181개 이야기 → 760개 의미 챕터**로 보정했다. 아래 169/670 및 20초 오차 안내는 이번 보정 전 기록이다. 재생 제한으로 제외한 6개 원본은 계속 제외한다.

- 공개 원본의 영상과 음성을 실제로 읽어, 절대 원본 시간을 표시한 AV 클립으로 전환 전후를 대조했다. 화면 컷·무음·페이드 후보는 원본 프레임의 PTS를 사용한다. 외부 URL에 시작 시간을 써서 전달한 분석이나 20초 샘플의 반올림 시간을 게시하지 않는다.
- 카이유 스케이트→부활절 `306 → 305.722`, 새해 파티 `630 → 625.333`, 요새 만들기 `940 → 931.389` 등 도입부가 빠진 경계를 수정했다. 세서미는 주제가 앞의 콜드 오픈을 보존하고 실제 와이프 화면에서 나눈다. 원본 EOF도 실제 미디어 길이로 맞췄다.
- 긴 블루이 모음 두 개의 합쳐진 이야기와 빠진 전환을 찾아 **54편 / 53편**, 다른 모음은 7편으로 나눴다. 반복 로고는 원본 프레임으로 찾되, 같은 이야기 안의 재등장 로고와 마지막 종료 로고는 별도 에피소드로 만들지 않는다. 구분이 바뀐 이야기의 단어·표현과 대표 이미지도 해당 내용으로 다시 연결했다. 안정적으로 대응되는 기존 에피소드 ID는 유지했다.
- **115개 이야기(블루이 114개와 카이유 장기자랑 1개)**는 해당 이야기 전체 AV를 기준으로 의미 챕터를 다시 만들었다. 나머지 **66개 이야기의 내부 경계 258개**는 개별 원음 클립으로 재확인했다. 대화·노래가 이어져 안전한 분리 지점이 없는 곳은 한 문맥으로 합쳤다. 마지막 커튼을 독립 수업 챕터로 오인하던 장기자랑 편은 전체를 다시 대조해 세 문맥(학교에서 소식 듣기 / 집에서 장기를 찾고 배우기 / 연습을 마치고 공연하기)으로 묶었다. 30.4초의 실제 화면 컷과 190.722초의 무음 구간에서 나누어 알려진 대사 한가운데를 자르지 않는다. 첫 내레이션의 이어지는 When 절도 앞 문장과 합쳐 쉐도잉·총정리 문제에 완결된 문장이 나오게 했다.
- 모든 원본은 0초부터 실제 끝까지, 모든 챕터는 소속 이야기의 처음부터 끝까지 빈틈·겹침 없이 연결된다. 단어는 확보한 대본 근거와 상황 연습용 추천을 계속 구별한다. 새로 만든 제목은 내용 요약 제목으로 표시하고, 추측한 원음 자막·문장 시간을 만들지 않는다.
- 에피소드 재생은 YouTube의 `startSeconds`와 `endSeconds`를 재생·재재생·재생 중 챕터 이동마다 다시 적용한다. 끝으로 탐색할 때 다음 이야기의 첫 프레임에 걸리지 않게 끝 직전으로 제한했다. 보정된 자료로 새로 저장하는 수업은 출처 버전 `v2`다. 기존에 저장·배정된 수업 내용은 이 카탈로그 수정으로 자동 변경하지 않는다.

검증 근거의 압축 기록: [animation-boundary-review-v2.json](animation-boundary-review-v2.json). 원본 미디어·원음 클립·분석 응답은 git에서 제외한 `output/animation-solo/boundary-review/`에 둔다. 모델을 이용한 AV 대조와 대표 브라우저 검사를 수행한 것이며, 29개 원본 전체를 사람이 연속 청취했다는 뜻은 아니다. 원본 업로더가 이미 짧게 편집해 수록한 이야기는 그 수록 분량을 보존한다.

타입 검사, Vite 빌드, 변경 코드 lint, 기존 단체수업 영상 흐름·질문 회귀 검사 통과. 격리 브라우저에서 181개 이야기·대표 이미지·범위·챕터 연결·단어 근거를 검사했고, 긴 원본 9개 각각의 챕터 이동·선택·저장, 학생 미리보기 게임→총정리, 미리보기 수집/자동 배정 없음, 모바일 가로 넘침 없음을 확인했다. 실제 YouTube에서는 카이유 부활절의 시작·챕터 이동·끝 정지·처음부터 재재생과 새 블루이 이야기의 원음·챕터·단어 선택을 확인했다. 운영 배포 후 확인 결과는 별도 릴리스 기록으로 남긴다.

재검수 절차는 `prepare-boundary-media.mjs` → `index-boundary-cuts.mjs` → `review-media-boundaries.mjs` / `verify-boundary-points.mjs`, 블루이 전환 탐색은 `find-bluey-logo-frames.py` → `refine-bluey-logo-frames.py`, 전체 이야기 의미 구분은 `build-av-episode-contexts.mjs`, 게시 조립은 `assemble-av-catalog.mjs`다. 미완료·위험 경계가 있으면 조립이 실패한다. `CATALOG_DRAFT=true`는 로컬 후보 확인에만 사용한다. 썸네일은 `render-av-episode-thumbnails.mjs`로 실제 원본 프레임에서 만든다. 기존 거친 샘플 컴파일러는 v2 자료를 명시적 예외 없이 덮어쓰지 못하도록 막았다.

- 35개 원본의 공식 챕터와 공개 설명을 확인했다. 세서미 스트리트 모음 2개에서 공식 에피소드 8개, 단일 에피소드로 올라온 카이유 원본 20개를 카탈로그에 넣었다. 총 28개 에피소드 카드. 이는 긴 원본 전부를 분리 완료한 수가 아니다.
- 공식 내부 챕터가 있는 카이유 7개 에피소드에 34개 구간이 있다. 다른 에피소드는 의미 챕터 준비 중으로 표시하고 전체 에피소드만 재생한다.
- `카이유와 벌`은 기존 시간 지정 대사를 대조해 4개 구간에 소통 의도 설명을 추가했다: 안심시키기, 아픔 전달과 도움, 설명으로 오해 풀기, 허락 요청과 질문.
- 모음 영상 2개의 에피소드 대표 이미지 8개는 실제 원본 스토리보드의 해당 구간 프레임을 추출하여 저장했다. 동일 원본 표지를 모든 에피소드에 반복하지 않는다. 단일 에피소드는 원래 영상의 표지를 쓴다.
- `PlainTeachingVideo`의 선택적 `chapters`가 재생바의 구간 버튼을 그린다. 이 모드에서는 탐색 값과 표시 시간이 에피소드 상대 시간이다. 실제 YouTube 탐색은 원본 절대 시간으로 변환한다. 끝 시간에서 재생을 멈추는 기존 로직을 재사용한다.
- 단어·표현은 **현재 확보된 대본**에서 근거를 찾은 항목만 모은다. 원본 전체 대본을 새로 확보한 것은 아니다. 자료가 없는 에피소드는 0개와 준비 중 안내가 나온다. 단어 하나가 여러 챕터에 나오면 하나의 항목에 여러 챕터를 연결한다. 챕터 전환으로 해당 단어 모음을 볼 수 있고 체크는 유지된다.
- 선택한 단어는 명시적 버튼으로 기존 `word_lists`에 저장한다. 선택한 챕터·단어로 기존 단어·문장·게임 구성기, 학생 미리보기와 최종 확인 문제를 재사용한다. 학습 자료가 없는 에피소드의 수업 만들기는 막고 영상 재생만 제공한다. 학생 자동 배정은 하지 않는다.

## 자동 분석을 게시하지 않은 이유

공식 에피소드 구분이 없는 긴 원본 13개는 분리 검수가 남아 있다. 기존 Vertex 영상 분석 절차를 사용해 7개 원본의 초안을 받았지만, `O37zFRCQhEQ`의 실제 첫 이야기(스케이트)를 Christmas로 잘못 이름 붙이고 경계를 대략적인 시간으로 반환했다. 원본과 맞지 않는 결과를 확인한 뒤 나머지 실행을 중지했다. 이 JSON은 `output/animation-solo/episode-analysis/`의 검수 전 자료일 뿐 앱 카탈로그에 들어가지 않는다. 현재 코드는 공식 챕터/확인된 단일 에피소드만 게시한다.

13개 원본은 원본 화면·소리와 대사 근거를 함께 대조해 제목 및 에피소드 경계를 새로 검수해야 한다. 모음의 반복 에피소드·원본 자체의 발췌·인트로/아웃트로도 구분해야 한다. 모든 원본의 에피소드 분리, 모든 에피소드의 의미 챕터, 전체 대본·단어장·문맥 이해 문제 생성이 끝났다고 보고하면 안 된다.
