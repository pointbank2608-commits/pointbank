# 텔레파시 참여 방식과 안내 대비 수정

- 원인: 공통 반 설정의 개인/팀 선택과 달리 텔레파시 본체는 항상 `telepathyTeams`개 팀으로 점수판과 결과를 만들었다.
- `telepathyMode`를 게임 설정에 저장하고 본체에 참여자를 전달한다. 개인은 반의 출석 학생 이름(반 없이 개인은 ‘나’), 팀은 팀·순서 정하기의 이름과 순서, 없음은 점수판과 정답자 선택을 숨긴다. 기존 설정에 mode가 없으면 공통 반 설정을 따른다.
- 점수판·맞힌 사람/팀 선택·리모컨·결과 순위 모두 같은 참여자 목록을 사용한다. 참여 방식이나 명단이 바뀌면 진행 점수를 초기화하여 다른 사람에게 점수가 이어지지 않는다.
- 알 열기 옆 안내에 불투명한 밝은 바탕과 진한 글씨를 적용한다. 개인·없음에는 ‘팀마다’ 대신 각자 적도록 안내한다.

검증:

- `node app/scripts/games/check-telepathy-participation.mjs`: 반 없이 개인 설정 후 새로고침, 반 학생 3명/결석 제외 후 2명, 개인 정답 점수와 순위, 저장한 수업을 다시 열어 발표, 사용자 지정 팀 이름·순서, 점수 없음 전환, 안내 색 대비 7:1 이상.
- `check-telepathy.mjs`: 기존 팀 점수/순위, 후보와 동물 중복 방지, 시간 제한, 390/768/1440px 화면.
- `FIT_TYPES=telepathy`의 `check-game-viewport-fit.mjs`: 일반·전체화면·수업 발표의 게임판 및 버튼 경계.
- 앱 프로덕션 빌드.

센서 계약: 기존 공통 센서를 유지한다. 게임의 선생님 수동 점수는 서버 채점 근거나 학습 성취로 바꾸지 않는다. 자동 답변 검증은 인증/API를 격리하고 센서를 끈 로컬 fixture에서만 수행한다.
