# 파닉스 수업 슬라이드 구현과 검토

## 확인 위치와 공개 상태

- 개발 서버: `/phonics?tab=course` → 레벨 → 수업용 유닛 → 1차시 / 2차시 / 추가 활동.
- 직접 미리보기: `/phonics/lesson?unit=course-4-1&lesson=1`.
- 레벨 1–5 전체 42유닛(9 / 8 / 8 / 8 / 9), 워크북 기준 376학습 항목. 같은 단어가 다른 규칙에 등장하는 항목은 별도로 센다. 컬러 파일은 단어별로 공유한다.
- `PHONICS_TEACHING_PREVIEW = import.meta.env.DEV`를 유지한다. 운영 빌드에는 수업 탭을 노출하지 않고 직접 URL도 검토 중 안내로 제한한다. URL 파라미터로 제한을 해제할 수 없다.
- 사용자의 커밋·푸시·배포 지시에 따라 이 변경을 별도 커밋으로 반영한다. 코드 배포와 수업 콘텐츠 공개는 구분하며, 개발 미리보기 제한은 유지한다. 운영 DB 변경은 없다. 다른 진행 중인 워크북·숙제 작업은 이 범위와 구분한다.

## 편성·문장 데이터

- [전체 편성표](phonics-lesson-plan.md): 규칙별 단어·순서·단어 수·차시별 슬라이드 수.
- [유닛별 사이트워드·읽기 문장](phonics-reader-drafts.md): 기존 확정과 초안 구분, 새 사이트워드와 복습 단어.
- `src/data/phonics/teachingPlan.json`에는 규칙 ID와 필요한 패밀리 이름만 저장한다. 공통 단어표를 복사하지 않는다. `courseUnits()`가 기존 `PHONICS_UNITS`의 순서와 공통 단어·그림·음원 정보를 해석한다.
- 레벨 3과 레벨 5의 9유닛 편성은 2026-10-26 사용자 답변으로 확정됐다. 레벨 2는 모음 구간을 넘지 않고 3패밀리씩 묶으며 남는 패밀리를 생략하지 않는다.
- 기존 ABC 문장과 레벨 4 Unit 1 문장은 유지한다. 나머지 40유닛은 사용자가 승인한 **초안 작성** 범위이며 최종 콘텐츠 승인과 다르다. 새 사이트워드는 유닛당 1개, 문장 어휘는 해당 유닛 또는 앞서 학습한 단어만 사용한다.
- 초안 읽기 구간마다 `문장 검토 중` 표시를 한다. 단어 학습 완료와 문장 최종 승인을 섞어 표시하지 않는다.

## 재사용한 수업과 활동

- 기존 `buildStage1Course`의 ABC 수업을 변환해 사용한다. 대소문자·그림·대표 단어·전체 단어·쓰기·그림자·Missing·읽기 흐름을 유지하며, 최신 지시에서 제외한 Your Turn은 복원하지 않는다. 종료 슬라이드를 포함해 98단계이다. 기존 저장 참조와 옛 수업·8쪽 교재 라우트는 보존한다.
- 첨부 `ClassBank_Level4_Unit1_FullSlides_v2.pdf` 137쪽을 이미지로 모두 확인했다. 레벨 4 Unit 1은 1차시 69단계, 2차시 47단계, 추가 활동·종료 21단계의 같은 흐름으로 재구성했다. 단어·제목·강조는 HTML이며 PDF 전체 페이지를 배경으로 쓰지 않았다.
- 첨부 PDF의 같은 읽기 장면에서 그림 부분만 추출했다. 고정 장면에서 빨간 화살표와 문장만 바꾼다. 검은 블록이 필요한 확인 문항은 해당 장면에서 추출한 검은 블록을 사용한다. 학습 단어 block의 공통 컬러 그림을 덮어쓰지 않는다.
- 시안과 공통 컬러 그림이 다른 경우, 현재 뜻과 일치하는 공통 그림을 우선한다. 예를 들어 black은 현재의 검은 고양이 색상 그림, club은 현재 기준 뜻인 모임 그림을 쓴다. 질문·정답의 보기 위치는 고정하지만 시안의 보기 섞기 순서까지 그대로 복사한 것은 아니다.
- 레벨 2·3과 나머지 유닛은 현재 공통 규칙과 승인 편성으로 확장한 수업이다. 이번 첨부에서 레벨 2·3·5 최신 최종 PDF는 확인되지 않아, 그 파일들과 디자인·게임 흐름이 완전히 동일하다고 주장하지 않는다. 전체를 개발 검토 상태로 제공한다.
- `Stage1Word`, `Stage1Picture`, `Stage1Speaker`, `Stage1Lines`와 기존 슬라이드 스타일을 공통 활동에서 재사용한다. 글자·문장·그림은 각각 교체할 수 있다. 새 패키지·DB 스키마는 추가하지 않았다.

## 활동과 진행

- 소리·대표 단어 → 소리 합치기 → 규칙별 전체 단어 → 연결·구별·듣기 → 복습 → 전체 단어 쓰기 → 규칙 글자 완성·분류 → 사이트워드·문장 → 차시 종료.
- 레벨 2는 워드 패밀리를 구별한다. 단순 첫소리 구별로 대체하지 않는다. e·i·o·u로 넘어가는 첫 유닛에는 모음 전환 안내가 있다.
- 자음군은 두 소리를 유지하는 안내와 분해 예시를 사용한다. sh·ch·th 같은 이중자음 및 ee·ea 등은 목표 글자 묶음을 하나로 유지한다. 매직 e는 떨어진 모음과 e의 위치를 유지한다. th·oo·ow의 다른 발음은 서로 다른 규칙 ID로 유지한다.
- 연결 문제의 그림 순서와 위치는 문제·정답에서 고정한다. 정답 단계에 번호만 더한다. 쓰기는 규칙별로 기존 인쇄 소유닛 크기에 맞춰 나누며 모든 기본 단어가 포함된다.
- 레벨 4·5 퍼즐은 흩어진 조각 → 모이는 조각 → 완성 그림과 단어, 단어 기억은 단어 → 가림 → 그림과 단어 순서다. 자동 정답 공개는 없다. 다시 보기·이전·다음·키보드·큰 화면·수업 선택 복귀를 제공한다. 추가 활동 없이도 각 차시는 종료된다.
- 레벨 1 하늘색·2 핑크·3 초록·4 연보라·5 노랑 테두리와 아이보리 내부, 네이비 글자, 빨간 목표 글자 강조를 사용한다. 대소문자 블록은 같은 크기이다.

## 그림과 음원

- 기존 345개의 단어별 컬러 연결을 펼쳐 검토했다. `them`의 실제 누락 컬러를 새로 제작·연결했다. `burn`과 `watch`는 그림 속 정답 글자가 게임에서 노출되어 글자 없는 컬러 그림을 새로 제작했다. 원본 파일은 보존했다.
- 최종 파일: `public/phonics-images/{them,burn,watch}-course-v1.webp`. 모두 내장 image_gen 사용. 프롬프트·원본·참고 파일은 `scripts/phonics/course-artwork.json`에 있다.
- `line`은 축소본에서 선이 불명확했으나 원본 확대에서 실제 선을 확인해 유지했다. 단어·뜻을 그림에 맞추기 위해 바꾸지 않았다.
- `teachingReview.json`은 인칭·관계·추상 표현 등 문맥 설명이 필요한 단어를 표시한다. term·then·from·her·them·may 등은 그림만 보고 맞히는 퍼즐에 넣지 않는다. 교사용 안내에 이유를 표시하고, 단어 기억·학습·복습·쓰기에서는 유지한다. 준비 완료를 가짜로 표시하기 위한 단어 생략이 아니다.
- 규칙 자체의 전용 음가 녹음은 없다. 단어·문장은 기존 브라우저 영어 TTS와 기존 녹음 필드를 사용한다. 클릭 시 실제 재생 함수에 연결되어 있는지 확인하며 자동 재생·유료 음원 호출을 하지 않는다. 전자칠판 실제 하드웨어의 음량·음성 설치 상태는 별도 확인해야 한다.

## 검사 명령과 결과 위치

`app/`에서 실행한다.

```text
node scripts/phonics/export-lesson-plan.mjs
node scripts/phonics/check-lessons.mjs
node scripts/phonics/check-print-course-separation.mjs
node scripts/phonics/check-workbook-navigation.mjs
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
```

- `check-lessons.mjs`: 42유닛의 순서·참조·전체 단어 포함, 문장 미학습 어휘·사이트워드 1개, 발음 규칙 구분, 이미지 파일, 퍼즐·기억·정답 재실행, 연결 위치, 쓰기와 같은 장면 읽기, PC·모바일·큰 화면, 활동별 잘림 검사.
- `check-print-course-separation.mjs`: 알파벳 26유닛·52쪽, 선택·인쇄·기존 단어 학습과 ABC 교재 경로 유지.
- `check-workbook-navigation.mjs`: 공통 기준표·기존 유닛 ID와 2–5단계 인쇄 내용 유지. 허용한 그림 변경만 공통 자산 검사에 반영한다.
- 검사 로그와 화면은 `output/phonics-lessons/`, `output/phonics-lessons-*.log`에 저장한다. 최종 수행 결과는 실행한 로그를 기준으로 확인한다.
- 전체 검사에서 42유닛의 규칙·단어 순서, 40유닛 새 사이트워드·문장 어휘, 대표 활동의 PC·모바일·큰 화면 배치, 기존 인쇄·단어 학습 회귀 검사가 통과했다. 단어 파일·문맥 검토·녹음 누락 목록은 `output/phonics-lessons/media-audit.json`에 별도로 내보낸다. 검사는 브라우저 소프트웨어 기준이며 실제 전자칠판 하드웨어에서 실행한 결과가 아니다.

## 남은 콘텐츠 검토

40유닛 문장·사이트워드 초안 승인, 문맥 의존 그림 설명 검토, 레벨 2·3·5 최종 시안 대조, 전용 음가 녹음 확보와 실제 전자칠판 소리 확인이 남아 있다. 새 연계 워크북 전체 제작과 인쇄 메뉴 차시 구분은 이번 범위에 넣지 않았다.
