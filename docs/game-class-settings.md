# 게임 공통 반 설정

두 주사위 읽기의 반 설정을 일반 게임과 파닉스 게임에서 함께 사용한다.

- 공통 화면: `app/src/components/GameClassSettingsContent.tsx`
- 일반 게임: `GameToolbar`가 기존 반·결석·팀/순서 저장과 게임별 설정 적용을 담당한다.
- 파닉스 게임 실행 및 수업 편집: `PhonicsClassSettingsContent`가 같은 화면과 기존 `TeamOrderPanel`을 사용한다.
- 화면 순서: 반과 학생 명단 → 결석 제외 → 없음/개인/팀 → 팀 수 → 자동 넘기기 → 팀·순서 정하기 → 적용.
- 팀·순서 정하기는 출석 학생이 있고 개인 또는 팀을 선택했을 때 표시한다. 반이 없어도 마지막 설정 항목과 적용 영역 사이의 여백은 유지한다.
- 게임별 팀 수 상한과 고유 진행 방식은 유지한다. 시한폭탄·번개 피하기처럼 자체 진행을 사용하는 게임의 자동 차례 처리는 기존 방식이다.

## 파닉스 수업 저장

기존 슬라이드의 `teams`는 그대로 읽는다. 새로 반 설정을 적용하면 `PhonicsGameSlide.classPlay`에 반 ID, 참여 방식, 팀 수, 자동 넘기기, 결석 학생 ID, 팀 배정·이름·순서를 저장하고 `teams`도 함께 갱신한다. DB 변경은 없다. 수업 재열기와 발표는 저장한 설정을 사용하며, 실제 학생 명단은 기존 반 조회 API로 읽고 결석 학생을 제외한다. 다른 슬라이드를 수정하지 않는다.

파닉스 실행 화면의 다음 차례 버튼과 문제 완료 후 자동 넘기기는 같은 순서를 사용한다. 자동 넘기기를 끄면 문제를 넘겨도 지금 차례는 유지한다. 팀 이름은 차례와 점수 표시 양쪽에 반영한다. 게임 점수와 차례를 개인 학습 성과로 기록하지 않으며 기존 학습 센서 호출은 변경하지 않는다.

## 로컬 검증

가짜 API와 반 명단으로만 실행한다. 운영 계정/학습 데이터는 사용하지 않는다.

```powershell
cd app
$env:VITE_SUPABASE_URL='http://127.0.0.1:9'
$env:VITE_SUPABASE_ANON_KEY='local-fixture-only'
node scripts/lessons/check-shared-class-settings.mjs
node scripts/lessons/check-two-dice-class-settings.mjs
```

첫 검사는 등록된 일반 게임 76개와 파닉스 게임 48개의 실제 경로에서 반 설정을 연다. 파닉스는 사용 가능한 유닛을 각각 찾는다. 공통 항목·여백·체크박스 배치, 짧은 화면, 수업 저장/재열기/발표, 팀 이름·순서, 결석 제외, 슬라이드 독립성, 개인 차례와 자동/수동 넘기기를 확인한다. `CLASS_SETTINGS_DEEP_ONLY=1`이면 두 주사위와 소리 풍선 및 저장/발표 동작만 검사한다.

`CLASS_SETTINGS_SCREENSHOTS`에 외부 출력 폴더를 지정하면 파닉스 공통 설정 화면을 저장한다. 파닉스 게임 전용 label/font 스타일은 공통 설정 패널에 적용하지 않는다.
