# 파닉스 게임 효과음

2026-10-28 사용자 요청: 40종 전체의 조작·장면·성공 효과음을 먼저 연결한다. 배경음악과 개별 파닉스 음가 녹음은 이번 작업에 포함하지 않는다. 향후 음가 녹음은 공개 음원 수집 → 이용 조건 확인 → 우리 수업 규칙에 맞춘 검수 방식으로 진행한다.

## 동작

- 시작, 버튼·카드 선택, 글자 조각 놓기, 부분 짝 맞추기, 다시 시도, 정답 장면, 짧은 성공음, 다음 문제, 최종 완료에 연결한다. 글자 길 그리기도 교사가 완료를 확인한 뒤 장면·성공음을 재생한다.
- 40종 모두 `phonicsSoundProfile()`에서 기존 `phonicsGameVisuals.ts`의 세계·동작·소품에 대응하는 음원을 선택한다. 모험 5종은 자기 세계의 소품과 장면 소리를 유지하면서 하위 미션을 진행한다.
- 기차는 객차 결합·출발, 정원은 다리·성장, 식당은 몬스터 먹기, 바닷가는 물고기 낚기, 공방은 조각 쌓기, 탐험 섬은 발걸음·보물·로켓 효과음을 사용한다. 책은 종이 넘기기, 소리 풍선은 짧은 풍선 소리를 사용한다.
- 독립된 반복 재생 음악이나 자동 음성 칭찬은 없다. 소리로 철자 이름이나 음가를 대체하지 않는다.

## 설정과 중단

- 플레이 화면의 **효과음** 버튼은 기존 게임 공통 `classbank.gameSound` 설정에 연결한다. 효과음을 꺼도 단어·문장 듣기 버튼은 사용할 수 있다.
- **효과음 음량**은 0–100%, 기본값 55%이다. `classbank.phonics.effectsVolume`에 저장하며, 음량 0에서는 재생하지 않는다. 설정 저장이 막혀도 현재 화면에서는 작동한다.
- 교사의 시작·터치·키보드 입력으로 Web Audio를 활성화한다. 목록 진입만으로 소리를 자동 재생하지 않는다.
- 재시도·장면·완료 소리는 직전 클릭 소리를 대체한다. 빠른 클릭은 제한하고 동시 재생은 최대 3개로 제한한다.
- 단어·문장 읽기를 누르면 현재 효과음과 예약된 성공음을 취소하고, 읽기 완료 또는 오류 전까지 새 효과음을 막는다. 오래된 읽기 종료 콜백이 새 읽기의 우선권을 해제하지 않게 세대 번호로 구분한다. 브라우저가 종료 신호를 주지 않으면 안전 타이머로 복구하며 실제 브라우저의 발화 상태도 확인한다.
- 일시정지, 나가기 확인 창, 숨겨진 탭, 게임 종료, 음소거는 재생 중인 소리와 예약·다운로드 후 대기 중인 소리를 취소한다. 재개해도 오래된 소리를 다시 재생하지 않는다.
- 누락된 음원, 다운로드·디코드 실패, 지원하지 않거나 차단된 Web Audio가 게임 진행을 막지 않게 처리한다.

## 음원과 권리

`app/public/sounds/minigames/*.wav`의 기존 ClassBank 효과음을 재사용했다. 이는 `app/scripts/sfx/build-minigame-sfx.py`로 직접 합성한 원본 사운드이며, 외부 녹음·샘플 라이브러리·런타임 AI 호출을 사용하지 않는다. 샘플레이트 32kHz, 모노 PCM이며 파일 길이·피크·RMS·SHA256은 같은 디렉터리의 `manifest.json`에 있다. 외부 파일 다운로드나 새 유료 서비스는 없다.

## 코드와 확인

- `app/src/lib/phonicsGameSound.ts`: 게임별 효과음 대응, 캐시·디코드·재생·중단·음성 우선권.
- `app/src/components/PhonicsSoundControls.tsx`: 공통 음소거와 파닉스 효과음 음량.
- `app/src/pages/PhonicsGamesPage.tsx`: 실제 클릭·부분 진행·정답·교사 확인·라운드·완료에 연결.
- `node --experimental-websocket scripts/phonics/check-games.mjs --sound` (app 디렉터리): 기존 7,000개 문제 생성 조합과 40종 플레이를 검증하며 실제 AudioBuffer 재생의 길이·RMS·실행 상태를 음원 명세와 비교한다. 각 게임에서 장면·성공·최종 완료음을 확인한다. 음소거, 음량 0·기억, 음성 우선권, 일시정지·숨김·나가기의 현재·예약 소리 중단, 음원 누락·Web Audio 미지원도 확인한다. `--edges-only`를 추가하면 경계 조건만 검사한다.
- 증거: `output/phonics-games-sound/`. 데스크톱과 390px 모바일 화면을 확인한다. 실제 전자칠판 스피커와 기기별 음량·TTS의 청감 검수는 별도이다.

기존 수업 단어·정답 판정·점수·학생 숙련도·DB는 변경하지 않았다. 후속 사용자 요청에 따라 이 효과음 변경만 main 커밋·푸시·자동 운영 배포 대상으로 확정했다.
