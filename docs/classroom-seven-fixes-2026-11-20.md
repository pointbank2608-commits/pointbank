## 영상 질문 동작

- 기존 `PlainTeachingVideo`에 시간 조회·정지·이동·재생 제어 참조를 추가했다. 별도의 중복 플레이어를 만들지 않았다.
- YouTube의 `seekTo`는 비동기이므로 다시 보기 시작 직후의 이전 질문 프레임을 끝 지점으로 오인하지 않도록 재생 구간 진입을 확인한다. 반복 중에는 다른 질문을 찾지 않는다.
- 현재 질문의 카드 컴포넌트를 유지해 선택·배열·정답 공개 상태가 보존된다. 일반 재생·탐색은 질문 중 잠그고 계속 보기로 이어 간다. 다시 보기 멈추기도 제공한다.
- 질문 시점과 다시 볼 시작점은 서로 다른 값이다. 시작점이 질문보다 같거나 뒤면 저장을 막는다. 빈 질문·빈 보기·잘못된 정답·선택하지 않은 빈칸·영상 구간 밖 시점도 막는다.
- 브라우저에서 현재 위치 7.930884초를 00:07.93으로 자동 입력하고 정지하는 것을 확인했다. 질문/다시 보기 00:08.00 동시 입력은 저장을 거부했다. 영상 끝 00:08.00에 질문을 두는 미리보기와 다시 보기 멈추기도 확인했다. 제어되는 영상은 구간 끝보다 미리 정지하지 않으며, 원본 영상이 끝난 프레임에서도 질문을 확인한다.
- 영상 주소/선택 영상을 바꾸면 이전 영상의 질문·시간을 초기화한다. 일반 수업 편집기의 기존 되돌리기 흐름을 유지한다.
- 기존 수업 JSON 저장을 재사용하므로 새 DB 마이그레이션은 없다. 이 영상의 자기 편집본을 불러오며 다른 교사의 수업에 쓰지 않는다. 기존 편집본의 다른 슬라이드도 보존한다.

## 학습 센서

실제 수업 실행 중에만 기존 `useLearningActivity` group 센서를 문항 순서에 연결한다. 서버의 수업 스냅샷에는 질문 ID·문장·시점·버전이 포함된다. 문항 노출·응답 시도·정답 공개·장면 반복을 관찰하며, 미리보기에는 수집 문맥을 주지 않는다. 교실의 말하기를 개별 학생의 응답이나 학습 성과로 추정하지 않는다. 배열 정오 표시는 로컬 수업 피드백이며 서버 채점 근거로 쓰지 않는다. 센서 전송의 운영 수신은 이번 합성 검증에서 확인하지 않았다.
