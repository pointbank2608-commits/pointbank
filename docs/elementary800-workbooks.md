# 초등 800단어 단어장 (2026-10-26)

## 사용 경로

활동지 `/materials` → **초등 800단어 단어장** 카테고리.
- 올려주신 동사편: `/materials/elementary-800?tab=original`. 사용자 PDF의 합본 40쪽과 Level 1~4 각 10쪽을 열기/내려받기. 후속 Level 5(25개·10쪽), 6(25개·10쪽), 7(21개·9쪽), 후속 합본 29쪽, 전체 Level 1~7 합본 69쪽도 실제 PDF로 제공한다. 원본 문구·순서·그림을 그대로 유지했고 원본의 10쪽 레벨 오표기는 화면에 설명한다. PDF 이미지 압축만 적용(원본 약 52MB → 합본 약 11MB); 사용자의 원본 파일은 변경하지 않았다.
- 품사별 교재: `/materials/elementary-800?tab=workbook`. 품사 → 레벨 체크 → 카드/쓰기/둘 다 → 인쇄. 카드 1세트(소개), 2세트(짝 찾기), 4세트(고피쉬); 표지·게임 안내·흑백 선택. 단어 25개당 카드 2쪽 + 쓰기 7쪽 + 선택한 표지/안내.

## 자료·정렬

사용자가 확인한 정렬은 **품사 → 쉬운 단어부터 → 기존 교재 순서 유지**다. 기존 동사 Level 1~4의 100개는 순서를 고정하고 재배치하지 않는다. 후속 동사는 이 100개를 제외하고 Level 5부터 25개씩, 다른 품사는 Level 1부터 구성한다. 레벨은 학습 순서이며 학년·공인 난이도 등급이 아니다.

추가 단어는 `048_word_bank_moe800.sql`의 번호 목록을 옮긴 `elementary800Words.json`에 있는 단어만 사용한다. a/an은 같은 1번이므로 800번호/801표기다. 원본 100개 모두 이 목록 안에 포함되는지 확인했다. 현재 사전에서 800번호가 명시된 뜻만 사용하며, 같은 철자라도 추가 확장 뜻의 번호가 null이면 제외한다. 옛 스키마와 고정 후속 데이터는 기준 철자 목록으로 확인한다. 실제 뜻·품사·예문·난이도는 로그인된 사용자의 기존 `fetchWordBank()` 데이터에서 읽는다. 동사 후속 71개는 2026-10-26 실제 사전 UI에서 확인한 `elementary800VerbContinuation.ts`를 우선 사용해 이미 인쇄된 후속편의 단어/예문 순서가 바뀌지 않게 했다. 난이도 순으로 정렬한 뒤 기존 800번호를 안정적인 순서로 사용하고, 뜻 번호가 낮은 항목을 대표로 선택한다. 여러 품사의 단어는 품사별로 나타날 수 있다. 원본 사전·사용자 단어장·수업을 수정하지 않는다.

후속 교재는 기존 사전 그림을 재사용한다(원본 100개 그림의 화풍으로 새 그림 800개를 그린 것은 아니다). 사전의 그림 주소가 없으면 기존 `WORKBOOK_COLOR_PATHS`에서 **동일 뜻 ID**에 해당하는 파일만 보충한다. 다른 뜻의 이미지를 단어 이름만 보고 가져오지 않는다. 없는 그림은 뜻 단서, 없는 예문은 직접 문장 쓰기 안내를 표시하며 화면에서 개수를 알린다. 그림 로딩 실패 시 인쇄를 중단하고 오류를 표시한다. 사전이 일부만 로드되면 전체 완성본이 아니라는 안내가 나타난다.

## 파일

- `app/public/workbooks/elementary800/`: 원본/후속/전체 합본 및 레벨별 PDF 10개와 실제 표지 이미지.
- `Elementary800WorkbookPage.tsx`: 원본 보기와 품사·레벨 선택/인쇄.
- `Elementary800Sheets.tsx`, `elementary800.css`: A4 표지·카드·쓰기·게임 안내.
- `elementary800Workbook.ts`, `elementary800Words.json`: 목록·정렬·분권.
- `materialsCatalog.ts`, `App.tsx`, `AppLayout.tsx`, 한국어/영어 번역: 카테고리·라우트·인쇄 레이아웃.
- `GameCreateButton.tsx`: 기존 4개 생성 메뉴에서 실제 선택하지 않는 numbers를 상태 타입에서 제외. 함께 진행 중인 게임 안내의 숫자 유형 추가 때문에 생긴 빌드 타입 오류만 수정(실행 동작 변화 없음).

## 확인

`node app/scripts/materials/check-elementary800.mjs` (저장소 루트):
- 800번호/기존 동사 100개, 사전 밖 단어 제외, 대표 뜻 중복 방지, 난이도→기존번호 정렬, 입력 배열 비변경, 전체 번호의 분권 누락 검사.
- 실제 MaterialsPage/AppLayout/교재 페이지를 렌더링해 카테고리·원본 PDF·레벨 선택·고피쉬 4세트·품사 전환 시 이전 선택 해제·모바일·영어·로드 오류·실제 print 호출 확인.
- 인증/사전 API는 합성 데이터. 합성 단어/뜻이 들어간 QA PDF를 실사용 교재로 배포하지 않는다.
- 25개로 생성된 A4 PDF 10쪽(표지 1+카드 2+쓰기 7) 확인. 표지·카드·쓰기의 렌더 이미지를 열어 확인했고 페이지 컨테이너 세로 넘침 없음.
- 사용자 PDF를 압축한 뒤 렌더링해서 확인. 합본 40쪽, 레벨별 10쪽 검증.
- `npm run build`: 통과. `npm run lint`: 통과(기존 경고 유지).

## 실제 사전 확인

연결된 로그인 세션으로 `/dictionary`의 교육부 초등 800 필터를 선택하고 더 보기를 끝까지 펼쳐 화면에 표시된 항목을 확인했다. UI의 단어·뜻·예문·품사·난이도·그림 주소만 읽었다(인증 토큰·숨은 앱 상태·개인 단어장·학생 자료 접근 없음, DB 쓰기 없음).

- 실제 812개 뜻, 801개 표기. 기준 SQL의 801개 표기와 정렬 후 지문 `0x4c134e7f`도 일치했다(a/an 1번 공유). 실제 단어가 기준 목록과 동일함을 확인했다.
- 대표 뜻 기준 명사 428(18권), 형용사 110(5권), 부사 38(2권), 전치사 27(2권), 대명사 12, 접속사 7, 감탄사 9, 관사 3, 수사 4, 조동사 5(각 1권).
- 실제 동사 행 166/표기 165 중 원본 100개를 제외한 새 동사 71개. care의 두 뜻은 첫 뜻으로 묶었다. 원본의 end/surprise/matter/handle/clean/practice는 사전에 다른 품사의 뜻으로 실려 있어도 원본 동사 의미를 그대로 유지한다.
- 후속 71개 PDF는 실제 그림 전부 디코딩, 페이지별 내용 세로 넘침 0, A4 총 29쪽을 확인했다. 압축 후 Level 5 약1.87MB, 6 약1.93MB, 7 약1.64MB, 후속 합본 약5.14MB, 원본 포함 전체 약16.11MB(10진 MB).
- 원본을 변경하지 않고 후속 PDF와 합친 69쪽 전체본을 제공한다.
- 고정 동사 PDF 재생성: `node app/scripts/materials/build-elementary800-verbs.mjs` 후 `python app/scripts/materials/compress-elementary800-pdfs.py`. 브라우저/폰트/이미지 디코딩과 25/25/21 분권을 검증한 후 PDF를 쓴다. 압축 스크립트가 마지막에 원본+후속을 병합한다.

## 남은 검증과 경계

동사편은 고정 PDF 전권으로 제공하고, 다른 품사는 실제 사전으로 레벨별 카드/쓰기 교재를 생성·인쇄하는 방식이다. 사전의 기존 뜻·예문을 새로 전부 집필한 것은 아니며 모든 품사의 모든 문장·그림을 교육 전문가가 새로 검수한 상태로 주장하지 않는다. 운영 DB의 항목이 바뀌면 동사 고정본 외의 품사별 개수·순서는 바뀔 수 있다. 실기기 프린터/iOS PDF 뷰어는 미검증. 커밋·운영 배포·DB 변경 없음.
