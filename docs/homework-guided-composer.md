# 쉬운 숙제 만들기 — 2026-11-02

## 사용 흐름

숙제 화면에서 **오늘 수업 복습시키기** 또는 **단어·문장 외우게 하기**를 선택합니다.

1. **학습 내용**: 저장한 수업·단어장·문장 모음을 고릅니다. 같은 단어와 같은 뜻은 한 번만 모으며 다른 뜻은 구분합니다. 내용 확인·수정은 기본 접힘입니다. 수정 내용은 이번 숙제에만 사용하고 원본 자료는 바꾸지 않습니다.
2. **연습 방법**: 오늘 수업 복습, 뜻과 철자 암기, 문장·표현 말하기 중 선택합니다. 각 선택의 ‘학생 화면 예시 보기’는 실제 HomeworkRunner를 사용하며 저장·배정·학생 기록·포인트 지급을 하지 않습니다.
3. **학생에게 보내기**: 숙제 이름, 반 전체/선택 학생, 마감일을 확인하고 보냅니다. 기존 `hw_assign_draft` 배정과 숙제 공유·결과 화면으로 연결합니다.

내 수업 카드에도 **이 수업으로 숙제 내기**를 노출했습니다. 수업을 다시 찾거나 블록을 변환할 필요 없이 같은 화면에 해당 수업이 선택됩니다.

## 분량과 활동 구성

- 수업의 단어 소개·단어 공부·게임이 같은 단어를 반복 사용해도 학습 내용은 중복 없이 모읍니다. 게임은 저장된 공통 자료가 있을 때 그 자료도 읽으며, 다른 단어로 바꾸거나 자료를 만들어 넣지 않습니다.
- 기존 `lessonCandidates`, 공통 단어 카드 변환, 기존 문제 생성 함수, 플립 카드·녹음·학생 미리보기를 재사용합니다.
- 단어 100개를 한 번에 선택해도 100개씩의 개별 소개 블록을 생성하지 않습니다. 보고 듣기 카드 묶음, 확인 문제 묶음, 쓰기 문제 묶음으로 구성합니다. 100개 전체 연습도 60개 활동 제한 안에서 생성됩니다.
- 10개씩/20개씩/한 번에 모두를 제공합니다. 예를 들어 100개는 20개씩 5회로 준비하고 교사가 이번에 보낼 회차를 고릅니다. 다음 회차는 같은 기기에 기억합니다.
- **자동으로 하루에 한 회차를 공개하거나 예약 발송하지 않습니다.** 화면에서도 ‘다른 회차는 자동 배정·예약되지 않는다’고 안내합니다. 분량 계획과 이번 실제 전송 분량을 따로 표시합니다.
- 이미 전송이 확인된 같은 구성은 표시하고 기존 숙제를 열 수 있습니다. 같은 내용을 다시 연습시킬 때는 **새 숙제로 다시 내기**를 명시적으로 선택합니다.
- 말하기는 최대 다섯 표현을 한 녹음 활동으로 묶고, 교사가 확인하는 녹음임을 안내합니다. 자동 발음 채점을 추가하지 않았습니다.
- 문장 배열 조건에 맞지 않거나 의미 고르기가 모호한 내용은 기존 듣고 쓰기 방식으로 연습합니다. 같은 철자의 다른 뜻을 구분하며 의미가 모호한 객관식은 만들지 않습니다.
- 출석·지원하지 않는 판서 단계는 자동 숙제에 넣지 않습니다. 가져올 내용이 없거나 연결 확인에 실패하면 안내하고 다음 단계를 막습니다. 제한 초과·너무 긴 내용은 명시적으로 안내하며 임의로 삭제하지 않습니다.

## 저장·기존 기능 보존

- 구성과 다음 회차는 사용자·학원·반별로 **이 기기**에 보관합니다. 자동 서버 초안 저장을 했다고 표시하지 않습니다.
- 보내기 전에 요청 UUID와 실제 배정 스냅샷을 저장합니다. 응답을 받지 못하고 새로고침해도 같은 요청과 스냅샷으로 재시도하여 기존 서버의 중복 배정 방지를 사용합니다.
- 새 데이터베이스 테이블·SQL 변경·유료 생성 API를 추가하지 않았습니다. 실제 운영 자료를 테스트 목적으로 수정하지 않았습니다.
- 기존 숙제 결과·공유·학생 PIN·학생별 맞춤 게임과 추천은 유지했습니다. 자주 쓰지 않는 입구는 상단 **더보기**로 모았습니다.
- 기존 블록 편집기와 이전 마법사는 삭제하지 않았습니다. **더보기 → 직접 세부 편집**으로 현재 구성·학생·마감일을 넘기거나 기존 방식으로 시작할 수 있습니다.
