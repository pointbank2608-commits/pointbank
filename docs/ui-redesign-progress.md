## 알려 둘 것
- 새 마스코트 그림은 구글 AI로 만들어 자홍 배경을 지운 것(`app/scripts/vocab/out/ui2/`, `cut.py`). 노트북 뒷면이 연보라라 가장자리가 살짝 거칠 수 있음.
- 시안의 "스프링 잉글리시"·"Kelly · 원장"·"10월 17일·반 7개·학생 11명"은 하드코딩하지 않고 실제 학원·계정·날짜에서 읽는다.
- 오늘 화면의 "일정 설정"은 설정으로 이동. 수업 시작 카드는 다음 수업이 있으면 그 수업을 바로 시작, 없으면 `/curriculum`으로 이동.
