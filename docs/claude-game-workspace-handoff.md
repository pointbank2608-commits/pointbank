# Claude 인수인계: 게임 안에서 수업 준비·진행 (2026-10-19)

사용자 요청은 선생님이 게임 화면 안에서 자료·반·학생 순서·팀·설정·저장을 처리하고, 기존 단어장/문장 모음으로 게임센터와 내수업에서 바로 게임을 진행하는 것이다.

선생님 게임 47개 라우트에 공통 `GameWorkspace`를 적용했다. 기존 페이지 설정 폼을 준비 창에 유지하고 게임판만 portal로 분리해 준비 창을 열어도 현재 게임을 재마운트하지 않는다. 자료 선택은 원본을 수정하지 않고 게임용 구성과 출처 스냅샷을 저장한다. 다른 게임으로 전환할 때 목표 게임의 자료 변환을 실행하고 반·동일 명단의 팀/순서는 유지한다. 내수업에서는 현재 활동만 교체한다.

로컬 게임 시간은 `gameClock`으로 정지·재개한다. 온라인 Quizshow 서버 대회는 멈추지 않으며 화면에 안내한다. 준비 창은 연결된 화면에서 그대로 보인다. 학생 따라보기 중에는 자료·게임 구성을 바꾸기 전에 따라보기를 끄도록 제한한다. 기존 게임별 저장 방식과 숙제·통장·학생 라우트는 유지한다.

타입 검사·프로덕션 빌드·합성 로직/브라우저 검증을 통과했다. 47개 게임의 준비 창은 확인했고, 퀴즈→돌림판 및 내수업 전환을 실제 페이지로 검증했다. 모든 게임의 전체 라운드/실제 다인 대회까지 검증한 것은 아니다. 운영 데이터 변경, 커밋, 푸시, 배포는 하지 않았다.

변경 파일, 실행한 테스트, 동작의 한계, 되돌리기는 [game-workspace-progress.md](game-workspace-progress.md)를 먼저 확인한다. 이전 숙제 편집기 작업은 [별도 인수인계](claude-homework-block-editor-handoff.md)에 있다. 현재 작업 외의 미추적 그림 생성물/PDF를 함께 커밋하거나 삭제하지 않는다.
