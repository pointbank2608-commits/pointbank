2026-10-19 현재 로컬 구현의 실제 메뉴·버튼 이름을 확인해 작성했다. 단체수업·개별수업과 숙제 배정·전달을 구분한다. 앱 업데이트 상태와 학원에서 열린 기능에 따라 화면이 다를 수 있다.

수업 만들기 매뉴얼은 게임 우선 홈·내 단어·문장 생성·기존 항목 편집기·선택적 원본 저장·준비/집중 플레이·선생님 메뉴·선택적 수업 추가 안내를 반영해 원본과 PDF를 함께 갱신했다.

수업 만들기는 추천 구성, 직접 구성, 게임 안 설정, 개별수업 생성·배정·현황과 체크리스트를 담았다. 숙제 내주기는 빠른 만들기, 수업 가져오기·블록 편집기, 학생별 맞춤 게임, 전달 방식·결과·스탯 확인을 담았다. 예시 단어장은 설명용이며 실제 학생 자료를 넣지 않았다.

PDF는 A4이며 한글 폰트를 포함한다. 양쪽 문서 8쪽을 PNG로 렌더링해 한글·표·줄바꿈·여백·쪽번호를 확인했다. 프로그램이나 DB는 변경하지 않는다.

## 다음에 고칠 때

원본 Markdown을 수정한 뒤 저장소 루트에서 `build_manuals.py`를 Python으로 실행한다. ReportLab·pypdf와 Windows 맑은 고딕 폰트를 사용한다. `<!-- PAGE -->`는 쪽 나누기이므로 유지한다. 생성 후 PDF를 이미지로 다시 렌더링해 확인한다.

개발용 적용 방법과 SQL 안내는 교사용 본문에 섞지 않았다. 새 게임 학습 기능의 운영 적용은 [별도 인수인계](../claude-game-learning-handoff.md)를 참고한다.
