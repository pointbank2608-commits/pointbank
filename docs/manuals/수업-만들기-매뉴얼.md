# 수업 만들기

처음 사용하는 선생님을 위한 클래스뱅크 사용 안내

## 01. 가장 쉬운 시작: 추천 구성으로 만들기

**어떤 수업을 만들까요?**

| 하고 싶은 일 | 선택할 방식 |
| --- | --- |
| 선생님이 칠판에서 반 전체를 진행 | 단체수업 |
| 학생이 각자 기기에서 자기 속도로 학습 | 개별수업 |
| 집에서 할 활동을 학생에게 전달 | 숙제 - 숙제 내주기 매뉴얼 참고 |

### 먼저 준비해 주세요

게임만 사용할 때는 홈의 **[게임 고르기]**에서 게임을 고릅니다. 준비 화면에서 **[샘플로 바로 해보기]**·내 자료 불러오기 또는 **[+ 단어장 만들기]·[+ 문장 모음 만들기]**를 선택하세요. 기존 항목 편집기로 작성하며 반·수업·이름·저장 없이 시작할 수 있습니다. 홈과 **[내 단어·문장]**에서도 자료를 만들 수 있습니다. 다른 게임을 고르려면 준비 화면 맨 위의 **[← 게임 목록]**을 누릅니다.

### 단체수업을 빠르게 만드는 순서

1. 왼쪽 메뉴 **[내 수업]**으로 들어갑니다. 화면에 표시된 반이 수업할 반인지 확인합니다.
2. **[단체수업] → [추천 구성으로 만들기]**를 누릅니다. 홈 아래 ‘내 수업’의 **[수업 만들기]**로도 시작할 수 있습니다.
3. 수업할 **반**, 가르칠 **내용**, 수업 **시간**을 고릅니다. 단어·문법·파닉스·상황 표현·영상·노래 중 필요한 내용을 선택합니다.
4. 단어 수업은 준비한 단어장을 고르거나 단어를 붙여 넣습니다. 아래에 제안된 활동과 진행 순서를 확인합니다.
5. 준비해 둘 때는 **[저장해 두기]**, 순서를 더 고칠 때는 **[자세히 편집]**, 바로 진행할 때는 **[지금 시작]**을 누릅니다.

> 처음에는 단어장 하나로 수업을 만들고, 제안된 활동을 미리 확인한 뒤 시작해 보세요. 예상 시간은 안내용이므로 학생 반응에 맞춰 진행하면 됩니다.

## 02. 활동을 직접 고르고 게임 진행하기

### 내가 원하는 순서로 만들기

1. **[내 수업] → [단체수업] → [직접 구성하기]**를 누릅니다.
2. 수업 이름과 사용할 단어장을 정합니다. 예: ‘월요일 동물 복습’.
3. 활동을 고르는 목록에서 단어 소개, 게임, 문제풀이, 영상, 활동지 등 필요한 블록을 추가합니다.
4. 활동 순서를 바꾸고 각 활동의 내용과 정답을 확인합니다. 게임이 사용할 단어와 구성이 맞는지도 확인합니다.
5. 새 수업은 **[만들기]**, 기존 수업을 고친 경우에는 **[저장]**을 누릅니다. 저장한 수업 카드에서 **[수업 시작]**을 누르면 진행할 수 있습니다.

### 게임 화면 안에서 할 수 있는 일

| 버튼 | 하는 일 |
| --- | --- |
| + 단어장 만들기 / + 문장 모음 만들기 | 지원하는 자료를 기존 게임 항목 편집기로 작성 |
| 내 자료 불러오기 / 샘플로 바로 해보기 | 같은 자료 재사용 또는 직접 체험. 반 연결은 선택 |
| 참여자·팀·순서 | 순서형 게임의 임시 참여자·팀 이름·제외·선두 설정 |
| ▶ 게임 시작 / ☰ 메뉴 | 미리보기 중앙에서 시작. 메뉴에서 계속하기·설정·준비 복귀 |
| 게임 방법 영상 / 전체화면 종료 | 영상은 설명용. 전체화면 종료는 오른쪽 위에서 크기만 변경 |

전체화면 전환만으로 시작되지 않습니다. 미리보기 중앙 **[▶ 게임 시작]** 아래 실제 항목·팀 수를 확인하세요. 전체화면 종료·Escape·설정 열기/닫기에도 현재 판을 유지합니다. 이름은 선택이며 비우면 기본 이름을 씁니다. 원본은 **[내 단어장에도 저장]**, 게임 설정은 **[내 활동으로 저장]**을 선택합니다. 임시 보존은 이 탭 복구용입니다.

> 설정창은 학생이 보는 화면에도 표시됩니다. 정답이 포함된 설정은 수업 전에 준비하세요. 온라인 대회는 서버에서 계속 진행하므로 화면을 가린 것을 대회 전체 일시정지로 생각하지 마세요.

**[게임 설정·수정]**은 기존 편집기로 바로 연결합니다. **[준비 화면으로]**는 같은 게임, **[다른 게임 고르기]**는 전체 목록입니다. **[다른 게임 하기]·[활동지 만들기]**는 같은 자료를 전달합니다. **[수업에 추가]**에서 기존 수업 또는 새 수업을 직접 고릅니다. 다른 게임은 새 판이며 점수는 합산되지 않습니다. 자동 팀 게임의 차례는 기존 규칙을 따릅니다. 휴대폰 참여 보카 대회의 실제 온라인 참여는 내 활동으로 저장한 뒤 사용하세요.

## 03. 학생이 혼자 하는 개별수업 만들기

### 만들고 확인하기

1. **[내 수업]**에서 반을 고른 뒤 **[개별수업] → [새 개별수업 만들기]**를 누릅니다.
2. 준비된 단어·문법·주제 수업을 고릅니다. 직접 만들려면 **[빈 수업에서 시작하기 (추천)]**에서 이름과 시작 방식을 정하고 **[만들고 편집하기]**를 누릅니다.
3. 단어를 붙여 넣어 시작하거나, 편집기에서 필요한 학습 블록을 추가합니다. 단어 만나기 → 뜻 고르기 → 듣기 → 철자처럼 순서를 잡아 보세요.
4. 게임 블록을 넣을 때는 혼자 할 수 있는 게임 종류와 선생님이 저장한 게임 구성을 선택합니다.
5. **[미리보기]** 또는 수업 카드의 **[더보기] → [학생 화면 미리보기]**로 학생 입장에서 풀어 봅니다. 내용을 확인한 뒤 저장합니다.

### 학생에게 내기

1. 수업 카드의 **[더보기] → [오늘의 수업으로 내기]**를 누릅니다. 집에서 하게 하려면 카드의 **[숙제로 내기]**를 선택합니다.
2. 받을 학생을 고르고 필요하면 기한을 정합니다. 표시된 **오늘의 수업 / 숙제** 구분을 확인합니다.
3. **[N명에게 내기]**를 누릅니다. 학생은 학생 페이지의 배정된 활동에서 시작합니다.
4. 수업 카드의 **[현황]**에서 진행·완료·어려워한 부분을 확인합니다. 진행 중 도움이 필요한 학생은 현황판에서 확인할 수 있습니다.

> 개별수업을 저장하는 것과 학생에게 내는 것은 다릅니다. ‘낸 학생 N명’ 표시를 확인해야 실제 배정 여부를 알 수 있습니다.

### 게임과 스탯 연결

매치업·애너그램·두더지잡기·워드서치·행맨은 게임 뒤 짧은 확인 문제로 학습을 확인할 수 있습니다. 교사는 게임 단계에서 **[게임 뒤 짧은 학습 확인을 하고 학생 스탯에 반영]**을 선택합니다. 게임 점수·속도 자체는 능력 점수가 아닙니다.

## 04. 다음 수업까지 이어 쓰기

### 한 단어장으로 이어 가는 예시

**수업 준비:** ‘동물 10개’ 단어장을 고르고 단어 소개·매치업·퀴즈로 단체수업을 만듭니다.

**교실 진행:** 수업 시작 전에 반·자료·팀을 확인합니다. 게임을 바꿀 때는 같은 자료로 다른 게임을 열고 새 판을 시작합니다.

**집에서 연습:** 숙제 메뉴의 **[학생별 맞춤 게임]**에서 같은 단어장을 선택합니다. 학생별 추천을 확인한 뒤 숙제로 보냅니다.

**다음 개별수업:** 학생은 **[지난 숙제 맞춤 몸풀기]**로 필요한 낱말을 짧게 복습하고 원래 수업으로 돌아갈 수 있습니다. 이 연습은 선택 사항입니다.

### 수업 시작 전 5가지 확인

- [ ] 수업할 반과 학생 명단이 맞나요?
- [ ] 사용할 단어장과 게임 내용이 맞나요?
- [ ] 활동 순서와 문제의 정답을 확인했나요?
- [ ] 소리·전체화면·팀·순서를 준비했나요?
- [ ] 저장한 수업 또는 배정한 학생 수를 확인했나요?

### 자주 막히는 부분

**개별수업 탭이 보이지 않아요.** 학원에서 해당 기능을 열었는지 관리자에게 확인해 주세요.

**단어장을 고쳤더니 다른 수업 내용도 달라졌어요.** 같은 단어장을 쓰는 수업에 반영될 수 있습니다. 한 수업만 바꾸려면 사본이나 별도 단어장을 사용하세요.

**이미 학생에게 낸 수업을 고쳐도 되나요?** 진행 중인 단계 순서가 어긋나지 않게 사본으로 저장해 새로 배정하는 편이 좋습니다. 기존 수업 삭제는 배정 기록에도 영향을 줄 수 있으므로 주의해 주세요.

**게임 자료를 바꿀 수 없어요.** 학생 따라보기가 켜져 있다면 먼저 끄고 변경합니다. 자료 종류나 필요한 낱말 수가 맞지 않는 게임은 선택할 수 없습니다.

**이어서 만들기만 하면 저장된 건가요?** 기기 임시저장과 수업 저장은 다릅니다. 목록에 남길 때는 화면의 저장·만들기 버튼을 눌러 주세요.

이 문서는 2026-10-20 현재 구현된 화면을 기준으로 작성했습니다. 학원에서 열린 기능과 앱 업데이트 상태에 따라 보이는 메뉴가 다를 수 있습니다.
