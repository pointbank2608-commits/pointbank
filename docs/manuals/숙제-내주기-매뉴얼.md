# 숙제 내주기

자료 선택부터 학생 전달, 결과 확인까지 한 번에 따라 하기

## 01. 가장 쉬운 시작: 새 숙제 내기

### 어떤 방법으로 만들까요?

| 상황 | 시작할 버튼 |
| --- | --- |
| 자료와 분량을 골라 빠르게 만들기 | 새 숙제 내기 |
| 활동을 직접 넣고 순서를 고치기 | 숙제 블록 편집기 |
| 같은 자료를 학생별 약점에 맞게 연습시키기 | 학생별 맞춤 게임 |
| 이미 만든 수업을 집에서 하게 하기 | 수업 카드의 이 수업으로 숙제 내기 |

### 새 숙제를 만드는 4단계

1. 왼쪽 **[숙제]**에서 반을 확인하고 **[새 숙제 내기]**를 누릅니다.
2. **[누구에게]**에서 반 전체 또는 받을 학생을 고릅니다. 숙제 이름과 마감도 확인합니다.
3. **[무엇으로]**에서 최근 수업·단어장·영상 장면·지난 오답 등 사용할 자료를 고릅니다.
4. **[몇 분] → [확인]**으로 진행합니다. 만들어진 활동·대상 학생·마감을 확인하고 학생 화면을 미리 본 뒤 최종 생성 버튼을 누릅니다.

> 화면을 열거나 자료를 고르는 것만으로 숙제가 전달되지는 않습니다. 마지막 확인 버튼을 누른 뒤 목록에 생긴 숙제를 확인하세요.

### 만드는 것과 전달하는 것은 달라요

숙제가 생성되면 공유 화면에서 링크·QR·안내문을 확인합니다. 학생이 들어올 수 있도록 해당 링크나 안내를 전달해 주세요. 안내문 복사는 메시지를 자동 발송하는 기능이 아닙니다.

처음에는 단어장 하나로 짧은 숙제를 만들고, 테스트 학생으로 시작·답 저장·완료까지 확인해 보세요.

## 02. 수업을 가져오거나 블록으로 직접 만들기

### 오늘 수업을 숙제로 바꾸기

1. **[수업]**에서 저장한 수업 카드의 **[이 수업으로 숙제 내기]**를 누릅니다. 수업 편집 중에는 **[저장하고 숙제로 가져오기]**로 이동할 수 있습니다.
2. 숙제 블록 편집기에서 저장된 수업과 가져올 활동·내용을 선택합니다.
3. **[선택한 내용 가져와서 추리기]**를 누릅니다. 집에서 필요한 활동만 남기고 순서를 정리합니다.
4. 문제·정답·활동 완료 조건을 확인하고 미리 봅니다. 자동으로 가져올 수 없는 활동은 안내를 보고 적절한 숙제 활동으로 바꿉니다.

> 수업을 가져오기는 저장된 수업의 내용에서 고르는 기능입니다. ‘오늘 실제로 실행한 활동’을 자동으로 알아서 가져오는 기능은 아닙니다.

### 블록 편집기의 기본 사용법

**[숙제] → [숙제 블록 편집기]**에서 숙제 이름을 쓰고 필요한 블록을 추가합니다. 왼쪽에서 블록을 고르면 내용을 편집할 수 있습니다. 위·아래 버튼이나 끌기로 순서를 바꾸고, 필요 없는 블록은 삭제합니다.

| 버튼 | 기억할 점 |
| --- | --- |
| 초안 저장 | 편집 중인 내용을 보관합니다. 학생에게 배정되지 않습니다. |
| 처음부터 미리보기 | 학생이 보는 흐름 전체를 확인합니다. |
| 현재 블록 미리보기 | 지금 고른 활동만 확인합니다. |
| 배정 → 확인하고 배정 | 반 전체/개별 학생과 마감을 확인한 뒤 실제 숙제를 만듭니다. |

배정 후에는 당시의 내용과 평가 기준이 고정됩니다. 이후 초안 수정은 새로 배정할 숙제에 적용됩니다. 이미 낸 숙제를 바꾸고 싶다면 새 숙제를 만들고 기존 숙제의 처리 여부를 별도로 확인하세요.

‘기기 복구본·서버 미저장’이 보이면 저장이 끝난 것이 아닙니다. 연결을 확인하고 초안 저장을 다시 시도해 주세요.

## 03. 학생마다 다른 게임 숙제 내기

### 같은 단어장으로 맞춤 연습 만들기

1. **[숙제] → [학생별 맞춤 게임]**을 누릅니다.
2. **[함께 배울 자료]**에서 단어장을 선택합니다. 예: ‘동물 10개’.
3. 학생 이름을 바꿔 가며 추천 이유와 활동을 확인합니다. 철자가 어려운 학생은 글자 순서·철자 쓰기, 듣기가 어려운 학생은 듣기 연습 등이 제안됩니다.
4. 필요 없는 활동은 체크를 해제하고, 이번에 받지 않을 학생은 제외합니다. 학생 화면도 미리 확인합니다.
5. **[진행할 곳] → [숙제로 보내기]**를 선택하고 마감을 정합니다. 마지막 **[확인하고 보내기]** 버튼을 누릅니다.

> 개별수업 시간에 하게 하려면 같은 창의 [진행할 곳]을 [개별수업으로 내기]로 바꿉니다. 개별수업 기능이 열린 학원에서 선택할 수 있습니다.

### 게임센터에서 쓰던 자료로 시작하기

교사용 게임 화면에서 **[같은 내용으로 다른 게임] → [이 자료로 맞춤 게임 숙제·개별수업 만들기]**를 누릅니다. 추천창으로 가져온 자료와 반을 확인한 뒤 위 순서대로 진행합니다. 단어 자료와 해당 버튼이 있는 화면에서 사용할 수 있습니다.

### 점수는 어떻게 기록되나요?

- 게임의 운·반응 속도 점수를 영어 능력으로 더하지 않습니다. 채점 가능한 문항의 처음 답을 기존 스탯에 반영합니다.
- 이미 지원되는 개별수업 게임 5종은 게임 뒤 **[혼자 확인하고 마치기]**로 짧은 확인 문제를 풉니다. 교사가 측정을 켠 경우에 사용합니다.
- 이 게임 확인에서 같은 날 같은 낱말·능력을 반복한 기록은 재도전으로 분리합니다.
- 기록이 부족하면 공통 복습을 제안합니다. 학생 스탯이 ‘?’인 것은 아직 판단할 기록이 부족하다는 뜻입니다.

확인 문제를 지원하는 개별수업 게임: 매치업·애너그램·두더지잡기·워드서치·행맨. 게임센터의 모든 게임이 학생용으로 제공되는 것은 아닙니다.

## 04. 학생에게 전달하고 결과 확인하기

### 학생에게 맞는 입장 방법 안내

| 숙제 전달 방식 | 학생에게 안내할 내용 |
| --- | --- |
| 일반 숙제의 반 링크·QR | 화면 안내에 따라 이름과 PIN으로 입장 |
| 학생별 개인 링크·QR | 해당 학생에게만 전달. 학생별 맞춤 숙제는 개인 링크·QR 사용 |
| 학생 포털을 사용하는 수업·숙제 | 학원 코드·이름·등록된 학부모 휴대폰 번호로 로그인 후 배정된 활동 선택 |

공유 화면의 안내를 그대로 사용하세요. 개인 링크·QR은 해당 학생·보호자에게 전달합니다. PIN을 잊었다면 숙제 화면의 **[학생 PIN] → [새 PIN]**으로 새 번호를 만들어 안내합니다. 기존 번호를 다시 보는 기능은 아닙니다.

### 결과 확인과 다음 수업 연결

1. 숙제 목록에서 해당 숙제의 결과를 열어 미시작·진행 중·완료 학생과 틀린 낱말을 확인합니다.
2. **[학습 카드]** 또는 **[기록] → [학생 스탯]**에서 학생별 학습 기록을 확인합니다. 학생·출석의 이름 옆 스탯 버튼으로도 같은 카드를 열 수 있습니다.
3. 게임 학습 기록이 있으면 혼자 맞힌 낱말·하루 뒤에도 기억·다른 능력에서도 확인한 기록을 볼 수 있습니다.
4. 다음 개별수업 전에 학생이 **[오늘의 맞춤 시작 연습]** 또는 **[지난 숙제 맞춤 몸풀기]**로 복습하도록 안내할 수 있습니다.

### 보내기 전 확인 / 자주 하는 실수

- [ ] 받을 반과 학생이 맞고, 활동과 정답을 미리 확인했나요?
- [ ] 마감 날짜와 시간을 확인했나요?
- [ ] 초안 저장에서 끝내지 않고 실제 배정·생성을 마쳤나요?
- [ ] 학생에게 맞는 링크와 입장 방법을 전달했나요?
- [ ] 완료 여부와 다음에 연습할 낱말을 확인할 위치를 알고 있나요?

**일부 학생에게만 보내졌어요.** 맞춤 추천창의 성공 인원을 확인하고 남은 학생만 재시도합니다. 성공한 숙제를 다시 만들지 않게 목록도 확인하세요.

**마감이 지나 학생이 못 들어가요.** 숙제의 마감·닫힘 상태를 확인합니다. 필요한 경우 새 기한의 숙제를 다시 준비하고 안내해 주세요.

**학생이 저장에 실패했어요.** 연결을 확인하고 화면의 재시도 안내를 따릅니다. 완료했다고 보기 전에 저장·완료 표시를 확인합니다.

이 문서는 2026-10-19 현재 구현된 화면을 기준으로 작성했습니다. 새 게임 학습 연결은 해당 앱 업데이트가 반영된 환경에서 제공됩니다. 메뉴가 없다면 학원 기능 설정과 업데이트 상태를 관리자에게 확인해 주세요.
