효과적인 영어 수업을 발견·검증·개별수업으로 제공하는 첫 어휘 회상 경로다. 교사 승인 없이 새 수업/숙제를 배정하지 않는다. 학생 수행·블록 사용에서 센서를 자동 수집하고, 어드민은 분모·누락·사전 상태·제공 버전을 확인하여 다음 검증 방향을 기록한다. 지연 확인 1일/7일은 초깃값이며 최적 효과로 검증하지 않았다. 전이, 읽기·문법·말하기 전체, 대규모 효과 추정은 미구현이다.

## 코드·빌드·배포

- 이전 전체 로컬 DB/동시성/브라우저 검사 통과는 각 인수인계서에 기록했다. 이번 채점 수정 뒤 학습 경로 브라우저 회귀·전체 TypeScript 검사 통과.
- 기준 main `58fe7d6202e20a497c3fb6a4fad68a2bc6969825`를 격리 추출하고 선택 파일만 덮어쓴 후보에서 npm ci와 운영 공개 설정만 사용한 `npm run build:vercel` 성공(종료 코드 0). 수정 후 재빌드도 성공. 운영에서 sensors enabled, 기존 청크/플러그인 시간 경고만 있다.
- 환경은 공개 VITE_SUPABASE_URL/ANON_KEY만 전달했다. 서비스 키·기타 API 키를 후보/배포에 넣지 않았다. 무관한 미추적 미디어·기존 output 변경은 커밋 대상에서 제외한다.
- 이번 변경은 main 푸시의 기존 GitHub→Vercel 자동 배포로 전달한다. 로컬 Vercel CLI의 다른 팀 권한을 우회하지 않는다. 실제 성공 커밋/URL은 GitHub 배포 상태로 확인한다.
- 운영 수집 중지: `VITE_LEARNING_SENSORS_ENABLED=false`를 명시하고 재배포. 변수를 제거하면 운영 기본 true이므로 중지되지 않는다. SQL 중지/복구는 런북을 따른다.
