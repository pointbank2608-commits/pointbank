# Ready Class 교재·영상·노래·팝콘 개선

## 구현 및 위치

- Ready Class의 현재 단계·유닛에서 **워크북 인쇄** → `/phonics/workbook?unit=course-2-1`. 실제 공통 단어·그림과 슬라이드 ID를 참조한다. 기존 노란색 독립 워크북과 이전 ABC 교재 파일·데이터는 보존했다.
- 1단계 9유닛 92쪽, 2단계 8유닛 72쪽, 3단계 8유닛 71쪽, 4단계 8유닛 110쪽, 5단계 9유닛 86쪽. **총 42유닛, 학생용 431쪽**. 교사용 설명·정답은 체크하면 별도 페이지로 추가된다. 유닛·단어·페이지별 슬라이드 대응은 [편성표](ready-class-workbook-units.md).
- A4 세로, 12mm 여백. 단계 색상은 실제 슬라이드의 하늘색·핑크·초록·보라·노랑을 따른다. 페이지 선택·전체 선택·해제와 이미지 디코딩·글꼴 로딩 후 인쇄를 지원한다. 미확정 읽기 문장은 학생용에서 제외한다.
- 레벨 2 Unit 1은 dad/bag/jam 도입 → 9단어 확장 → 실제 듣기 문항 bad/tag/ram → 서로 다른 Match 배열 → 9단어 복습표 및 확장 6단어 기억하기 → 쓰기 → ad/ag/am 전체 빈칸 → 9단어 분류로 구성했다. 첨부 샘플의 그림을 복사하지 않고 사이트의 공통 컬러 그림을 사용한다. 차시 이름은 학생용에서 제외했다.
- `/videos`: 등록된 주제 태그, 제목·표현·대사·단어 검색, 학습 내용 및 실제 길이 표시. 수업 시간은 **영상 2회+단어당 30초+질문당 1분**에 따른 예상치로 표시한다. 선택한 활동만 기존 수업 초안에 넣는다. 영상 관련 실제 대사·질문 인쇄는 `/materials/video-worksheet?clip=...`.
- 영상 전체화면은 영상·자막·조작을 함께 유지한다. 기존 3개 진행 모드, 배속 0.5/0.75/1/1.25/1.5/2, 반복 1~5회, 자막 5개, 배역 설정을 보존했다. 조작바는 설정·자막 팝업으로 정리했고, 재생 중 3초 자동 숨김·마우스/터치 복원·호버/키보드/팝업 고정·항상 표시를 지원한다. 모바일 세로에서는 조작바를 여러 줄로 배치한다.
- 내 수업의 영상 포함 수업에서만 실제 러너 순서대로 이동 탭을 제공한다. 전체화면 상태를 유지하고, 돌아온 영상은 시간·설정을 복원하되 자동 재생하지 않는다. 저장 수업을 수정하지 않는 탭 메모리다.
- 자료 → 파닉스 → **노래·챈트**. Ready Class는 같은 `video_clips.pack.phonicsSong.unitIds`를 읽는다. 등록은 기존 플랫폼 관리자 권한과 `video_clips` RLS를 재사용한다. `/admin/videos`의 **노래·챈트 등록·수정** → `/admin/phonics-songs`. 새 SQL/운영 DB 변경은 없다. 영상 ID·실제 길이·채널·연결 유닛을 입력하며 외부 유튜브 링크임을 표시한다. 임의의 노래 링크는 등록하지 않았다.
- 팝콘 자세히 설정에 **POP! 카드 개수**(0~100)를 추가했다. 0은 POP! 없는 연습, 미설정된 과거 게임은 기존 25%(최소 1개) 동작을 유지한다. `config.popcornPopCount`가 실제 더미와 기존 저장 경로에 반영되고 변경 시 새 판으로 시작한다.

## 검증과 한계

- `node app/scripts/ready-media/check.mjs`: 합성 DB + 실제 React 화면. 42유닛의 기본 단어·목표 철자·그림·쪽 경계, 학생/교사 선택, 영상 설정·전체화면·자동 숨김·활동 이동·무자동재생 복원, 실제 노래 등록·수정 함수, 선택 활동만 수업 초안 생성, POP! 더미 구성을 검사한다. 운영 계정·학생 자료에는 쓰지 않는다.
- `node app/scripts/ready-media/check-popcorn-save.mjs`: 실제 게임 준비/저장/재저장과 모바일 화면에서 POP! 3개 설정을 검사한다.
- `READY_PDF=1`로 단계별 대표 유닛을 PDF로 출력했다. 대표 학생 PDF는 각각 12/9/9/17/10쪽이며 빈 페이지·사이트 메뉴 출력이 없는지 확인했다. 페이지 PNG를 렌더링해 표·그림·쓰기칸을 시각 확인했다. 431쪽 전부를 사람이 하나씩 교정한 것은 아니다.
- 공개 영상 52개는 ID·구간이 유효했고 대사도 있었다. 대표 썸네일 12개는 HTTP 200이었다. 깨지는 환경에서는 썸네일 대체 표시를 제공한다. 공개 파닉스 DB 조회는 0행으로, 공통 정적 기준과 실제 파일을 검증했다. 로그인 사용자 전용 업로드 자산의 전수 조사는 아니다.
- 실제 유튜브 대표 영상 `hyacEIXP3oc`는 플레이어 준비 후 **코드 150(임베드 제한)**으로 재생되지 않았다. 이 결과를 앱 동작 검증 통과와 구별한다. 제한 안내·유튜브에서 열기를 제공하며 영상 ID를 임의로 바꾸지 않는다. 실제 모든 영상의 재생·소리는 확인하지 못했다.
- 현재 등록된 파닉스 노래는 0개다. 공유 저장/수정 연결은 합성 데이터로 확인했고 운영 영상은 등록하지 않았다. 실제 사용할 노래 링크는 관리자가 검토해 등록해야 한다.
- 공통 자산 기준 42유닛의 컬러 그림 누락은 발견되지 않았다. 이번 슬라이드 연계 워크북은 색칠 교재가 아니므로 선화를 새로 제작하거나 기존 선화 목록을 변경하지 않았다.
- 사용자 후속 요청으로 검증 후 선별 커밋·푸시·자동 운영 배포를 진행한다. 기존 저장 수업·게임·문법·문장 은행 데이터를 테스트 목적으로 바꾸지 않았다.
