# 수업 준비·Ready Class 화면 수정 — 2026-11-19

운영 최신 기준 `d29d300e`에서 작업했다. 서비스 표시는 수업뚝딱을 유지한다.

## 변경

- 사이트워드 37개 리뷰의 찾기 영역: 안내 아래 5mm, 가운데점 제거, 여섯 단어를 같은 너비의 독립 칸에 배치. 문장·쓰기 영역은 보존했다.
- Ready Class: 기존 42유닛의 차시·단어·문항 데이터를 재사용한다. 준비 화면에서 선택 차시의 모든 실제 슬라이드, 좌우 이동, 목표·순서·인쇄·마지막 확인·노래를 함께 제공한다. 차시 번호는 해당 차시 기준이며 대표 카드도 실제 슬라이드다.
- 발표: 슬라이드 바로 옆 이전·다음, 방향키, 목차·판서·음성·장 번호를 모았다. Fullscreen API와 ResizeObserver로 원래 16:9 비율을 유지한다. 종료·복귀 때 URL의 슬라이드 선택을 유지한다.
- 클레이 디자인: 사용자 제공 Listen and Blend 시안을 바탕으로 내장 imagegen으로 글자 없는 공통 교실 배경 `clay-classroom-v1.png`를 제작했다. 기존 공통 활동 컴포넌트와 실제 글자·그림·버튼을 사용한다. 단계 색상은 유지한다.
- 짝 연결: 문제·정답의 배치를 유지하고 실제 단어 ID를 기준으로 화살표를 잇는다. 중복 정답 문자·숫자는 제거했다.
- 듣고 고르기: 그림 선택 표시를 제공한다. 전체 단어 음원을 사용하며 녹음 재생 실패 때 공통 영어 TTS로 보완한다. 정답 화면의 그림별 스피커는 각 단어를 읽는다.
- 내 자료 게임 선택: 지원 자료 기준의 전체 게임 목록, 썸네일 카드, 자료 유형을 표시한다. 자료가 바뀌면 팝업 선택 상태를 새로 만든다. 기존 quickSource 전달을 재사용한다.
- 공유 단어장: 안내를 단어 고치기 옆으로 옮겼다. 확인 문구와 복사 흐름은 유지하고 다른 수업 수에서 현재 수업을 중복 합산하던 값을 고쳤다.
- 영상 활동: 쉐도잉·빈칸 듣기를 영상 탭에 나란히 배치한다. 준비된 영상·내 영상 버튼은 기존 대본 설정기를 사용한다. 빈칸 듣기 변환은 문장별 줄바꿈, 소수점 시작·종료 시각, 해석과 기존 빈칸을 보존한다.

## 확인한 범위

- 브라우저: 사이트워드 37세트 모두 여섯 칸·약 5mm 간격·내용의 페이지 영역 내 배치를 확인했다. 01세트 측정값은 약 4.998mm였다.
- 브라우저: 실제 준비 경로, 38개 썸네일과 화살표 선택 연동, `2 / 38`, 2차시 시작의 `1 / 39`, 일반 발표 화면의 이동 버튼·번호 표시를 확인했다.
- `node scripts/classroom-ux/check-source.mjs`: 영상 대본 여러 줄·빈칸·소수점 구간 보존, 42유닛과 슬라이드 단어 참조, 37개 리뷰 데이터 통과.
- `npm run build`: TypeScript와 Vite 프로덕션 빌드 통과. 기존 대형 청크 경고가 있다.
- 변경 컴포넌트 oxlint: 오류 없음. 기존 Fast Refresh export 경고가 있다.

## 아직 직접 확인하지 못한 범위

실제 A4 인쇄 결과·쪽 수, 실제 Chrome/전자칠판 전체화면·소리 청취, 여러 단계의 모든 화면 유형, 다른 짝 연결 문항, 단어장/문장 모음 교대 게임 실행, 단어장 복사·취소, 영상 활동 네 가지 시작 경로의 최종 실행은 완료로 기록하지 않는다. 이전 브라우저 검증은 사용자의 Esc로 중단되었다. 인앱 브라우저의 전체화면 요청은 거절되어 오류 안내를 확인했다.

## 학습 센서·운영 범위

새 서버 채점·개인 성과 지표·자동 배정을 추가하지 않았다. 그림 선택은 교실 화면의 로컬 표시이며 학생의 독립 학습 성과로 저장하지 않는다. 미리보기에서 학습 기록을 수집하지 않는다. 합성 확인 서버는 수집 플래그를 false로 정의하고 운영 DB 요청을 합성 응답으로 대체한다. 운영 수집·중지 규칙과 기존 배정은 변경하지 않았다. DB 마이그레이션은 없다.
