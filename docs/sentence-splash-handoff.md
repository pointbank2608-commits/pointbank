# Sentence Splash 구현·인수인계

2026-10-19. HTML 시안은 디자인 참고로만 사용했다. React 정식 컴포넌트이며 iframe을 쓰지 않는다.

## 실행 및 편집

1. **게임 → Sentence Splash** (`/games/sentencesplash`), 분류는 연습하기 / 문장 배열.
2. 게임 화면의 **설정·저장**에서 문장을 직접 고치거나 여러 문장을 한 줄씩 붙여넣고 **입력한 문장 추가**를 누른다.
3. 저장한 **문장 목록**, 기존 **문장 은행**도 가져올 수 있다. 위로·아래로·삭제로 순서를 편집한다.
4. 문장당 30·45(기본)·60·90초를 고르고 **미리보기 적용**을 누른다. 임시 게임은 미리보기만 바뀌고, 이미 저장한 게임은 이때 변경 내용도 저장한다. 실패하면 편집 중 입력은 남는다.
5. 이름을 적고 **새 게임으로 저장**하면 현재 적용한 문장·순서·시간을 복제해 기존 저장 시스템에 보관한다. 저장하지 않은 편집이 있으면 먼저 미리보기에 적용한다.
6. **시작·이어하기 → 게임 시작!**으로 플레이한다. 단독 실행도 가능하다. 수업의 게임 블록에서 Sentence Splash를 고른 뒤 저장된 게임을 연결할 수 있다. 기존 공통 화면의 **수업에 넣기**도 같은 템플릿을 수업에 복사한다.
7. 성공 → 다음 문장 → 전체 결과. 실패하면 정답을 보여 주지 않고 같은 문장에 재도전한다. 마지막에 성공 문장 수·다시 플레이·게임 종료를 보여 준다.

## 기존 시스템 연결

- `GameType`, `GAME_CATALOG`(48번), `GAME_META`, 교사/학생 라우트, `GAME_PAGES`에 등록했다.
- `GameWorkspace`와 `GameThemeFrame`을 사용해 화면 안 설정·팀·순서·일시정지·확대·전체화면을 재사용한다.
- `useGameTemplates`의 인증·반·저장 목록·수업 `GameEmbedContext`를 재사용한다. 저장 전에도 편집·미리보기가 가능하도록 게임 페이지에 7개 예시의 로컬 초안을 둔다. 공통 임시 활동 기능이 없는 배포에서도 동작한다. `sampleCards`는 공통 임시 활동 흐름과 함께 사용할 수 있는 선택 매개변수이며 다른 게임의 기본값은 바꾸지 않는다.
- 저장 모양: `game_type: 'sentencesplash'`, `items: [{id,label}]`, `config.splashSeconds`. 기존 `classroomSource`도 편집 결과와 함께 갱신한다. DB 스키마 변경이나 추가 SQL은 필요 없다.
- `SENTENCE_LIST_GAMES`, `prepareClassroomGame`, `buildGameContent`에 연결해 문장 목록·수업 자료에서 생성할 수 있다. 단어장에서는 예문 또는 두 단어 이상인 문장을 재료로 받는다.
- 블록 레지스트리는 카탈로그에서 자동 생성하며 개념은 `sentenceOrder`로 연결했다. 새 메뉴를 늘리지 않았다.
- 기본 7문장은 데모 소스다. 선생님이 명시적으로 저장하기 전에는 영구 게임을 생성하지 않는다.
- 플레이 컴포넌트는 항목·시간·종료 콜백만 받는다. 학생용 페이지에는 교사용 편집기를 렌더하지 않는다. 숙제 점수/스텟의 새 채점 종류는 이번 범위에 추가하지 않았다.

## 구현 파일

새 파일:

- `app/src/lib/sentenceSplash.ts` — 예시·문장 분리·고유 벽돌·판정·경과 시간·행 배치.
- `app/src/components/SentenceSplash.tsx`, `SentenceSplash.css` — 파스텔 하늘·바다, 클릭/터치/키보드, 시간 게이지, 결과·재도전.
- `app/src/pages/SentenceSplashPage.tsx` — 기존 템플릿을 이용한 교사용 편집·저장·미리보기.

- `app/scripts/games/check-splash.mjs`, `splash.html`, `splash.tsx` — 합성 데이터 검증 전용. 운영 진입점에 포함하지 않는다.
- `docs/sentence-splash-handoff.md` — 이 문서.

등록/연결 수정:

- `app/src/App.tsx`, `components/GameThemeFrame.tsx`.

## 동작 기준과 검증

- 공백으로만 분리해 대소문자·축약형·문장부호를 보존한다. 벽돌 ID는 문장 ID와 원래 위치로 만들며, 같은 글자의 중복 벽돌은 어느 쪽이든 현재 단어와 일치하면 한 번만 사용할 수 있다.
- 단어 폭을 측정해 행으로 배치한다. 모든 행이 같은 거리만큼 움직이므로 이동 중에도 서로 겹치지 않는다. 매우 긴 문장은 터치 영역을 줄이는 대신 게임판 높이가 늘어나 세로 스크롤이 생길 수 있다.
- 낙하와 시간 게이지와 입력 시점 판정이 모두 `gameClock.now()`를 사용한다. 교사 일시정지는 이 시계를 멈춘다. 비활성 탭에서 프레임이 지연되면 복귀/입력 시 실제 경과 시간을 기준으로 판정한다. 마지막 행은 제한 시간에 바다에 도달하며, 남은 단어가 있으면 시간 초과로 실패한다.
- 정오답은 글자·안내 문구·흔들림·완성 칸으로 알린다. 키보드 Enter/Space는 기본 버튼 동작으로 지원한다. 모션 감소 환경에서는 부가 애니메이션을 끈다.
- AI API 및 새로운 외부 라이브러리는 추가하지 않았다. 저장된 문장 5개·50개 모두 일반 로직으로 처리한다.

`cd app; node scripts/games/check-splash.mjs` 검증:

1. 축약형·문장부호·중복 단어 ID/중복 클릭 방지.
2. 다양한 폭과 긴 단어에서 벽돌이 겹치거나 잘리지 않음, 4개 시간 옵션의 낙하 진행률.
3. 문장 목록·수업 자료 변환, 50문장 생성, 원본 자료 유지.
4. 오답 → 정답 → 최종 점수, 시간 초과 정답 숨김, 재도전, 공통 시계 일시정지.
5. 1440/768/390px 실제 브라우저에서 벽돌 영역·가로 넘침 검사. 모바일 PNG도 직접 확인.
6. 기본 7개 라운드를 키보드로 모두 완료, 7/7 결과와 종료.
7. 여러 문장 추가·순서 변경·삭제·시간 설정·저장 실패 시 입력 유지·재시도·저장·새로고침 후 재실행.
8. 실제 `GameEmbedContext`와 `GAME_PAGES`로 저장한 템플릿 실행.
9. 학생 편집기 없음, 브라우저 오류 없음, AI/운영 백엔드 네트워크 요청 없음.
10. 실제 게임 목록에서 Sentence Splash 카드·썸네일·실행 경로 표시.

`npm run build`(TypeScript 포함) 및 `npm run lint`는 통과했다. 린트는 오류 0개이며 저장소의 기존/동시 작업 경고가 남아 있다. 기존 `check-workspace-logic.mjs`의 자료 변환·다중 일시정지 소유자·타이머 취소/재개 검증도 통과했다.

실제 계정이나 운영 학생 데이터는 테스트에 쓰지 않았다. 운영 저장 권한은 기존 인증/RLS를 그대로 사용한다. 운영 DB에서 직접 생성·삭제하는 검증은 하지 않았다. 커밋·배포는 이번 기능 구현에 포함하지 않았다.
