# 아이스크림 가게 배치·동작 점검 (2026-10-26)

범위: 아이스크림 가게의 메뉴/주문/결과/짝 연습에서 공유하는 조립 그림 및 주문 흐름. 다른 게임 전체를 점검한 결과는 아니다.

## 발견 및 수정

- 컵 스쿱이 입구 위에서 뜸: 컵 1·2스쿱의 아래쪽 기준을 46/48%에서 34/36%로, 3스쿱 위쪽을 64%에서 52%로 조정했다. 컵 입구와 스쿱 하단이 겹친다.
- 스프링클·소스의 고정 높이: 실제 표면 스쿱 좌표에서 토핑 위치와 크기를 계산한다. 컵 2스쿱에는 두 표면에 분배한다. 스쿱 이미지 윤곽으로 토핑을 제한해 주변에 떠 보이지 않는다.
- 초코 플레이크 과소 표시: 콘에서 14%였던 너비를 스쿱 너비의 64%(콘 기준 약 42%)로 확대한다. 컵에서도 스쿱 크기에 비례하고 실제 위쪽 스쿱에 붙는다.
- 큰 3스쿱 콘: 기존 조립 높이가 자체 표시 영역을 넘을 수 있어 전체 조립 그림을 88%로 맞췄다. 메뉴·결과·주문 카드에 같은 조정이 적용된다.
- 담기 종류 → 크기 순서로 선택하면 주문 문장 음성이 빠짐: 마지막에 크기를 고르는 경우에도 완성된 주문 문장을 읽는다.
- 다시하기/다른 단계/나가기에서 이전 음성이 이어질 수 있음: 브라우저 음성을 취소한다.

이미지 파일은 덮어쓰지 않았다. 스쿱 9종은 파일 비율이 비슷하고 투명 여백도 작아 이번 문제는 원본 크기보다 조립 좌표에서 발생했다. 위에서 조정한 이미지 외 추가 재제작이 필요한 크기 불일치는 이번 점검에서 찾지 못했다.
