# Claude 인수인계: 게임 → 학생 스탯 → 맞춤 숙제·개별수업 (2026-10-19)

사용자는 기존 학생 스탯을 분석한 뒤, 그 구조를 유지하면서 게임 수행을 숙제·개별수업에 연결하고 필요한 SQL을 알려 달라고 요청했다. 이번 작업은 로컬 구현과 합성 검증까지 완료했다. 운영 SQL 실행·커밋·배포는 하지 않았다.

## 사용자가 실행할 SQL

Supabase SQL Editor에서 아래를 **각각 순서대로** 실행한다.

1. `supabase/088a_game_learning.sql` — 게임 확인 문제·문항별 서버 채점·학습 이벤트.
2. `supabase/088b_personal_game_review.sql` — 기존 숙제/개별수업/게임 기록 통합 추천, 다음 수업 맞춤 복습, 성장 근거, 교사 게임 결과.
3. `supabase/088_check.sql` — 읽기 전용 확인. 반환 칸이 모두 `true`여야 한다.

선행 기능은 기존 숙제 041, 개별수업/복습/스탯 047~065, 게임 템플릿 069, 기능 가드 074다. 088은 기존 운영 환경에 이 기능들이 적용되어 있다는 전제다. **이번 변경 때문에 087 숙제 블록 SQL을 다시 실행할 필요는 없다.** 각 적용 파일은 트랜잭션으로 묶었고 재실행을 검증했다. 기능 스위치·기존 학생 기록·스탯 등급을 일괄 변경하는 SQL은 없다.

`supabase/088_rollback.sql`은 문제가 있어 되돌릴 때만 쓴다. 정상 적용 과정에서는 실행하지 않는다. 앱의 이번 학습 게임 변경도 함께 복원해야 하며, 이 SQL은 모은 학습 기록과 추가 테이블을 삭제하지 않는다. 기존 주요 함수는 088b 첫 실행 때 보관한 정의로 복원한다.

## 완성한 사용자 흐름

### 교사: 같은 자료로 학생별 게임 연습

- 숙제 화면의 **학생별 맞춤 게임**에서 공통 단어장을 선택한다.
- 기존 학습 기록으로 약한 영역·복습 대상·새 단어를 섞고 이유를 표시한다. 근거가 부족하면 공통 복습임을 명시한다.
- 선택한 자료 밖의 단어는 넣지 않는다. 같은 철자의 뜻이 다른 경우 과거 기록을 그대로 약점으로 취급하지 않는다.
- 글자 순서·철자 쓰기·듣기·보기 고르기 등 기존 서버 채점 가능한 학습 활동을 게임 묶음으로 만든다. 새 아케이드 게임 엔진을 생성하는 기능은 아니다.
- **숙제로 보내기 / 개별수업으로 내기**를 고른다. 미리보기와 학생·활동 제외 후 교사가 확인 버튼을 눌러야 생성/발송한다.
- 일부 학생 발송 실패 시 이미 성공한 학생을 제외하고 재시도한다. 같은 화면에서 개별수업 생성 후 배정이 실패해도 만든 수업 ID를 재사용한다.
- 교사용 게임 화면의 **같은 내용으로 다른 게임** 창에서 **이 자료로 맞춤 게임 숙제·개별수업 만들기**를 눌러 현재 단어 자료를 가져갈 수 있다. 자료 출처가 있고 영어 낱말 자료인 경우 제공한다. 수업 발표 중에는 이 경로로 수업 밖으로 이동시키지 않는다.
- 자료를 가져올 때 반을 먼저 맞추고 해당 반 학생 명단 로딩이 끝난 뒤 추천창을 연다. 원본 단어장과 게임 템플릿은 수정하지 않는다.

### 학생: 개별수업 게임 뒤 짧은 확인

- 대상은 기존 혼자 하기 게임 **매치업·애너그램·두더지잡기·워드서치·행맨 5종**이다. 교사용 47개 게임 전체를 숙제용으로 전환했다고 표현하지 않는다.
- 게임 시작 시 확인 문제를 서버에 고정한다. 게임을 마치면 **혼자 확인하고 마치기**로 최대 4문항을 푼다.
- 짝 게임은 실제 짝의 뜻 고르기, 출처 뜻이 있는 단어 게임은 철자 쓰기, 뜻이 없는 영어 낱말은 받아쓰기를 확인한다. 출처에만 남고 현재 게임에서 빠진 단어는 확인 문제에서 제외한다. 적절한 자료가 없으면 완료만 기록한다.
- 게임 자체의 점수·운·반응 속도는 능력 점수로 받지 않는다. 확인 문항의 응답을 서버가 채점해 기존 `learning_events`에 저장한다.
- 확인 문제를 열어도 답 기록은 생기지 않는다. 첫 답과 재도전은 분리하고, 같은 날 같은 낱말·능력을 다른 게임 확인에서 반복하면 재도전으로 기록한다. **이 추가 중복 제한은 개별수업 게임 확인 경로에 적용하며, 기존 숙제/일반 수업의 전체 채점 규칙을 소급 변경하지 않는다.**
- 저장 실패 시 다음으로 넘기지 않으며 같은 요청 ID로 재시도한다. 새로 열어도 완료한 확인 문제와 첫 답을 유지한다.
- 확인 결과는 학생 끝 화면과 교사 수업 현황에도 반영한다. 확인 문제 2개 이상을 어려워하면 진행 중 수업의 기존 도움 요청에 표시한다.
- 교사는 게임 단계의 **게임 뒤 짧은 학습 확인을 하고 학생 스탯에 반영**을 끄면 완료만 기록하게 할 수 있다. 학생에게는 설정 UI가 없다.
- SQL이 아직 없으면 점수를 만들어 넣지 않고 완료만 기록한다는 안내를 표시한다. 일반 통신 실패를 SQL 미적용으로 숨기지 않는다.

### 다음 개별수업: 지난 숙제에서 이어지는 준비 연습

- 학생 홈에 **오늘의 맞춤 시작 연습**, 수업 시작 화면 위에 **지난 숙제 맞춤 몸풀기**를 제공한다.
- 숙제·게임 확인·개별수업 낱말 기록을 합쳐 서버가 최대 6문항을 만든다. 철자가 어려우면 철자, 듣기가 어려우면 듣기 등 기존 채점 단계로 연결한다.
- 수업 전 몸풀기 후 원래 수업으로 돌아갈 수 있다. 교사가 만든 수업 순서를 자동으로 변경하거나 복습을 강제하지 않는다.
- 같은 날 같은 수업 전 준비 연습은 기존 배정을 재사용한다. 자료가 부족하면 가짜 문제를 만들지 않고 원래 수업을 시작하도록 안내한다.
- 기존 ‘어제 복습/다시 배우기’도 숙제에서 만난 낱말을 사용할 수 있게 했다. 진행 중인 다른 복습을 삭제하지 않는다.

## 기존 스탯과의 관계

5개 능력, 세부 능력 태그, 처음 답 기준, 최소 30개 채점/3개 활동·세부 8개, 최근 기록 가중치와 등급 구간은 유지한다. 종합 등급에는 꾸준함이 포함됨을 카드에 표시하고 세부 능력별 근거 수를 함께 보여 준다.

학습 카드에 별도 **게임으로 확인한 성장**을 추가했다. 게임 숙제와 게임 확인의 처음 답 중 혼자 맞힌 낱말 수, 같은 능력에서 하루 이상 뒤 다시 맞힌 낱말 수, 서로 다른 능력에서 맞힌 낱말 수를 표시한다. 이것은 새로운 능력 등급이나 심리검사 수치가 아니다. 다른 능력 확인이 문맥 전이 전체를 보증한다고 표현하지 않는다.

## 검증

명령은 `app`에서 실행한다. 모두 합성 자료/임시 DB/로컬 브라우저를 사용하며 실제 계정이나 운영 DB에 접속하지 않았다.

- `node scripts/games/check-learning-db.mjs`: PostgreSQL WASM에서 9개 검증 묶음 통과. 최신 기존 채점/공개 문제 함수(065)와 학생 열기(051)를 사용한다. 다른 학생/토큰·권한·기능 가드, 정답 제거, 스냅샷, 첫 답/재전송/재도전, 같은 날 중복, 추천/복습/스탯 합류, 성장/교사 결과, SQL 확인, 재적용·복원/기록 보존을 검증한다.
- `node scripts/games/check-personal-games.mjs`: 6가지 약점 영역의 자료 범위, 원본 보존, 숙제→개별수업 변환과 실제 채점 일치, 근거 부족·빈 자료 검증 통과.
- `node scripts/games/check-learning-browser.mjs`: 실제 매치업→확인→저장 실패 재전송→완료, 학생 설정 없음, 학생별 다른 게임 추천, 교사 확인 후 발송, 부분 실패 재시도, 개별수업 배정, SQL 미적용 안내, 실제 숙제 페이지 자료 가져오기, 768/390 폭 통과. React 콘솔 오류도 실패로 처리한다.
- `node scripts/games/check-workspace.mjs`: 기존 교사용 47개 설정창·게임 전환·내수업 발표 회귀 검증 통과.
- 기존 숙제 `check-logic.mjs`, `check-blocks.mjs`(17개 DB/블록 검증), 개별수업 `check-review.mjs`, `check-test-block.mjs` 통과.
- `npm run build` 및 TypeScript 통과. 전체 lint 오류 0개, 기존 경고 58개.

브라우저/DB 테스트 도구는 이전 작업에서 설치된 로컬 `node_modules/homework-test-tools` 아래 Playwright·PGlite를 사용한다. 외부 HTTPS는 브라우저 검증에서 차단한다. 웹폰트 차단으로 합성 스크린샷에 기존 아이콘 이름이 글자로 보일 수 있다.

## 남은 운영 확인과 범위

운영 SQL 적용 후 테스트 학생으로 게임 확인→스탯→맞춤 숙제→다음 수업 몸풀기를 확인해야 한다. 실제 태블릿의 터치·음성 재생, 여러 기기에서 장시간 중단/복구는 아직 운영 검증하지 않았다.

맞춤 자동 선택은 현재 단어 기반 능력 중심이다. 읽기 지문·문장 이해 전체, AI 말하기 채점, 학습 난이도의 통계적 보정, 47개 전체 게임의 개인 플레이 지원을 이번에 구현했다고 주장하지 않는다. 기존 스탯 집계 공식과 과거 점수를 일괄 재계산/마이그레이션하지 않았다.

이전 작업인 숙제 블록 편집기 및 교사용 게임 작업 화면의 변경을 포함한 미커밋 상태에서 이어 작업했다. 기존 미추적 그림 생성물과 제안서 PDF는 수정하지 않았다. 커밋할 때 관련 없는 파일을 섞지 않는다.
