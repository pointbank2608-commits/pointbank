# 단어 뽑기 일반 모드: 뜻에 맞는 영어 단어 뽑기

- 일반 모드는 각 라운드의 목표 단어·뜻·보기 묶음을 만든다. 뜻을 화면에 보여 주고 같은 뜻으로 등록된 영어 단어만 정답으로 인정한다. 정규화 비교는 기존 어드벤처 `wordKey`를 재사용한다. 문법 분류 태그·예전 `missions` 설정은 사용하지 않는다.
- 최대 12개 보기에는 목표 단어를 항상 포함한다. 앞 라운드에서 뽑힌 단어를 보기에서 제외하지 않아, 많은 자료의 뒤쪽 문제나 마지막 문제에서도 정답이 사라지지 않는다. 전체 라운드 수·문제 순서 섞기 설정은 유지한다.
- 오답은 기존 집게 놓침 애니메이션으로 돌아오고 획득함·완료 결과에 추가하지 않는다. 같은 뜻으로 다시 시도할 수 있다. 정답은 기존 획득 애니메이션·정답 확인·다음 문제 흐름을 따른다. 쉬운 모드도 같은 판정이다.
- 일반 모드의 뜻 누락은 기존 입력 검증에서 안내한다. 그림 모드는 뜻이 없어도 기존 그림 문제와 정답으로 실행하고, 편집·저장 시에도 모드를 구분해 검증한다. 저장 형식을 바꾸거나 운영 자료를 변환하지 않고 실행할 때 기존 단어/뜻으로 문제를 만든다.
- 기존 교실 게임 엔진의 관찰용 `LearningRecord`에 실제 제시한 뜻과 정답 영어·뜻을 전달한다. 자료 ID는 기존 단어 ID, 실행 라운드 ID는 목표 단어 ID를 유지한다. 새 서버 채점·학생 평가 지표·분석 수집을 추가하지 않는다. 클라이언트 게임 정오 판정을 서버 채점 근거로 간주하지 않는다.

검증: `node app/scripts/games/check-claw-meaning.mjs` 및 프로덕션 빌드 통과. 인증/API가 분리된 로컬 fixture와 가짜 키, 센서 false만 사용한다. 일반 모드 오답·재도전·정답·다음 문제·결과, 쉬운 모드, 동일 뜻의 다른 단어, 저장 후 재실행과 16개 목표가 12개 보기에서 빠지지 않음, 뜻 누락 안내, 뜻 없는 그림 문제의 정답·오답을 확인했다. `CLAW_OUTPUT` 지정 시 새 뜻 문제 화면을 JPG로 저장한다.
