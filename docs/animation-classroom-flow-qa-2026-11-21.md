# 애니메이션 영어 수업 흐름 — 2026-11-21

## 구현 범위

- 상세 하단을 `영상에 질문 넣기 → 활동지 → 이 영상으로 수업 만들기`로 정리했다. 기존 편집창·영상별 활동지·수업 구성 콜백을 연결한다. 학습 장면 재생과 듣고 따라 하기 하단 버튼은 제거했다.
- 썸네일 재생 전에 현재 교사·영상의 최신 질문 편집본을 조회한다. 편집기와 동일한 조회 함수를 사용한다. 저장본이 없으면 같은 플레이어에서 질문 없이 일반 재생한다. 질문 조회 실패 시 질문 없는 영상으로 조용히 대체하지 않고 재시도를 제공한다.
- 기존 절대 초 저장 형식과 학습 구간 오프셋을 유지한다. 플레이어가 질문 시점을 통과하면 자동 정지한다. 기존 학생 문항 UI를 영상 오른쪽 위에 겹쳐 표시하며 객관식 보기는 세로로 배치한다.
- 별도 계속 보기 버튼을 제거했다. 질문 중에도 기존 재생 버튼이 활성 상태로 남아, 누르면 해당 질문을 처리한 것으로 표시하고 이어 재생한다. 다음 질문은 독립적으로 정지한다.
- 편집 중 일시정지에서 준비된 영상을 덮던 앱 재생 오버레이를 제거했다. 시간 이동과 일시정지는 플레이어를 재생성하지 않는다.
- 동일한 플레이어에서 듣고 따라 하기로 전환한다. 실제 재생 시각으로 현재/마지막으로 들은 대사를 선택하고, 문장 처음부터 끝까지 재생한 뒤 마지막 프레임에서 멈춘다. 문장 이동은 위치 이동과 버퍼 상태를 확인한 뒤 표시 문장을 갱신한다.
- 수업 설정 안에서만 배속을 고른다. YouTube가 제공하는 기존 범위를 사용하며, 기본값을 바꾼 경우 설정 버튼에 현재 배속을 표시한다.
- 질문 번호와 재생 진행점은 동일한 트랙 좌표를 사용한다. 질문 뒤로/재생/앞으로 및 문장 이전/듣기/다음의 높이·아이콘·라벨 정렬을 맞췄다.

## 센서·운영 자료

기존 질문 표시·응답·정답 공개 관측을 유지한다. 저장된 수업 블록에서 문장 듣기는 공통 활동 센서의 audio 관측을 사용하며, 별도의 문장 문항 ID나 서버 채점 근거를 만들지 않는다. 카탈로그 재생의 수업 버전·개별 문장 학습 성과는 이 관측으로 확정할 수 없다. 문항 미리보기와 합성 계정의 검증에는 운영 학습 센서를 사용하지 않는다. DB 형식·API·권한 변경은 없다.

## 검증 결과

GPT 내장 브라우저로 검증했다. 사용자 컴퓨터의 창과 마우스는 조작하지 않았다. 첨부 PDF 5쪽을 이미지로 확인했으며, 실제 기능 요구는 사용자 메시지를 기준으로 구현했다.

- 운영 원래 경로에서 상세 하단 5개 진입점, 썸네일의 일반 플레이어와 별도 질문 재생 경로, 외부 배속 선택창을 확인했다.
- 합성 저장소와 실제 Bluey YouTube 연결 영상(24.50~89.50초)을 사용했다. 편집기에서 14.01초 객관식·18.23초 말하기 질문을 저장한 뒤 편집창을 닫고 썸네일로 열었다. 첫 질문 자동 정지·선택·정답 공개·아래 재생 버튼으로 계속·다음 질문 자동 정지를 확인했다. 별도 계속 보기 버튼은 없다.
- 질문 없는 다른 영상은 질문·번호 없이 실제 재생됐다. 교사/영상별 최신 저장본 선택과 원본 시각 보존은 데이터 회귀 검사로 확인했다.
- 편집 중 실제 재생 → 질문 추가에서 iframe ID가 유지됐고 앱의 흰 재생 덮개가 없었다. 재생바로 14.01초를 고르면 영상 프레임과 질문 입력이 해당 장면으로 갱신됐다.
- 6초에서 듣고 따라 하기로 전환하면 재생 위치 6초·같은 iframe·현재 문장 2/2가 유지됐다. 문장 듣기는 5.5초부터 시작해 9.46초에 멈추고 따라 말하기·다시 듣기를 표시했다. 0.75배의 4초 문장 구간이 로딩을 포함해 약 5.95초에 완료됐다. 다시 듣기·이전 문장(0.5초)·다음 문장(5.5초)에서도 iframe을 유지했다. 이 로컬 대본은 합성 테스트 문장이며 실제 대사 정확성 검토 자료가 아니다.
- 0.75배 질문 수업도 첫 질문 14.01초에서 멈췄다. 활성 번호 중심과 진행점 계산 차이는 0.01px 미만이었다. 브라우저 자동 대기 한 번은 제한 시간에 도달했지만, 직후 화면에 정상 정지한 질문과 14.01초가 표시된 것을 확인했다. 영상 자체의 PLAYBACK_TIMEOUT은 발생하지 않았다.
- 대상 oxlint, `check-animation-flow.mjs`, 기존 `check-video-questions.mjs`, 프로덕션 빌드 통과. 실제 0.75배 재생과 재생바 좌표 검증은 내장 브라우저에서 수행했다.

운영 DB에 테스트 질문을 쓰지 않았다. 합성 저장/복원과 실제 YouTube 재생을 구분한다. 운영 실제 대본의 문장 번호·해석 및 기존 활동지·수업 구성 진입은 배포 후 사용자 경로에서 추가로 확인한다. 증거는 `output/animation-flow/`에 보관한다.
