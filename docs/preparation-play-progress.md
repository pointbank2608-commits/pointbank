# 게임 우선 준비·집중 플레이 개편 (2026-10-19)

현재 저장소의 React/Vite·Supabase 구조를 유지했다. 루트와 상위에 AGENTS.md가 없음을 확인하고 CLAUDE.md·README·기존 인수인계를 읽었다. 기존 미커밋 변경과 Sentence Splash를 보존했다. 구현·검증 중에는 DB 마이그레이션·운영 변경·배포·커밋을 수행하지 않았다. 이후 사용자 요청으로 이 변경을 커밋하고 main에 푸시해 Vercel 자동 배포를 진행한다. 관련 없는 생성물과 임시 파일은 제외하며 추가 DB 적용은 없다.

## 화면과 재사용

홈은 게임/활동지 → 자료 생성/불러오기 → 추천 게임 → 최근 실제 자료 → 내 수업 순서다. 홈·주요 게임 메뉴는 전체 목록으로 열며 저장한 게임 탭도 유지한다. 게임·활동지·내 단어·문장·내 수업·우리 반을 직접 찾을 수 있고 기존 기타 메뉴도 유지한다. 자료가 없는 계정에 가짜 최근 기록을 넣지 않는다.

내 단어·문장은 상단 두 생성 버튼과 전체/단어장/문장 필터, 문장용 이름/생성 문구를 제공한다. 기존 그룹·이전 버전·편집기를 유지한다. 목록 조회 응답과 계정 전환·자료 생성이 충돌하지 않게 순서를 보호한다.

게임 생성 버튼은 **기존 게임 페이지 항목 편집기**를 준비 패널로 연다. 별도 공통 텍스트 입력기는 제거했다. 지원 자료 버튼만 표시하고 기존 변환 함수와 native config로 항목 수·정답·그림·분류를 검증한다. 내장 대본·수학·가게·타이머에는 공통 단어 입력을 강요하지 않는다. 다이어그램은 이미지와 핀이 필요하다.

영구 저장 체크는 기본 해제이며 체크할 때만 이름을 요구한다. 원본 저장과 게임 구성 저장을 구분하고 저장 실패 때 입력·이름을 남겨 재시도한다. ref 잠금으로 중복 생성을 방지한다. 샘플은 DB 자료나 수업을 만들지 않는다.

word_lists(kind=word/sentence)는 재사용 원본, game_templates(items/config)는 게임 구성, curriculum_lessons.playlist는 활동 순서다. 스키마를 바꾸지 않았다. 원본은 복제해 임시 구성에 쓰며 자동 덮어쓰기하지 않는다. 기존 저장 게임의 명시적 설정 편집은 종전 동작을 유지한다. 같은 자료로 다른 게임·활동지로 이동하며, 수업 추가는 기존/새 수업을 직접 고른 뒤 저장한다. 기존 수업 append는 updated_at 조건으로 동시 수정 덮어쓰기를 거부한다.

## 준비와 집중 플레이

준비 화면 맨 위에 [← 게임 목록] 링크를 제공한다. 전체 게임 목록으로 이동하며, 같은 게임으로 돌아오면 저장하지 않은 작성 내용은 기존 임시 복구 슬롯에서 이어 쓴다. 키보드 Enter 이동과 모바일 표시를 브라우저에서 확인했다.

준비는 자료·게임별 설정·참여 방식·선택적 저장을 담당한다. 플레이는 **동일한 게임 컴포넌트와 DOM을 유지**하며 viewport에 게임을 크게 보여준다. 앱 내비게이션·공통 헤더·편집 목록·추가 관리 영역을 접고 선생님 메뉴로 이동한다. 전체화면 API가 거절돼도 집중 레이아웃은 동작한다.

메뉴에서 로컬 gameClock을 멈추고 게임 단축키가 편집 입력을 가로채지 않게 한다. 메뉴 닫기·준비 복귀·크기 변경은 판을 다시 마운트하지 않아 진행을 유지한다. 원래 다시하기/undo는 유지한다. 다른 게임으로 이동하면 같은 내용의 새 판이며 점수는 합산하지 않는다. 새로고침 복구 대상은 내용·설정이고 진행 중 점수/물리 상태 영구 저장은 추가하지 않았다.

적절한 범위에서 게임을 확대하며, 긴 문장·많은 항목을 너무 작게 줄이지 않도록 최소 배율 아래에서는 내부 스크롤을 사용한다. 항목이나 필수 버튼을 삭제하지 않는다. 모바일에서도 메뉴·스크롤·기존 터치/키보드 조작을 사용할 수 있다.

수동 순서 게임에만 선택적으로 임시 참여자·반 명단·제외·섞기·순서 이동·여기서 시작·팀 이름·현재/다음을 제공한다. 마지막에서 처음으로 순환하며 한 명이면 현재=다음, 0명이면 표시하지 않는다. 기존 팀/자동/동시 진행에 별도 다음 참여자를 덧붙이지 않는다.

## 임시 보존

임시 구성은 사용자·학원·게임별 sessionStorage 한 슬롯에 보존한다. 작성 종류 전환용 슬롯은 단어/문장 각각 하나다. 기존 항목 편집기에 아직 추가하지 않은 텍스트도 useRecoverableField로 이 탭에서 복구하며 DB 저장과 구분한다. 과거 공통 입력란의 텍스트는 복구만 지원한다. 다른 계정/학원의 자료 전달·임시 수정은 거부한다. 기존 구성의 일반 항목·짝은 재사용 가능한 원본으로 추론한다.

## 실행한 검증과 한계

- npm run build: TypeScript/Vite 통과. 기존 큰 chunk 경고 존재.
- npm run lint: 오류 없이 완료. 기존 훅 의존성·Fast Refresh 등 경고 존재.
- check-preparation-play.mjs: 실제 AppLayout/라우트/기존 편집기·게임 + 합성 API를 Chrome에서 확인. 홈 우선순위/전체 목록, 매치업 무저장 작성·실제 짝 맞추기/undo, pause/resume·준비 복귀 DOM/진행 보존, 저장 실패/재시도/중복 클릭, 자료 재사용, 전체화면 거절, 모바일, 현재/다음 순환·제외·한 명 경계, 틱택토 실제 수·원래 차례, 타이머 START/STOP/결과, 온라인 교실 미리보기 제약, 긴 문장 24개/내부 스크롤, 추가 전 텍스트·단어/문장 전환 복구 통과.
- check-workspace.mjs: 48개 기존 설정 열기/닫기 실행 오류 없음. 공통 시계·반 명단 제외, 기존 수업 게임 교체 시 후속 활동·따라보기 snapshot 보존 통과.
