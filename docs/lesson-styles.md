# 내 수업 틀 (2026-10-30)

수업의 **구조**(슬라이드 종류·순서·게임 종류·보조 블록·고정 슬라이드)만 저장해 두고, 다른 단어장이나 문장 모음을 고르면 같은 모양의 수업을 다시 만드는 기능. 수업 준비 시간을 줄이려는 사용자 제안(단체수업 1차).

## 쓰는 법
- 저장: 내 수업 카드 → "더보기" → **내 수업 틀로 저장**(이름을 정한다).
- 사용: 내 수업 위쪽 **내 틀로 시작** → 틀 고르기 → 반·단어장(또는 문장 모음) 고르기 → "이렇게 만들어져요" 미리보기 → **이 틀로 수업 만들기** → 바로 시작/자세히 편집.

## 슬라이드를 어떻게 다루나 (`lib/lessonStyles.ts` `planStyle`)
| 틀의 슬라이드 | 단어장으로 | 문장 모음으로 |
|---|---|---|
| 단어 소개·카드로 외우기 | 새 단어장의 낱말로 채움 | 뺀다 |
| 게임 | 같은 종류의 게임 내용을 새로 만든다(게임 센터에도 보임, 이름 `수업 · 단어장`) | 문장 게임(문장 배열하기·문장 스플래시)만 만들고 나머지는 뺀다 |
| 자료실(워크시트 등) | 낱말을 비워 수업 단어장을 따라가게 한다 | 뺀다 |
| 그 밖(직접 만들기·영상·노래·문법·STEM …) | 그대로 복사(고정) | 그대로 복사 |
단어/문장 입력 분리 규칙(2026-10-28)에 따라 단어 게임에 문장을 넣지 않는다. 재료가 모자라 못 만드는 게임(예: 낱말에 예문이 없어 문장 배열하기를 못 만듦)은 건너뛰고 건너뛴 수를 알려 준다.

## 저장 위치와 한계
- **이 브라우저의 localStorage**(`classbank.lessonStyles.<학원 id>`, 최대 30개). 서버 표·SQL은 만들지 않았다(운영 DB 변경 없음). 다른 컴퓨터에서는 안 보인다.
- 틀에는 게임 설정(팀 수·시간 등 게임 템플릿의 config)을 저장하지 않는다 — 새 게임은 기본 설정으로 만들어진다.
- 개별수업 틀·학원 공용 틀은 아직 없다.
- 다음 후보: 서버 저장(학원 공유 틀, SQL 필요 — 별도 승인), 게임 설정 보존, 개별수업의 "내 블록 조합"(054)과 합치기.
