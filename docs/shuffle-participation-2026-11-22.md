# 컵 속 친구 찾기 개인·팀 설정 연결

공통 반 설정에서 개인을 선택해도 본체가 `shuffleTeams`만 읽어 차례·점수·결과를 팀으로 표시했다. 게임 설정에 `shuffleMode`를 저장하고 출석 학생 또는 팀 이름/순서로 참여자 목록을 만든다. 개인/반 없음은 ‘나’, 반이 있는 개인은 출석 학생 이름, 팀은 팀·순서 정하기의 팀 이름과 순서를 쓴다. 없음은 차례·점수·순위와 +1점 안내를 숨긴다.

본체의 점수 및 자동 차례 진행은 동일한 참여자 인덱스를 사용한다. 명단이나 참여 방식이 바뀌면 점수와 진행을 초기화해 다른 학생에게 이전 점수가 이어지지 않는다. 개인 결과는 학생 수에 맞춰 열을 나누고 글자를 맞춘다. 그림 문제 옵션은 유지한다.

참여자 목록 생성은 텔레파시에서 검증한 로직을 `gameParticipants.ts`로 옮겨 공유했다. 텔레파시의 기존 내보내기는 호환을 유지한다. 학생 명단·결석·순서 조회는 `useGameParticipants.ts`에서 처리한다.

검증: `check-shuffle-participation.mjs`(반 없이 개인 재열기, 실제 학생 이름·차례·점수, 결석 제외, 저장한 수업을 다시 열어 발표, 사용자 지정 팀 이름/순서, 없음, 그림 옵션 유지), 기존 `check-shuffle.mjs`, 텔레파시 참여 회귀 검사, 앱 빌드.

기존 공통 센서를 유지한다. 게임 점수를 서버 채점 근거나 학습 성취로 바꾸지 않으며 합성 응답 검증은 인증/API를 격리하고 센서를 끈 로컬 환경에서만 수행한다.
