## 사용

- 게임 메뉴 → 파닉스 게임, 기존 게임 화면 상단 카테고리, 자료 → 파닉스에서 진입.
- 목록: `/phonics-games?unit=course-4-1`.
- 개별 게임: `/phonics-games/sound-train?unit=course-2-1`.
- 수업 슬라이드의 **이 유닛으로 파닉스 게임**은 현재 유닛 ID를 유지한다.
- 단계 → 수업 유닛 → 게임 → 문제 수(3/6/10) → 시작. 지원하지 않는 규칙·검토 중 문장·그림 부족은 이유를 안내한다. 잘못된 ID를 다른 수업으로 바꾸지 않는다.
- 교사용 인증 경로 안에 있으며 기존 파닉스와 같은 요금제 경계를 적용한다. 학생 화면·로그인은 추가하지 않았다.

## 게임 구성

40개 항목에 실제 플레이·정답·재시도·완료 흐름을 연결했다. 핵심 조작을 공유하며 학습 규칙·문제 생성·표현을 달리한다. 40개의 독립된 대형 게임 엔진이라는 의미는 아니다.

| 범위 | 게임 |
|---|---|
| 1–5 · 알파벳 | 소리 풍선, 알파벳 짝꿍, 소리 바구니, 글자 탐험대, 글자 길 그리기 |
| 6–10 · 단모음 | 소리 기차, 첫소리 변신, 워드패밀리 집, 모음 수리소, 소리 발판 |
| 11–15 · 매직 e | 매직 e 다리, 매직 e 연구소, 매직 e 조립소, 패밀리 열차, 끝 e 구조대 |
| 16–20 · 자음 | 두 소리 출발!, 한 소리 친구, 앞뒤 소리 탐정, 다른 친구 찾기, 자음 조각 수리 |
| 21–25 · 모음 조합 | 같은 소리 두 길, 두 소리 oo, ow 갈림길, 모음 조합 요리사, R 소리 여행 |
| 26–30 · 공통 | 소리 낚시, 몬스터 식당, 기억 카드, 사라진 카드, 그림 퍼즐 |
| 31–35 · 공통·문장 | 소리 빙고, 단어 보물찾기, 소리 분류 공장, 읽고 움직여, 문장 다리 |
| 36–40 · 모험 | 파닉스 농장, 공룡 탐험, 우주 구조대, 파닉스 섬, 우리 이야기책 |

모험은 3개 이정표와 미니게임 미션을 이어가는 첫 버전이다. 자유 이동 월드·캐릭터 육성·영구 수집품·장기 세이브는 포함하지 않는다. 게임별 안정적 ID·지원 단계·목표·조작은 `app/src/lib/phonicsGames.ts`가 관리한다.

## 학습 규칙

- `courseUnits()`와 공통 curriculum/words를 참조한다. 기존 단어·뜻·규칙·순서·기본/확장은 수정하지 않았다.
- `fetchPhonicsBank()`의 기존 그림 정보를 수업 데이터에 병합하며 실패하면 공통 로컬 자료를 유지한다. OW 비교의 과거 유닛은 공통 기준에서 읽는다.
- 워드패밀리는 수업 그룹 ID로 구분한다. 같은 소리의 다른 철자는 철자 분류로 안내한다. 소리만으로 구별할 수 없는 철자를 단독 듣기 정답으로 요구하지 않는다.
- 매직 e는 떨어진 위치를 보존한다. 자음군 조립은 자음 두 글자를 유지하고 이중자음 빈칸은 목표 묶음을 사용한다. 모든 철자 조각을 음소 하나라고 설명하지 않는다.
- Q/q 글자 게임은 Q를 사용하며 단어 내부 강조는 `qu`를 유지한다. X는 box·fox·six의 실제 위치를 사용한다.
- th·oo·ow의 서로 다른 발음 ID를 유지한다. OW 비교는 두 발음을 배운 5단계 Unit 6 이후에만 허용한다. 시작 화면에 Unit 3·6의 복습임을 안내한다.
- `teachingReview.json`의 문맥 의존 단어는 그림 정답 게임에서 제외하고 읽기·철자·분류에는 유지한다. 명확한 그림 단어가 2개 미만이면 해당 게임은 시작하지 않는다.
- 선택지는 실제 단어 수에 맞게 줄인다. 분류는 2개 이상 규칙·패밀리가 필요하다.
- 문장·이야기책은 `reading.status === approved`인 유닛에서만 시작한다. 현재 ABC Unit 1과 Level 4 Unit 1이며 나머지 초안을 게임에서 승인하지 않는다.

## 소리·진행·결과

- 기기 내 영어 TTS로 **전체 단어·문장**을 읽는다. 개별 음가 녹음은 없으며 교사 모델링으로 안내한다. 유료 음성 API를 호출하지 않는다.
- 음성 미지원·실패는 교사가 읽도록 안내한다. 그림 실패는 빈 그림 대신 단어를 제공한다.
- 시간 제한과 자동 다음 문제 전환은 없다. 일시정지해도 조립·기억·정답 상태를 유지한다. 큰 화면·Escape·나가기 확인을 제공한다.
- 첫 시도 정답과 오답·힌트 후 완성을 구분한다. 따라 쓰기는 교사 확인 활동으로만 센다. 자동 필기 인식이나 장기 숙련도 평가를 주장하지 않는다.
- 점수·진행은 현재 세션의 메모리 상태다. 페이지를 벗어나면 초기화된다. DB·숙제·학생 스탯에 쓰지 않는다. 새 SQL·패키지·환경변수는 없다.
- 한국어·영어와 반응형 UI를 제공한다. 따라 쓰기는 터치·포인터 입력이다.

문제 조합 7,000개, 40개 ID와 42개 수업 유닛 검사 통과. 실제 Chrome에서 40종 각각 3문제 완료·결과 도달, 모험의 미션 전환을 확인했다. 추가로 오답·힌트 결과, 조립 중 일시정지, Q/X 유닛, 음성 오류, 그림 실패 대체, 영어 전환, 390px 모바일 가로 넘침 없음을 확인했다.

기존 승인 단어표·과거 워크북 참조 회귀와 TypeScript·프로덕션 빌드 통과. 기존 대형 번들 경고는 유지된다. Node 20의 기존 Supabase 의존성은 위 WebSocket 플래그가 필요하다.

브라우저 검사는 합성 계정과 가로챈 Supabase 요청으로 실행했으며 운영 DB 쓰기는 0건이다. 결과·화면은 `output/phonics-games/checks.json`, `edge-checks.json`, 같은 폴더 PNG에 있다. 실제 전자칠판 하드웨어·설치된 영어 음성의 재생은 별도 확인 대상이다.

## 놀이 층 (2026-10-29, 1·2단계)

분석: 40종은 조작 틀 19가지를 공유하고 "문제 1개 → 정답 → 다음"을 반복해서, 아이에게는 문제집처럼 느껴졌다. 틀 하나하나를 고치기 전에 **모든 게임이 공유하는 판 구조**와 **가장 많이 쓰이는 조작**부터 바꿨다.

1단계 — 판 구조(`GameSession`, 40종 전부):
- **별과 목표:** 한 판의 목표는 "별 모으기"(문제 수 × 3). 첫 시도 ★3, 한 번 다시 ★2, 그 밖 ★1. 도전 난이도의 첫 시도는 +1, **3연속 첫 시도부터 콤보 +1**. 상단에 별·콤보 표시(콤보는 팀마다 따로 센다).
- **즉각 반응:** 문제를 맞히면 칭찬 말풍선·`+★` 숫자·별 터짐이 나온다(움직임 줄이기 설정이면 말풍선만).
- **결과 화면:** 별 1~3 등급, 모은 별·최고 콤보. 기존 문구("첫 시도에 혼자 맞힘: n")는 그대로 둔다.
- **팀 대결(1~4팀):** 문제마다 팀이 돌아가며 차례, 팀별 별 점수, 결과에 순위. 시작 화면 "함께 하는 방법".
- **난이도(쉬움/보통/도전):** 쉬움 = 그림과 글자를 함께, 도전 = 그림 없이 소리로. 그림 단서(`cue()`)를 쓰는 게임(분류·빈칸·첫소리 바꾸기·조립)에 적용된다.
- **소리 설명:** 문제마다 "설명 듣기" 버튼이 첫 설명 문장(없으면 게임 종류별 기본 문장)을 한국어·영어 TTS로 읽어 준다. "문제마다 설명을 소리로 읽어 줘요"를 켜면 자동으로 읽는다(글을 못 읽는 유치원 친구용). 선택은 이 브라우저에 기억한다(`classbank.phonics.autoSpeak`, 기본 꺼짐).

2단계 — 끌어서 놓기(`components/PhonicsDrag.tsx`의 `DragButton`/`DragBox`): 눌러서 고르는 방식은 **그대로 두고** 끌기를 더했다(키보드·보조 기기·기존 흐름 유지). 10px 넘게 끌면 카드가 손가락을 따라오고 `[data-drop]` 영역 위에서 빛난다. 틀리면 제자리로 돌아온다.
- 분류 7종: 단어 카드를 바구니로. 빈칸·첫소리 바꾸기 6종: 글자 조각을 빈칸으로. 고르기·읽고 고르기 6종(소리 낚시·몬스터 식당 등): 그림을 가운데 친구에게 끌어다 주기. (소리 풍선은 터뜨리기라서 눌러서만.)
- 그림(`img`)을 잡고 끌면 브라우저 그림 끌기가 포인터를 끊으므로 `dragstart`를 막았다.

정답 뒤 안내·다음 버튼(2026-10-29): 예전에는 정답 뒤 "완성했어요" 칸과 "다음 문제" 버튼이 활동 아래에 새로 생겨 화면이 길어지고 버튼이 화면 밖으로 밀렸다. 이제 **결과 카드**(`.pg-dock`, 높이 0의 sticky)가 화면 아래에 떠서 게임 화면 크기가 바뀌지 않는다. 카드에는 안내·읽을 단어(매직 e 게임은 모음·e를 강조해 보여 주고 듣기 버튼)·큰 "다음 문제/결과 보기" 버튼이 있고, 버튼은 폭죽을 볼 수 있게 0.65초 뒤 켜지며 그때 초점이 가서 엔터·스페이스로 넘길 수 있다. 오답 안내("다시 살펴볼까요?")도 같은 자리에 2.6초만 뜬다. 세션 상자는 둥근 모서리만 자르는 `overflow: clip`을 쓴다(`hidden`이면 sticky가 붙지 않는다). 전체화면에서는 전체화면 상자 안에서 같은 방식으로 동작한다.

힌트(2026-10-29): 예전 "선생님 힌트"는 활동 아래에 펼쳐지는 상자라 화면이 길어졌다. 이제 문제 제목 옆 **"힌트" 버튼**(전구 + 단계 점 2개)이 **2단계**로 돕는다 — ① 무대 친구의 말풍선 자리(`.pg-stage-caption`, 한 줄·넘치면 말줄임, 9초 뒤 원래 문구로)에 힌트가 뜨고 단어를 소리 내어 읽어 준다(짝 맞추기·다른 친구 찾기는 읽지 않음) ② 한 번 더 누르면 **정답이 반짝**인다(`data-hint`: 분류 바구니·빈칸 글자·조립할 다음 글자·고르기 그림·소리 풍선·위치 버튼·다른 친구·매직 e 글자·글자 탐험·사라진 카드·빙고 칸, 기억 카드는 카드를 모두 보여 줌). 힌트를 쓴 문제는 "도움 후 완성"으로 기록되어 별이 최대 ★2다. 화면 크기는 변하지 않는다(검사에서 높이를 비교).

아직(3·4단계): 같은 틀을 쓰는 게임마다 규칙·동사를 다르게 하기, 같은 단어를 다른 방식으로 다시 만나게 하기, 개별 음가 소리.

확인: `node --experimental-websocket scripts/phonics/check-play-layer.mjs`(설정 화면·분류/빈칸/고르기 끌기·별·콤보·팀 대결·난이도·소리 설명·결과 카드 위치·힌트 9항목, 합성 계정·DB 쓰기 0건)와 기존 `check-games.mjs`(40종 완료)·`--sound`.
