# 교사용 게임 조작 화면 정리 — 2026-10-24

현재 GAME_CATALOG 60종에 공통 GameWorkspace/GameThemeFrame을 적용한다. 컴퓨터 사용에 익숙하지 않은 선생님이 게임 안팎 이동을 찾기 쉽도록 실제 UI를 수정했다. 연령·성별에 따른 능력을 단정하지 않고 읽기 쉬운 글자, 명확한 행동 이름, 큰 조작 영역과 진행 보존을 기준으로 삼았다.

## 조사와 수정

- 기존 플레이 화면에는 메뉴만 있어 준비 화면 복귀·전체화면을 찾으려면 메뉴를 열어야 했다. 이제 상단에서 메뉴·잠시 멈춤·준비 화면·전체화면을 바로 선택한다. 조작 바는 게임 확대/축소의 영향을 받지 않는다.
- 일반 화면/전체화면에 같은 조작 바를 사용한다. 준비 화면 복귀는 같은 보드 인스턴스를 유지하며, 게임 목록으로 이동하는 별도 링크는 ‘게임 목록으로 나가기’로 표시한다.
- 상단은 PC에서 한 줄, 휴대폰에서 두 열이다. 이동 버튼은 실제 표시 높이 48px 이상, 글자 16px 이상으로 검증했다. 키보드 포커스는 굵은 테두리로 보인다.
- 준비 화면의 도구 버튼 나열을 줄이고, 소리·화면·되돌리기·다시하기는 메뉴의 ‘소리·화면 도구’로 모았다. 자료 재사용·활동지·수업 연결은 ‘자료 활용·저장 (선택)’으로 접었다. 유효한 기능이나 저장 자료를 삭제하지 않았다.
- 보조 버튼의 중복 아이콘을 제거했다. 외부 아이콘 글꼴이 없어도 visibility_off 같은 코드 이름이 버튼에 나타나지 않는다.
- 게임 선택 화면에 ‘게임 고르기 → 예시로 해보기 → 우리 반 자료로 바꾸기’ 안내를 추가했다. 설정 창의 버튼·입력 글자·체크박스를 키웠다.
- 기존 게임 그림·문제·점수·정답·시간 제한은 변경하지 않았다. 과밀한 작은 화면은 기존 내부 스크롤을 유지해 글자를 무리하게 축소하지 않는다. 게임 격자·낱글자 칸에 일괄 최소 크기를 강제해 판을 깨뜨리지 않았다.

## 검증

- 전체 60종의 실제 샘플 진입 및 노트북 1366×768, 태블릿 1024×768, 모바일 390×844 검사.
- 60종 각각 잠시 멈춤/재개, 기존 설정 열기/닫기, 준비로 복귀 후 같은 게임 재개, 게임 영역 맞춤과 모바일 수평 넘침 확인.
- 짝 맞추기에서 실제 두 정답 카드를 맞힌 후 멈춤·전체화면 권한 거부 시 대체 화면·Escape·준비 복귀에도 정답 표시와 보드 DOM 유지 확인. 메뉴의 도구 접근 및 게임 목록 이동 확인.
- Sentence Splash 성공/실패 결과, 1920/1024/1280×600 화면 전환, 큰 글자와 영어 표시, 모바일 스크롤 후 PC 복귀 회귀 검사.
- 기존 수업 만들기 매뉴얼의 Markdown과 4쪽 PDF를 갱신하고 바뀐 2쪽을 이미지로 렌더링해 확인했다.
- 결과 기록과 실제 캡처: output/teacher-game-ux/. 서비스 DB에 테스트 자료를 쓰지 않는 합성 계정/자료로 검사한다.

이는 60종의 모든 분기·완주·다기기 온라인 대회까지 전수 검증했다는 뜻은 아니다. 온라인 퀴즈 서버는 교사 화면의 멈춤과 독립적으로 계속될 수 있으며 기존 안내를 유지한다. 실제 연령대 선생님 대상 사용성 관찰이나 물리 전자칠판·Safari 검사는 별도이다.
