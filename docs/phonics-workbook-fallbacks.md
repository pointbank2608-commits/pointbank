# 4·5단계 워크북 선택·인쇄 수정

## 원인과 자산 조사

이전에는 `unit.issues.length > 0`이면 선택과 렌더링을 모두 막았다. 컬러·선화 부족도 철자 오류와 같은 조건으로 처리했다. 별도 화면에서 CVC 선택기를 쓰지 않고 `rounded-xl border p-3` 라벨 안에 빨간 누락 문구와 링크를 넣으면서 버튼이 커졌다. CSS 누락이 아니라 컴포넌트·조건의 차이였다.

공통 단어 ID와 실제 public 파일, 대소문자, 컬러·선화 경로를 대조했다. 기존 파일이 있는데 연결되지 않은 정확한 단어명 자산은 없었다. `blank/blink`는 사전 컬러 그림이 있고 선화가 없다. `clam/glob/glum`에는 대응 그림이 없다. `black/block/clock`은 컬러·선화가 모두 있다. 유사 이름의 shell/globe, 장식·게임 소품을 대신 연결하지 않았다. brush의 기존 그림은 솔/빗이므로 새 공통 데이터의 뜻을 동사 ‘솔질하다, 이를 닦다’에서 명사 ‘솔, 빗’으로 바로잡았다. 과거 사용자 저장 카드와 DB는 수정하지 않았다.

## 활동 선택

| 유닛 자료 상태 | 처리 |
|---|---|
| 모든 단어에 컬러·선화 보유 | 기존 6개 활동 유지 |
| 컬러는 모두 있고 선화가 일부라도 없음 | 1~5번 유지, 6번만 목표 규칙 철자 찾아 표시하기 |
| 컬러가 일부라도 없음 | 모든 단어를 읽고 말하기, 따라 쓰기, 목표 철자 찾기, 글자 배열, 빠진 규칙 철자 채우기, 뜻 보고 쓰고 표시하기에 포함 |
| 단어 수·철자 구간·중복이 잘못됨 / 텍스트 활동에 필요한 뜻 단서가 없음 | 계속 인쇄 제한, 교사용 영역에 이유 표시 |

부분 누락 시 해당 활동 전체를 같은 유형으로 구성해 clock 등 그림이 있는 단어도 빠뜨리지 않는다. 글자 배열은 결정적인 회전으로 반복 글자 개수와 대문자를 보존한다. 뜻 단서와 같은 유닛의 목표 규칙을 함께 제공한다. 혼자 쓰는 텍스트 활동 페이지에는 전체 정답 단어·빨간 정답 강조·따라 쓰기 정답을 출력하지 않는다. 색칠용으로 컬러 그림을 흑백 변환하지 않는다.

브라우저에서 기존 이미지 로드가 실패해도 같은 대체 정책을 적용한다. 해당 유닛의 이미지 검사 결과가 정해지기 전에는 인쇄를 대기하며, 실패 시 깨진 이미지 대신 텍스트 활동을 렌더링한다.

## 현재 집계

| 단계 | 전체/인쇄 가능 유닛 | 학습 항목 | 기존 6활동 | 6번만 대체 | 그림 없는 활동 세트 |
|---|---:|---:|---:|---:|---:|
| 4 | 48 / 48 | 105 | 19 | 18 | 11 |
| 5 | 32 / 32 | 66 | 25 | 6 | 1 |

학습 항목 수는 규칙별 표시 항목이다. 중복 제거 단어 수로 바꾸지 않았다. 대체 유닛에만 작은 ‘읽기·쓰기형’ 표시가 있고, ‘준비 중’으로 집계하지 않는다. 단어·부족한 자산·영향받는 유닛은 접힌 ‘자료 준비 현황’에 표시한다. 공통 워크시트 이동 링크 하나만 남겼다.

## 수정 파일

- `app/src/data/phonicsWorkbook.ts`: 유효성 오류와 자산 부족 분리, 활동 유형 판정, 런타임 자산 검사 결과 적용, 뜻 단서.
- `app/src/data/phonicsWorkbookTasks.ts`: 반복 글자를 보존하는 글자 배열.
- `app/src/components/worksheets/CvcWorkbookSheets.tsx`: 기존 렌더러·강조·빈칸·따라 쓰기 재사용, 활동 대체, CVC와 공유하는 작은 라벨·선택 버튼.
- `app/src/pages/PhonicsWorkbookPage.tsx`: 정확한 집계, PC2열/모바일1열, 접힌 현황, 자산 실패 시 대체, 좁은 화면 미리보기 내부 스크롤.
- `app/src/i18n/workbookLocales.ts`: 한국어·영어 안내와 활동 문구.
- `app/src/data/phonics/words.json`: brush 뜻만 기존 그림에 맞게 수정. 확정 단어·순서·기본/확장·유닛 ID는 유지.
- `app/scripts/phonics/check-workbook-fallbacks.mjs`, `check-fallback-browser.mjs`: 자산·유효성·문제·선택·인쇄 검증.
- 기존 `check-curriculum.mjs`, `check-browser.mjs`, `scripts/workbooks/check-flow.mjs`, `check-pdfs.py`: 새 인쇄 정책의 예상값으로 회귀 검사 갱신.

## 검증 결과

- 별도 승인 단어표 대조 통과. 1~5단계 단어·순서·기본/확장 구분·안정적 ID 및 과거 참조 그대로 유지.
- black/block, blank/blink, clam/clock, glob/glum 및 brush 두 규칙 검사 통과. br은 [0,1], sh는 [3,4]를 강조·빈칸 처리.
- 잘못된 목표 구간·빈 단어 목록·뜻 단서 누락 차단, 실제 파일 존재·매핑 대조, 모든 단어의 글자 개수·중복 보존 검사 통과.
- PC2열/모바일1열, 작은 파란 규칙 라벨, 체크박스 선택·전체 선택·해제, 키보드 포커스, window.print 호출 통과. 모바일 전체 화면 가로 넘침 없음.
- 대표 5유닛 PDF 각2쪽, 전체4단계96쪽·5단계64쪽. A4 크기·빈 페이지·메뉴 누출 없음. 브라우저에서 그림 로드·넘침·목표 철자·문제 단서 검사, PDF를 PNG로 렌더링해 clam/clock 등 눈으로 확인.
- CVC·매직 e 대표 PDF는 기존 기준 대비 픽셀 차이0. Fredoka·Andika 로드 확인. 기존 문법 화면 회귀 검사도 통과.
- TypeScript, Vite 빌드, 변경 소스 Oxlint, git diff --check 통과. Vite의 기존 큰 번들 안내만 남음.

검사 결과·화면 캡처는 `output/phonics-fallback/`, 회귀 PDF 결과는 `output/phonics-curriculum/print/pdf-checks.json`에 있다. 브라우저 검사는 Supabase 응답을 가로채 실제 사용자 데이터를 변경하지 않는다.
