# 풍선 보기와 결과창 화면 맞춤

- 일반 글 문제는 `adventure.choices`로 보기를 만든다. 4개를 설정한 기본 재현에서 실제 DOM의 보기도 4개였다. 열려 있는 상단 설정 창은 왼쪽 풍선을 가릴 수 있다. 설정 창을 닫고 적용한 게임에서 실제 보기 수와 화면 노출을 검사한다.
- 기존 와이드 배치에서는 제목·질문·안내가 높이를 많이 차지해 풍선 슬롯이 작아졌다. 풍선 화면의 제목·질문·안내 간격과 높이를 줄여 풍선에 공간을 더 배분한다. 풍선 SVG와 글자는 같은 비율로 확대한다. 그림 질문도 장면 높이에 맞춘다.
- 그림 문제 생성은 이전에 보기 수를 4개로 고정했다. `pictureQuizDeck`의 선택적 보기 수를 어드벤처 설정과 연결했다. 다른 게임의 기본값은 기존 4개다.
- 공통 어드벤처의 정답 확인과 최종 결과는 `AdventureOutcome`을 사용한다. 전체 내용·듣기·다음/다시 플레이 버튼을 함께 측정해 카드에 맞춘다. 결과 목록은 여러 열로 배치하고, 축소할 때 자연 배치 폭을 늘려 실제 카드의 가로 공간도 활용한다. 내용 삭제·줄임표·결과 내부 스크롤은 사용하지 않는다. 최대 문항이나 긴 내용은 글자가 작아질 수 있다.
- `data-game-contained`는 내부에서 맞춤이 끝난 카드임을 공통 화면 맞춤 계산에 알린다. 내부의 축소 전 크기를 게임 전체 크기로 중복 계산하지 않는다.
- 게임 규칙·정답·차례·자료 저장·학습 센서 호출은 바꾸지 않는다. 확인은 API/인증이 분리된 로컬 fixture이고 운영 학습 근거를 만들지 않는다.

검증: `node app/scripts/lessons/check-balloon-layout.mjs`. 3440×1300, 1920×1080, 1366×768, 1024×768, 390×844에서 보기 3~6개의 실제 설정 적용과 일반/Chrome 전체화면 노출 40조합, 그림 보기 3~6개, 정답 확인/최종 결과, 긴 단어 50개 결과의 전체 표시를 검사한다. `BALLOON_OUTPUT`으로 JPG와 측정 JSON을 저장할 수 있다. 공통 화면 회귀는 `FIT_TYPES=balloonpop,wordfishing,wordtrain,wordclaw node app/scripts/lessons/check-game-viewport-fit.mjs`의 일반/전체화면/발표 12조합으로 확인한다.

기존 `check-adventure.mjs`는 현재 UI에 없는 `다시 시작` 버튼을 기다려 중단된다. 이번 검증 통과로 기록하지 않는다.

## 후속: 제목 영역 축소와 그림 문제 확대

풍선 화면의 브랜드 부제는 숨기고 게임 이름과 진행 수를 한 줄에 배치한다. 그림 문제는 장면 높이의 28%(최대 190px, 이전 16%·110px)로 확대하고 카드 여백도 줄인다. 높이 360px 이하 장면에서는 그림 카드와 풍선의 좌우 공간을 따로 확보한다. 다른 게임의 제목·그림 크기는 바꾸지 않는다.

위 5개 화면 크기에서 그림 보기 3~6개 20조합을 추가로 확인했다. 그림과 풍선의 화면 내 노출·겹침 없음, 와이드 화면의 그림 크기·제목 높이, 기존 일반/전체화면 40조합과 50문제 결과 검증을 통과했다. 타입 검사도 통과했다. 로컬 서버는 `VITE_SUPABASE_URL=http://127.0.0.1:5587`, 가짜 키와 센서 false로 실행하며 운영 데이터는 사용하지 않는다.

## 후속: 그림 문제를 낚시 게임처럼 좌우 배치

가로 화면(장면 폭 600px 이상·비율 3:2 이상)의 그림 문제는 왼쪽에 큰 그림, 오른쪽에 풍선 영역을 놓는다. 그림은 장면 높이의 최대 60%를 쓰고 보기 4개는 2×2, 5~6개는 3×2로 배치한다. 도움말과 연속 정답 보너스는 별도 행으로 놓는다. 세로 화면은 기존 위아래 배치를 유지하며 일반 뜻 문제에는 적용하지 않는다.

`check-balloon-layout.mjs`의 그림 문제 검증을 5개 화면 크기 × 보기 3~6개 × 일반/실제 Chrome 전체화면 40조합으로 확장했다. 그림의 왼쪽 배치·4개 보기의 두 줄 배치·화면 내 노출·그림과 풍선 겹침 없음, 일반 문제 40조합 및 결과 창 회귀를 통과했다. 프로덕션 빌드도 통과했다.

## 후속: 그림 모드 풍선과 영어 글자 확대

세로형 몸통과 긴 줄 때문에 두 줄 보기의 높이로 크기가 제한되던 부분을 고쳤다. 그림 모드에는 몸통이 넓고 줄이 짧은 별도 SVG(400×270)를 쓰며, 각 보기 칸의 가로·세로 96% 안에서 비율을 유지해 확대한다. 글자는 풍선 폭의 18%(최대 72px), 긴 단어는 기존 `GameFitText`로 줄여 담는다. 일반 뜻 문제의 풍선은 그대로다.

위 80조합과 50문제 결과 검증을 통과했다. 3440×1300의 그림 보기 4개에서는 풍선 폭 400px 초과·영어 글자 높이 55px 초과를 별도로 검사한다.
