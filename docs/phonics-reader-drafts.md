## 검토할 사항

- 소유·인칭 문장에서는 교사가 그림을 가리키며 사람·소유 맥락을 설명한다. 단순 그림 카드 장면은 실제 소유 관계를 증명하는 사진이 아니다.
- 같은 장면의 단어 그림 위치는 고정하고, 화살표와 문장만 바꾼다. 추가 그림이나 어려운 명사를 넣지 않았다.
- These are fish. 장면에는 같은 어휘 그림 두 개를 배치해 복수 의미를 보여 준다. teeth는 기존 복수 대상을 표현하는 그림을 사용한다.
- them은 관계 그림과 교사 설명을 함께 사용한다. 단독 그림만으로 인칭대명사를 확정하는 문제로 사용하지 않는다.
- 새 문장과 사이트워드는 별도의 승인 전까지 개발 미리보기만 제공한다.
