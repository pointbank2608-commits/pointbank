# 전체 게임의 단계별 시작 안내 적용 가능성 (26f17eb, 2026-10-20)

## 결론

현재 게임 목록 53종 모두에 공통 단계 안내를 적용할 수 있다. 교사용 53개 라우트가 모두 GameWorkspace에 연결되어 있다. 다만 동일한 단어 입력 양식으로 53종을 처리할 수는 없으며, 공통 진행 틀 안에서 게임별 필수 콘텐츠 편집 단계를 연결해야 한다. 이 문서는 구현 타당성 검토이며 기능 구현·배포 완료 보고가 아니다.

범위는 GAME_CATALOG의 53종이다. /materials/bingo 및 /materials/memory-cards 같은 인쇄 자료는 이 숫자에 포함하지 않는다.

## 구현 전 정리할 사항

1. gamePreparation의 표시용 kinds, gameWorkspace의 호환 범위, gameFromWords 변환, 페이지 listKind가 따로 관리된다. 문장 잡기/번개 피하기의 단어 지원, 참거짓/휴대폰 대회의 자료 선택 숨김 등이 확인됐다. 게임 분류(category)와 실제 지원 자료를 구별하고 하나의 안내 정의에서 참조하도록 해야 한다.
2. minItems=999는 실제 최소 개수가 아니라 전용 형식의 과거 표식이다. 새 안내에 999개 필요로 표시하면 안 된다. 각 게임의 변환 후 유효 항목·문제·그룹 수로 안내해야 한다.
3. 현재 공통 준비 검사는 글자 수·퍼즐 실제 배치 가능성까지 보장하지 않는다. 합성 한 글자 단어 두 개는 워드서치/크로스워드의 준비 검사를 통과하지만 게임 내부에서는 제외된다. 15글자 단어 두 개도 워드서치 공통 준비 검사는 통과하나 판은 최대 14칸이므로 내부 배치에서 제외된다. 안내 구현 시 누락/제외 이유 및 실제 사용 개수 검증 필요.
4. Sentence Bridge는 빈칸·정답·오답, Sentence Tower는 삽입 위치와 앞뒤 문장 정합성이 핵심이다. 단순 문장 목록을 조용히 샘플로 대체하거나 자동 정답 생성했다고 표현하면 안 된다.
5. 저장한 게임을 여는 경우는 기존 실행을 유지하고 필요 시 내용 바꾸기를 제공한다. 최초/새로 준비 경로에서 단계 안내를 사용하되 기존 원본·저장 게임·수업을 암묵 수정하지 않아야 한다.
6. 내장 역할극에는 단어장 선택을 강요하지 않는다. 휴대폰 대회는 무저장 체험과 실제 서버 세션 개설을 명확히 구분한다. 현재 임시 활동은 preview 경로다.

## 권장 공통 구조

자료 선택 → 게임별 필수 입력 → 준비 확인 → 시작. 샘플·내장 내용·기존 자료로 충분하면 해당 입력 단계는 생략한다. 이미 선택한 자료의 종류는 다시 묻지 않는다. 제한시간·팀 수·효과음 등은 유효한 기본값을 제공하고 추가 설정으로 접는다. 게임별 definition에는 입력 방식, 지원 자료, 필수 조건, 기본값, 기존 편집기 연결을 둔다. 게임 규칙과 진행 엔진은 기존 코드를 유지한다.

## 확인 방법과 한계

- GAME_CATALOG 53종 고유 식별자, GameType, 교사용 공통 라우트 53개 및 기존 페이지 편집/불러오기 경로를 대조했다.
- 임시 로컬 Vite SSR에서 53 × 2 = 106개 합성 자료 변환·공통 준비 검사를 실행했다. 검사 전후 원본 불변도 확인했다. 합성 자료로 공통 변환 및 준비 검사를 모두 통과한 유형은 단어 42종, 문장 12종이다. 이는 안내 기능 적용 가능 게임 수와 다르다.
- 워드서치 길이 경계 2건·크로스워드 한 글자 경계 1건을 추가 확인했다.
- 운영 DB 접속·자료 생성·앱 코드 수정·마이그레이션·커밋·배포는 수행하지 않았다.
- 이번 검토에서는 실제 브라우저로 53종을 다시 완주하거나 사용자 테스트를 실시하지 않았다. 새로운 단계 안내 자체도 아직 구현하지 않았다.
